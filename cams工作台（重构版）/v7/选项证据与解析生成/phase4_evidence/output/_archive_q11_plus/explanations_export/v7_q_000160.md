# v7_q_000160

教材章节：未映射

题型：single

题干：有效的反洗钱/打击资助恐怖主义合规计划的基本要素之一是:

英文题干：One of the basic elements of an effective AML/CFT compliance program is:

选项：

- A. 企业风险管理体系
  English: A system of enterprise risk management
- B. 基于人工智能的交易监控系统
  English: An artificial intelligence-based transaction monitoring system
- C. 独立且专业的审计职能
  English: An independent and skilled audit function
- D. 基于人工智能的强化尽职调查系统
  English: An artificial intelligence-based enhanced due diligence system

答案：C

解析：

考点：识别反洗钱合规计划的法定支柱之一

核心解析：教材在多处通过「支柱」或「防线」框架，界定有效反洗钱合规计划的法定基本要素。《银行保密法》要求义务实体基于五大支柱制定有效反洗钱计划（P180），第四大支柱是独立审计职能，用于测试内部反洗钱政策是否充分有效（P245）。同样，在「三道防线」框架中，独立审计职能作为第三道防线（P256），客观评估风险管理与治理的有效性。题干问的是合规计划的「基本要素」，直接对应法定支柱清单里的独立审计职能，C选项正是这一法定支柱的完整表述。
教材原句："The fourth pillar is an independent audit function that tests whether internal AML policies are adequate and effective."

A项错误：企业风险管理体系是反洗钱合规运作的基础环境（P265称风险评估为风险管理项目的基础），但它本身并未被教材列为合规计划的法定支柱之一。题干问的是合规计划的「基本要素」，正确项更直接匹配法规（P180、P245）列出的支柱清单。
B项错误：教材在技术演进部分提到AI驱动的交易监控系统可革新欺诈和洗钱检测（P330），交易监控本身是合规计划中的一项控制措施，但法规框架将独立审计列为支柱（P180），而不是具体的技术工具。正确项比B更吻合监管对法定基本要素的界定。
D项错误：强化尽职调查在教材中出现于高风险场景的管控措施中（P57、P357），课程亦提及用AI辅助检测，但监管法规未将「AI驱动的强化尽职调查系统」列为有效合规计划的基本支柱。正确项在教材支柱框架下定位更直接。
