题型：multiple

题干：在基于规则的交易监控方法中,用于检测可疑活动的最常见技术有哪些？(选择两项.)

英文题干：Which techniques are most commonly used in a rules-based approach to transaction monitoring for detecting suspicious activities? (Choose two.)

选项：

- A. 利用预设规则标记特定的交易模式
  English: Using predefined rules to flag specific transaction patterns
- B. 随机标记交易以作进一步调查
  English: Randomly flagging transactions for further investigation
- C. 通过统计方法调整监测场景以提高准确性
  English: Statistical tuning of monitoring scenarios to improve accuracy
- D. 利用先进的机器学习模型检测异常值
  English: Using advanced machine learning models to detect outliers
- E. 设置用于自动警报的交易阀值
  English: Setting transaction thresholds for automated alerts

## 【AI答案】

A、E

## 【考点】

基于规则的交易监控所依赖的预设规则与阈值

## 【核心解析】

基于规则的交易监控方法的核心是金融机构根据已知风险因素或监管要求预先设定的静态、可预测的规则和阈值（P436）。题干明确限定在「rules-based approach」范围内，问的是用于检测可疑活动的最常用技术。选项 A「利用预设规则标记特定的交易模式」直接对应预设规则（predefined rules），选项 E「设置用于自动警报的交易阀值」直接对应阈值（thresholds），二者同属教材描述的核心技术，且教材举例说明设定阈值（如 1 万美元）后超限交易触发警报（P436），正好把规则和阈值作为检测手段，因此 A 和 E 成立。

教材原句："Financial institutions create rules based on known risk factors or regulatory requirements. They set predefined rules or thresholds, which are static, predictable, and easy to implement and understand."

## 【错误项分析】

- **B 错误（教材定义应用）｜概念混淆**：随机标记（Randomly flagging）与基于规则的方法相悖，基于规则的方法依赖预定义条件而非随机选择，教材从未将随机标记列为基于规则的检测技术。
- **C 错误（题干对照）｜范围或程度偏差**：通过统计方法调整监测场景（Statistical tuning of monitoring scenarios）属于监控系统的后续调优维护，教材在 P446 将其描述为「持续测试和调优交易监控场景以确保有效性」，而非直接用于检测可疑活动的技术本身，与题干所问的检测技术匹配度较低。
- **D 错误（教材定义应用）｜概念混淆**：先进的机器学习模型（advanced machine learning models）属于行为分析手段，教材在 P398 指出机器学习可识别传统规则可能遗漏的模式，但题干明确限定在「基于规则的方法」（rules-based approach），机器学习不属于该范畴，题干更支持 A、E。

## 【易错提醒】

题干限定「基于规则的方法」，题目的选项常混入「基于风险/行为的方法」技术（如机器学习和统计调优）。基于规则的方法使用预定义的静态规则和阈值（P436）；机器学习通过从历史数据中学习并自适应变化（P398），属于另一类监控方法。看清方法限定词即可避免误选。
