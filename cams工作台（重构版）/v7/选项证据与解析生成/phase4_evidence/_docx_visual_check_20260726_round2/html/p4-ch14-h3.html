试卷名称:CAMS CH14

一、单项选择题

1. 在通过组织的全企业制裁风险评估发现可能存在漏洞,即与业务规模和运营情况相比,生成的制裁筛查警报数量过少时,以下哪项行动最能确保该风险领域得到妥善管理和尽可能彻底的整改？ ( )

A. 审查企业范围的风险评估方法

B. 加强员工关于已关闭警报的合理化说明文档编制方面的培训

C. 重新审视交易后监控系统的参数和阈值

D. 审查筛选系统当前采用的模糊逻辑

答案:D

解析：

考点

制裁筛查中模糊逻辑级别调优对警报数量的影响

核心解析

制裁筛查系统依赖模糊逻辑技术来检测名称的近似匹配，如拼写错误、缩写和音译等变体P421。机构需要定期调整模糊逻辑算法，以在检测准确性与减少误报之间取得平衡。题干中全企业制裁风险评估已经指出“警报数量过少”这一漏洞，且该漏洞“与业务规模和运营情况不匹配”。在给定选项中，问题更可能出在筛查系统本身的匹配灵敏度上，而非风险评估方法论或员工操作环节；因此，审查当前筛选系统采用的模糊逻辑是最直接的整改方向，可用于提升名称变体的检出率。

教材原句

"In a sanctions screening system, you might tune the fuzzy logic levels to adjust the fuzziness level, detecting variations in names, such as misspellings, abbreviations, and transliterations."

A项错误

审查风险评估方法论针对的是风险评估框架本身是否完善，但题干已说明漏洞是通过该评估发现的，问题出在筛查执行层面而非评估方法。直接调整系统参数比重新审视方法论更能精准解决“警报数量过少”的根因。

B项错误

加强员工针对已关闭警报的文档编制培训，聚焦的是警报产生之后的人工处理环节。题干的核心问题是警报“生成”数量过少，而非已生成警报的关闭理由记录不佳，培训无法提升系统本身的检出灵敏度。

C项错误

交易后监控系统（transaction monitoring）主要用于识别可疑交易模式，其参数和阈值调整与异常行为检测相关P328；而题干所指的“制裁筛查警报”属于制裁名单筛选系统（sanctions screening），二者在教材中分属不同的控制模块（P420-421 vs P306/P436）。审查模糊逻辑更直接命中制裁筛查系统特有的匹配灵敏度问题。

易错提醒

制裁筛查系统（sanctions screening）与交易监控系统（transaction monitoring）容易混淆。制裁筛查针对制裁名单、PEP名单等进行名称匹配，核心调优手段包括模糊逻辑级别P421；交易监控则针对客户交易行为模式设置规则和阈值，以识别可疑活动P328。题干明确说的是“制裁筛查警报”，应围绕筛选系统而非监控系统寻找整改措施。

 

2. 在将新技术应用于反洗钱(AML)时,应用程序编程接口(API)能够实现: ( )

A. 移动设备上的数字身份识别

B. 让不同的应用程序相互连接并通信

C. 通过人工智能(AI)和生物识别技术进行身份验证

D. 在客户入职期间快速进行客户细分和客户特征分析

答案:B

解析：

考点

API 的核心功能：让不同应用程序连接与通信

核心解析

在AML技术语境下，API（应用程序编程接口）的核心作用是实现系统间的连接与数据交互。教材提到，筛查系统应与其他系统兼容，这其中包括 API 集成P424；数据收集也可以通过 API 调用完成P476，并支持从数据库、云服务或第三方应用自动检索数据P480。因此，API最本质的功能是充当不同软件之间的桥梁。题干问 API 能够“实现”什么，选项B“让不同的应用程序相互连接并通信”最直接地对应这一功能。其他选项描述的是在连接能力基础上由具体应用完成的业务场景，并非API本身的定义。

教材原句

"Screening systems should be compatible with other systems. This includes data flows, workflow management tools, and application programming interface (API) integrations."

A项错误

教材在讨论数字身份时，确实提到了移动设备P404，但阐述的核心是政府电子身份系统与金融机构流程的整合，并未明确将“移动设备上的数字身份识别”归结为API的直接功能。API更基础的角色是打通数据通路，而非直接执行身份识别这一具体任务，因此B比A更直接地匹配API的本质定义。

C项错误

教材提到金融机构会使用AI和生物识别技术来验证客户P408，P374，但这些技术是独立的身份验证手段。API的作用是连接和调用这些技术模块，而不是直接等同于“通过AI和生物识别技术进行身份验证”这个身份验证功能本身。题干问的是API本身的功能，因此B的“连接与通信”比C更接近API的底层定义。

D项错误

客户细分和客户特征分析（CDD）是客户准入流程中的特定业务环节P374。教材表明这些流程会用到数据，而API负责从源头系统和第三方自动检索和传输这些数据P480。API是实现数据流通的通道，而非直接执行“快速客户细分和特征分析”的分析工具，因此B的功能描述更为通用和基础。

易错提醒

避免将API（连接工具）和它支撑的上层应用（如AI身份验证、数字身份识别）混为一谈。就像水管的作用是送水，而非直接灭火。本题问的是“送水”的功能，而非“灭火”的场景。

 

3. 以下哪一项最能描述模糊逻辑在客户筛选系统中的应用？ ( )

A. 它产生的输出结果包括介于"是"和"否"之间的一系列中间可能性.

B. 它是一种先进的分析工具,被广泛用于实施AFC控制措施.

C. 它能够实现更多的精确匹配,从而减少人工审核的需求.

D. 这是一种用于提升待审核警报质量的新技术

答案:A

解析：

考点

模糊逻辑输出相似度概率而非绝对的是/否判断

核心解析

模糊逻辑是一种通过算法计算名称间“相似度”来判断两名称属于同一人概率的匹配技术P420。这意味着它的核心输出不是二元的“匹配/不匹配”，而是一系列介于“是”和“否”之间的可能性分值。题干问的是模糊逻辑在客户筛选系统中的“应用描述”，选项A——“它产生的输出结果包括介于『是』和『否』之间的一系列中间可能性”——正与教材中对模糊逻辑使用“degrees of similarity”来决定“probability”的描述完全吻合，因此最能描述其本质特征。

教材原句

"This technique is accomplished through algorithms that use degrees of similarity to determine the probability that two names are the same."

B项错误

教材将模糊逻辑定位为一种“匹配技术（matching technique）”P420，而非一项实施AFC控制措施的广义“先进分析工具”。虽然CAMS教材讨论了用于AFC的先进分析（如P373），但就本题所问的“在客户筛选系统中的应用”而言，教材对模糊逻辑的定义支持A更直接。

C项错误

模糊逻辑的核心价值在于处理拼写错误、不完整名称等不一致数据P420，它放宽了匹配条件以减少漏报，而非追求“精确匹配”。追求精确匹配是其对立面——确定性匹配（deterministic matching）的特征。教材在讨论模糊逻辑时强调它导致“部分匹配”，这本身就意味着它不是精确匹配。

D项错误

模糊逻辑是一种名称匹配技术，其直接作用是计算相似度并产生匹配结果，不是对既有警报进行调查或处置。“新技术”也不是其定义特征，因此D混淆了匹配生成与警报审核两个环节。

易错提醒

模糊逻辑的核心是“相似度”（不是精确匹配），它放松匹配条件以减少漏报，但代价是增加误报（部分匹配需人工调查）。容易将其与追求“精确匹配”的确定性匹配混淆。

 

4. 在姓名筛查的背景下，模糊逻辑或模糊匹配是一种方法，其： ( )

A. 利用机器学习根据历史数据预测名称

B. 将筛查名单上的姓名与拼写、模式或发音相似的姓名进行匹配

C. 将长度相同且字符相同的名称进行匹配

D. 仅依赖于精确的字符串匹配

答案:B

解析：

考点

识别姓名筛查中模糊逻辑匹配的定义

核心解析

模糊逻辑匹配使用算法匹配相似但不完全相同的名称，处理拼写、打字错误和翻译差异P416。题干问姓名筛查背景下模糊逻辑是什么方法，关键属性是“处理名称相似但不完全相同的情况”。选项B“将筛查名单上的姓名与拼写、模式或发音相似的姓名进行匹配”直接覆盖了教材对模糊逻辑的核心定义，故成立。

教材原句

"Fuzzy logic matching uses algorithms to match names that are similar but not identical, accounting for variations in spelling, typos, and translations."

A项错误

机器学习利用历史数据预测并持续学习P417，与模糊逻辑聚焦特定名称集进行相似匹配不同。题干明确问模糊逻辑，选项A描述的是另一种技术，不如B直接吻合模糊逻辑的定义。

C项错误

将长度相同且字符相同的名称进行匹配实质上是要求严格的结构一致，而模糊逻辑设计的目的正是克服名称在拼写、长度、字符排列上的差异（如“John Smith”与“Jon Smith”仍被视为潜在匹配）。选项C接近精确匹配，与模糊逻辑的灵活性方向相反。

D项错误

教材指出仅靠精确名称匹配极具挑战性P420，模糊逻辑正是为弥补精确匹配的不足而引入，可匹配拼写错误、不完整名称及发音近似的名称。选项D描述的方法更接近确定性匹配，与模糊逻辑的目的相悖。

易错提醒

模糊逻辑与机器学习的核心区分在于：模糊逻辑聚焦特定名称的相似匹配，处理拼写变体和翻译差异；机器学习则通过历史数据学习并持续改进，可处理更广泛的数据模式P417。若题干强调“从历史数据中预测”或“持续学习”，则指向机器学习而非模糊逻辑。

 

5. 在确定制裁筛查的模糊匹配阈值时,应考虑以下因素: ( )

A. 处理潜在匹配项所带来的操作负担.

B. 对违规行为处以罚款的金额.

C. 团队处理潜在匹配的经验

D. 要筛选的数据是否可靠且经过验证

答案:A

解析：

考点

理解制裁筛查模糊匹配阈值与警报量、误报及调查工作量之间的关系

核心解析

模糊逻辑配置会生成部分匹配，这些匹配随后必须接受调查，以判断是真实匹配还是误报P421。在制裁筛查系统中，机构可以调节模糊逻辑级别；调整参数会增加或减少警报数量，调优则有助于管理警报量并减少误报P421。异常高的误报比例、超出预期的警报数量或完全没有警报，都会触发手动调优P422。因此，阈值会直接影响需要处理的潜在匹配数量、误报数量及相应调查工作量，A在四个选项中最直接。

需要注意，教材同时指出，机构不能简单按照团队规模限制系统生成的警报数量，因为这可能损害调查质量并造成不合规P421。这并不否定操作负担是阈值调优时的现实考量，而是说明不能为了迁就处理能力而机械压低警报量。

教材原句

"Tuning helps you manage the volume of alerts and reduces the number of false positives a system generates."

B项错误

模糊阈值应根据警报数量、误报比例及系统逻辑进行调优。违规罚款属于不合规可能产生的后果，不能直接决定模糊匹配级别。

C项错误

团队处理潜在匹配的经验不是模糊逻辑阈值的设定指标。团队规模也不应成为硬性限制警报数量的依据，否则可能影响调查质量P421；因此不能据此推出应按团队经验设定阈值。

D项错误

教材关于使用关键词过滤无关信息以及选择可信、可靠来源的内容，针对的是负面媒体筛查P422，不是制裁筛查的模糊匹配阈值。此外，“可信、可靠”也不等同于选项所说的“经过验证”，因此D与题干的匹配度不如A。

易错提醒

判断阈值题时，应优先寻找教材明确连接的调优结果：部分匹配需要调查，参数会改变警报数量，误报率和异常警报量会触发手动调优。这些因素共同指向潜在匹配的处理负担。操作负担可以纳入考量，但不能简单按团队规模设定警报上限。

 

6. 一家金融机构计划采用具备人工智能(AI)/机器学习(ML)功能的系统来实施负面媒体报道筛查。在测试期间，该系统生成了大量不相关的新闻文章供审核。解决这个问题的最佳方法是什么？ ( )

A. 精简媒体来源，避免无关文章

B. 依靠调查人员的人工筛选

C. 提高向媒体渠道更新的频率

D. 调整人工智能/机器学习模型，使其重点关注高风险关键词/短语，并优先使用可信媒体来源

答案:D

解析：

考点

AI/ML筛查系统的误报优化方法

核心解析

题干中的大量无关文章属于筛查误报。教材对该场景给出了直接调参规则：负面媒体筛查系统应调优关键词和短语，以过滤无关信息P422，并应选择可信、可靠的信息来源P422。D同时命中这两项要求，直接解决系统产生大量无关文章的问题，因此答案为D。机器学习模型利用历史筛查结果提高准确性、减少误报P417可作为辅助背景，但“高风险关键词/短语”和“可信媒体来源”是对教材调参原则的场景化表述，不应扩展成教材规定的唯一固定参数。

A项错误

简单缩减媒体来源可能减少文章数量，却也可能漏掉相关风险信息；它没有直接改善模型识别相关性的能力。D还保留可信来源并调整匹配重点，更贴合教材的模型优化路径。

B项错误

人工筛选只能在结果产生后处理噪音，不能解决系统持续产生大量误报的根因，也与采用AI/ML提升效率的目的不符。

C项错误

更新频率影响信息时效性，不会提高文章与筛查对象之间的相关性，不能解决题干所述大量无关结果。

易错提醒

负面媒体筛查应通过适当测试和调优减少误报，并优先采用经过验证的来源。关键词和短语是可调参数之一，具体设置仍应根据机构风险和筛查目标确定，并非只有一种固定配置。

 

7. 人工智能(AI)和机器学习(ML)程序有助于在反洗钱合规中采用基于风险的方法,具体体现在:(选择三项.) ( )

A. 自动生成可疑活动报告(SAR),无需人工审核

B. 高级客户风险评估,将客户背景信息与额外数据综合起来进行分析

C. 查明看似毫无关联的客户之间存在的联系,这些客户建立了复杂的网络用于洗钱

D. 自动调整客户的风险阈值,无需任何人工干预

E. 交易中复杂洗钱模式的检测

答案:B、C、E

解析：

考点

AI/ML在风险为本反洗钱中的具体应用场景与人工监督边界

核心解析

机器学习算法可通过识别可疑活动模式和异常来改进客户风险评估P416，对应B。网络分析模型能够揭示可能参与非法活动的个人或实体之间的隐藏网络P418，对应C。高级机器学习算法还可检测与洗钱和制裁规避相关的交易模式，并标记高风险活动供进一步调查P456，对应E。A、D都声称不需要人工审核或任何人工干预，但自动化仍须保留人工复核和模型治理，因此应选B、C、E。

教材原句

"Machine learning algorithms improve customer risk assessments by identifying patterns and anomalies that may indicate suspicious activity."

A项错误

NLP可以自动生成SAR叙述、减少人工工作量，但生成结果仍需人工审核确认，是否提交SAR也由人员最终判断P385、P397。A中的“无需人工审核”把辅助起草扩大成了自动决策。

D项错误

客户风险阈值会影响风险分类和后续控制，调整过程需要模型治理和人工监督，以确保模型可解释、无偏见并符合伦理原则P449。D中的“无需任何人工干预”忽略了这些治理要求。

易错提醒

区分“AI辅助决策”与“AI替代决策”：SAR叙述可以自动生成，但仍要人工审核；AI模型也需要治理监督。AI/ML可以增强检测和分析效率，但“without human intervention”或“without the need for human review”这类绝对表述忽略了必要的人工参与。

 

8. 哪些措施有助于确保名称筛查流程能够有效识别潜在风险？(选择三项.) ( )

A. 在政策和程序中明确界定筛查范围、频率以及警报裁决流程

B. 确定行业内最常用的姓名筛查数据库

C. 指定专人确保筛查控制措施得到一致实施

D. 进行风险评估,以确定要筛选的数据属性、筛选频率以及数据库的选择.

E. 定期进行测试,以验证筛查系统是否按预期运行

答案:A、D、E

解析：

考点

风险为本的名称筛查设计与测试

核心解析

有效的制裁筛查需要同时回答“如何筛”“筛什么、用什么名单”以及“系统是否真的按设计运行”。教材将规划客户和交易筛查方式、选择名单以及测试名单管理流程共同作为确保制裁合规计划有效的措施P419。选项A把范围、频率和警报裁决写入政策程序，固定筛查流程；选项D通过风险评估决定数据属性、频率和数据库，符合“根据法规和风险决定筛查对象及名单”的原则P419；选项E通过定期测试验证名单是否正确集成并产生相关警报P420。因此答案为A、D、E。

教材原句

"Carefully considering how to plan to screen customers and transactions, which lists to use, and how to test that the list management process is working correctly ensures that the sanctions compliance program is effective."

B项错误

“行业内最常用”不能替代与机构自身地理位置、交易币种、业务模式、客户所在地和客户活动相匹配的名单选择P419。数据库的普及度本身不能保证筛查适合本机构的风险暴露。

C项错误

指定责任人有助于落实控制，但选项只说明“有人负责”，没有规定筛查范围、风险参数或验证机制。相比之下，A、D、E直接覆盖筛查的设计、风险校准和测试。

易错提醒

名单选择应以机构风险为本，而不是追随行业使用频率；测试则验证选定名单是否正确进入系统并产生相关警报。风险评估和测试分别解决“参数为何这样设”与“系统是否照此运行”。

 

9. 使用人工智能（AI）和机器学习技术进行负面媒体报道筛查，可以：（选择三项。） ( )

A. 确保所有负面媒体来源都得到全面分析，而无需人工审查

B. 通过提供一致且高度准确的分析，显著减少重复性任务产生的人为错误

C. 能够立即识别媒体文章背后的意图，从而更有效地进行风险评分

D. 自动识别新信息并将其与以前遇到的数据区分开来

E. 覆盖多种语言和文字，超越人类语言能力的局限

答案:B、D、E

解析：

考点

区分AI/机器学习在反洗钱应用中的能力边界与局限

核心解析

机器学习能够从数据和历史表现中学习，并通过模式识别改进结果P384；自动化筛查可以提高处理速度和一致性，降低重复工作中的人为错误P416，因此B正确。AI支持历史分析和非结构化数据审查P385，能够把新内容与既有模式或历史结果比较，从而自动识别新增信息，D正确。AI结合自然语言处理还能识别语言变体和翻译差异P426，扩大跨语言筛查覆盖，E正确。

A项错误

声称可以覆盖“所有”来源且“无需人工审查”，范围过大。教材要求在自动化效率与人工监督之间保持平衡，人工分析师仍须审查和验证警报P452。

C项错误

“立即识别文章背后的意图”超出教材所述能力。AI仍存在幻觉、偏差和可解释性不足，不能把模式分析等同于对作者主观意图的确定判断P385。

易错提醒

AI可以扩大覆盖、提高一致性并辅助比较新旧信息，但不能保证穷尽所有来源，也不能取消人工复核。题目中的“所有”“无需”“立即识别意图”等绝对措辞是关键排除点。

 

10. 在金融机构(FI)实施客户筛查系统以检测可能存在的制裁规避行为时,应考虑以下哪些要求以确保有效的名单管理？(选择两项.) ( )

A. 只有特定人员才应被允许修改这些名单。

B. 仅应使用监管名单，包括外国资产控制办公室（OFAC）和欧盟的名单。

C. 名单可以在内部创建，也可以从供应商处购买。

D. 所有名单都应在所有司法管辖区用于筛查。

答案:A、C

解析：

考点

名单管理要求：修改权限控制与名单创建/采购途径

核心解析

有效名单管理要求金融机构对名单的修改实行审批控制，确保仅适当人员有权修改P423。同时，名单来源可以灵活组合：机构可自行维护内部灰名单，包含自身识别的金融犯罪风险对象P422，也可从第三方供应商处获取筛查名单P472。题干问检测制裁规避时的名单管理要求，选项A直接匹配修改权限控制这一治理措施，选项C直接匹配名单内部创建或外部采购的实践，二者均符合教材对有效名单管理的描述。

教材原句

"They should also establish an approval process and ensure that only appropriate individuals can make changes to the lists."

B项错误

金融机构除监管名单外还可维护内部灰名单P422，并从第三方获取筛查名单P472，因此不应仅使用监管名单。

D项错误

选用哪些名单应结合地理位置、交易币种、业务模式、客户所在地和活动等因素P419，而非在所有司法管辖区不加区别地使用全部名单。

易错提醒

名单管理并非仅依赖监管名单，金融机构通常会维护内部灰名单P422并采购外部筛选名单P472。同时，名单的选用需结合地理位置、交易币种等因素P419，不能在所有辖区统一使用全部名单。

 

11. 在反洗钱/打击恐怖主义融资(AML/CFT)合规工作中,实施可解析的人工智能(AI)或机器学习(ML)技术以提高运营效率的主要优势有哪些？(选择两项.) ( )

A. 能够在无需人工干预的情况下识别洗钱/恐怖融资风险

B. 减少对人力资源的需求

C. 更快、更准确地处理和分析大量数据集

D. 提高审计性、问责制和整体治理水平

答案:C、D

解析：

考点

区分'提升有效性'与'减少人工干预'在AI/ML优势中的不同定位

核心解析

FATF指出，AI/ML等技术可通过更快、更准确地处理和分析大量数据，增强风险评估与合规流程，同时提升可审计性、问责制和整体治理能力P408、P426。具备可解释性的AI/ML既能提高大规模数据处理的速度和准确性（C），也有助于保留清晰的决策依据、加强审计和治理（D）。这些优势并不意味着完全取消人工判断和监督。

A项错误

AI工具可以自动分析交易并减少员工负担，但可解释的模型仍需要人工治理、复核和监督。“无需人工干预”把自动化程度说得过于绝对。

B项错误

AI/ML可以减少不必要的人工审查和运营压力，但其主要优势是可扩展性、处理速度、模式识别和分析准确性，而不是笼统地减少人力资源需求。

 

12. 以下哪些是使用搜索引擎进行负面媒体报道搜索的局限性？(选择三项.) ( )

A. 搜索引擎在全球语言覆盖方面存在局限性

B. 搜索引擎提供的非结构化数据使媒体分析变得复杂

C. 搜索结果在识别相关负面媒体报道方面往往效率低下

D. 这个过程耗时且需要大量的人工投入.

E. 由于搜索引擎算法的不同,结果可能会不一致

答案:B、D、E

解析：

考点

识别搜索引擎负面媒体筛查的结构化、效率和一致性局限。

核心解析

搜索引擎返回的网页内容通常是非结构化数据，需要额外清洗和筛选P467，因此整个筛查过程耗时且依赖大量人工投入；不同搜索引擎的算法、个性化设置和索引覆盖还可能导致检索结果不一致。B、D、E分别对应非结构化数据、人工处理耗时和结果不一致三类局限。

A项错误

语言和司法管辖区边界确实会增加总体筛查复杂性，但题干问的是搜索引擎本身的主要局限，教材更直接支持B、D、E。

C项错误

该项把问题归结为搜索结果本身识别相关负面媒体的效率低；教材更直接支持的是非结构化结果需要人工处理，进而使整个筛查流程耗时。两者侧重点不同。

易错提醒

把“搜索结果难分析”“人工投入大”“同一查询结果不一致”与一般的跨语言数据治理问题区分开。
