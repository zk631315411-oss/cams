# v7_q_000342

教材章节：未映射

题型：multiple

题干：反洗钱/打击资助恐怖主义（AML/CFT）新技术实施过程中面临的挑战包括：（选择四项。）

英文题干：Challenges in the implementation of new technologies for AML/CFT include: (Select four.)

选项：

- A. 数据隐私。
  English: Data privacy.
- B. 增强型尽职调查（EDD）政策。
  English: Enhanced due diligence (EDD) policies.
- C. 旅行规则。
  English: The Travel Rule.
- D. 数据质量。
  English: Data quality.
- E. 复杂性。
  English: Complexity.
- F. 监管的。
  English: Regulatory.

答案：A、D、E、F

解析：

考点：识别技术实施中与数据、系统及制度相关的四类挑战

核心解析：教材在介绍KYC技术时直接点出，这些技术在身份验证和安全方面的应用虽然提升了效率，但本身存在“复杂性（complexity）、长期增长的可扩展性问题以及高昂的实施成本”等缺点，同时“在实施这些技术的过程中确保数据隐私是另一项重大挑战”（P410）。此外，在机构决定是否将系统迁移到新技术栈时，教材将“实施复杂性、数据质量以及更广泛的组织准备度”列为需要评估的关键成功因素（P384）。将这些表述与题干对照：A项“数据隐私”和E项“复杂性”与P410原文直接对应；D项“数据质量”与P384原文直接对应。F项“监管的”虽然在这两个直接证据中未被列为同一层级的并列项，但教材在论述交易监控系统调优时，将“确保监管合规”作为调优需要达成的核心目标之一（P331），并明确监管者负有通过许可、注册及风险为本的监督来确保受监管实体合规的职责（P228）。实施新技术必然要把满足这类监管要求纳入考量，因此监管挑战可合理推断为与数据隐私、数据质量、复杂性同属实施新技术所面临的挑战范畴。题干要求选择四项，这四项在教材关于技术选择与实施的相关陈述中均有支撑。
教材原句："these technologies come with some disadvantages, including complexity, scalability issues for long-term growth, and high implementation costs. Ensuring data privacy while implementing these technologies is another major challenge."

B项错误：增强型尽职调查（EDD）是高风险管理情境下，在客户关系存续期间（如开户后判定为高风险客户或提交可疑交易报告后）需要额外执行的一系列强化措施（P311、P356），本身属于反洗钱政策和程序的组成部分，而非实施新技术过程中派生的挑战。题干问的是技术实施的挑战，EDD更接近技术应用后需要承载的业务要求，两者属于不同维度。
C项错误：在候选材料中，“旅行规则”一词出现在关于地理定位技术加强风险报警并侦测不可能旅行模式的论述里（P396），其指向的是利用技术检测异常地理行为的应用场景，而不是技术实施自身的阻碍因素。换句话说，应对旅行规则是技术要辅助达成的目标之一，不构成实施技术时面临的困难本身。
