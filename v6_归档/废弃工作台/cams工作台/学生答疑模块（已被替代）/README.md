## 旧版模块做什么

旧版流程相对简单：

```text
整段粘贴
→ 解析输入
→ 匹配题目
→ 直接召回教材证据
→ 生成答疑草稿
→ 简单校验并保存
```

它主要验证了学生答疑模块的基本可行性：

- 可以整段粘贴学生问题。
- 可以尝试匹配题目。
- 可以召回教材原文。
- 可以生成答疑草稿。
- 可以保存历史草稿。

## 为什么被替代

新版 `学生答疑模块_agentic` 增加了更完整的流程：

```text
整段粘贴
→ 解析输入并判断类型
→ 自由回答 / 识别学生卡点
→ claim planner 拆出需要查证的主张
→ 多路召回教材原文
→ evidence judge 判断证据是否可用
→ 生成答疑草稿
→ reply reviewer 二次审查
→ 默认依据选择器
→ 保存历史答疑
```

相比旧版，新版更适合：

- 纯提问。
- 题目不完整。
- 学生卡点表达不清。
- 需要审查教材依据是否真的支撑回复。
- 需要默认显示 3 条依据，同时保留更多依据可展开。
