# v7_q_000158

教材章节：未映射

题型：single

题干：对于金融机构的高级管理层而言,哪项关键指标能为其提供有关反洗钱控制措施有效性的最有价值的数据？

英文题干：Which key metric provides senior management with information about the effectiveness of its AML controls?

选项：

- A. 自动监测系统生成的真阳性与假阳性之比
  English: The ratio of true positives to false positives generated by the automated monitoring system
- B. 监测名单筛查系统生成的洗钱警报数量
  English: The number of money laundering alerts generated by the watchlist screening system
- C. 每月新引入的高风险客户数量
  English: The number of high-risk customers onboarded each month
- D. 因商业原因退出的客户数量
  English: The number of clients exited for commercial reasons

答案：A

解析：

考点：区分关键绩效指标与关键风险指标的评价维度

核心解析：题干问的是衡量反洗钱「控制措施有效性」的指标。教材将这类指标划入关键绩效指标的范畴，定义为衡量金融犯罪防控控制有效性的量化标准，具体包括可疑活动报告提交时限、筛查误报率降低情况等（P296）。「真阳性与假阳性之比」这个指标，本质就是看监测系统抓准了多少、误报了多少——抓准的比例高、误报的比例低，就意味着识别可疑交易的系统更精准、更有效，直接落在上述定义范围内。相比之下，警报数量、新引入高风险客户数、商业原因退出的客户数，或者描述风险敞口，或者指向外部商业决策，并不直接回应「控制措施本身好不好用」这一问。
教材原句："Key performance indicators (KPI) are measures of AFC control effectiveness, such as SAR filing timelines, false positive reduction rates in screening, and alert resolution times."

B项错误：警报数量描述的是系统触发了多少警报信号，教材虽然把它列为监控校准中的一项关键指标（P446），但它反映的是触发量的大小，与「控制措施是否精准有效」的匹配度不如能同时衡量命中与误报的比率来得直接。题干更匹配直接评价有效性的关键绩效指标，而非单纯的警报产量。
C项错误：每月新引入的高风险客户数量反映的是风险敞口的流入情况，在教材框架中属于评估金融犯罪防控风险的关键风险指标（P296），侧重衡量风险本身，题干要求的却是对控制措施有效性的评价，在衡量维度上不如真阳性与假阳性之比更吻合。
D项错误：题干未提及客户退出的原因为合规相关，选项明确限定为「因商业原因退出」，与反洗钱控制措施的有效性没有直接关联。教材中提及因合规原因退出的客户名单（P466）或欺诈终止关系（P422）均为与金融犯罪风险相关的情形，与商业原因属于不同范畴。

易错提醒：关键风险指标衡量的是风险敞口（如可疑交易量、高风险客户数），回答「有多险」；关键绩效指标衡量的是控制措施的成效（如误报率、报告时限），回答「管得怎么样」。题目问的是「有效性」，匹配的是关键绩效指标。
