# v7_q_000001

教材章节：未映射

题型：single

题干：一名反洗钱合规官收到了一份独立审计报告，其中包含若干发现。对这份报告的恰当回应应包括:

英文题干：An AML compliance officer receives an independent audit report with a number of findings. An appropriate response to the report would include:

选项：

- A. 为审计团队起草详细的行动计划，以落实整改意见
  English: Drafting detailed action plans for the audit team to execute to close the findings
- B. 重新对审计发现中提及的控制措施进行测试，以确认审计结果
  English: Reperforming the testing for the controls mentioned in the findings to confirm the results of the audit
- C. 根据调查结果的根本原因分析来确定补救措施
  English: Defining remedial actions based on the findings' root cause analysis
- D. 将审查行动计划的责任分配给董事会
  English: Assigning responsibility for reviewing the action plan to the board of directors

答案：C

解析：

考点：审计发现后应根据根本原因分析确定补救措施

核心解析：组织识别控制缺陷后，必须分析并纠正错误的根本原因以避免再次发生（P279）。同时，教材指出在审计结束后，公开分享审计发现有助于识别控制缺口，从而进行更好的分析和制定补救策略（P259）。题干中反洗钱合规官收到了包含若干发现的独立审计报告，恰当回应自然是基于这些发现的根本原因分析来定义补救措施，这直接吻合教材对审计后续行动的核心要求：从根源上入手，而非简单重测或直接给审计团队派活。
教材原句："The organization must analyze and correct the root cause of the error to avoid recurrence."

A项错误：教材指出审计后应由反洗钱合规团队（AML compliance team）根据讨论的建议制定并优先实施行动计划（P258），而非为审计团队起草行动计划去执行整改。内部审计作为第三道防线不负责落地整改，因此题干情形更匹配C选项的根本原因分析与补救，而不是由合规官反过来给审计团队派任务。
B项错误：重新测试控制措施相当于对审计结果进行复核验证，这更接近审计或质量保证职能的职责，而非反洗钱合规官在接到审计报告后的首要行动。教材在审计发现后的流程中强调的是分析发现、识别控制缺口并进行补救（P259、P279），相比之下C选项的原因分析与补救更贴合题干所描述的「对报告的恰当回应」。
D项错误：董事会对合规计划承担最终责任（P264），并负责批准风险偏好和监督框架，但这并不等同于将「审查行动计划」的具体责任直接分配给董事会。教材在描述行动计划时强调应明确业务负责人、运营负责人等（P280），更偏向管理层和合规团队的日常治理，不如C选项那样直接对应审计发现后的标准补救流程。

易错提醒：容易误以为审计报告出来后应该由合规官给审计团队写行动计划让审计人员去执行整改。实际上，教材明确说审计后的行动计划由反洗钱合规团队制定并实施改进（P258），审计团队负责独立评价，不负责落实整改。合规官的正确回应是根据审计发现进行根本原因分析，再确定由自己团队主导的补救措施。
