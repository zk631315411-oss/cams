# v7_q_000015

教材章节：未映射

题型：single

题干：一个强大的交易监控系统应具备以下能力:

英文题干：A robust transaction monitoring system includes the capability to:

选项：

- A. 监控交易并识别可能表明可疑活动的异常情况
  English: Monitor transactions and identify anomalies that might indicate suspicious activity
- B. 自动翻译文档
  English: Automatically translate documents
- C. 整合社交媒体资料
  English: Integrate social media profiles
- D. 提交可疑活动报告(SAR)、货币交易报告(CTR)及其他监管报告
  English: File Suspicious Activity Reports (SARs), Currency Transaction Reports (CTRs), and other regulatory reports

答案：A

解析：

考点：交易监控系统的核心功能定义

核心解析：交易监控系统用于分析交易模式并检测异常（P51），其职能是监控可疑交易活动、审查警报并确保跟进（P254）。因此，系统本身的核心能力是「监控交易并识别可能表明可疑活动的异常情况」。选项A直接匹配这一定义。
教材原句："corporate banking transactions will require a relatively robust transaction monitoring system that can analyze patterns and detect anomalies in a more effective manner."

B项错误：教材中未见交易监控系统包含自动翻译文档的功能，仅在P408提及AI工具可验证文档真实性，而非翻译。该能力与交易监控的定义无关。
C项错误：教材指出社交媒体资料可作为外部信息源用于调查（P338），但它属于调查环节的辅助手段，而非交易监控系统本身具备的能力。题干更直接支持A所描述的系统核心功能。
D项错误：教材将提交SAR和CTR列为独立的「监管报告与联络职能」（P251），与交易监控系统分属不同环节。监控系统负责检测和生成警报，报告提交属于后续步骤，不如A更吻合交易监控本身的能力定义。

易错提醒：区分交易监控与报告提交：交易监控负责检测可疑活动并生成警报，而提交SAR/CTR属于监管报告职能（P251）。
