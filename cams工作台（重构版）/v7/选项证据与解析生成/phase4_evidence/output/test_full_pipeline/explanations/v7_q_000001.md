# v7_q_000001

教材章节：未映射

题型：single

题干：一名反洗钱合规官收到了一份独立审计报告，其中包含若干发现。对这份报告的恰当回应应包括:

英文题干：An AML compliance officer receives an independent audit report with a number of findings. An appropriate response to the report would include:

选项：

- A. 为审计团队起草详细的行动计划，以落实整改意见
  English: Drafting detailed action plans for the audit team to execute to close the findings
- B. 重新对审计发现中提及的控制措施进行测试，以确认审计结果
  English: Reperforming the testing for the controls mentioned in the findings to confirm the results of the audit
- C. 根据调查结果的根本原因分析来确定补救措施
  English: Defining remedial actions based on the findings' root cause analysis
- D. 将审查行动计划的责任分配给董事会
  English: Assigning responsibility for reviewing the action plan to the board of directors

## 【AI答案】

C

## 【考点】

审计发现后纠正措施应基于根本原因分析

## 【核心解析】

P279规定：组织必须分析并纠正错误的根本原因以避免再次发生（「The organization must analyze and correct the root cause of the error to avoid recurrence.」）。P299同时强调应制定纠正行动计划并加强金融犯罪防控框架，防止问题重复出现。题干中，反洗钱合规官收到包含若干发现的独立审计报告，恰当的回应首先应进行根本原因分析，再据此确定补救措施，这正是选项C表达的内容。其他选项虽有行动，但都跳过了这一根本分析环节，不如C直接契合教材对审计发现处置路径的要求。

教材原句："The organization must analyze and correct the root cause of the error to avoid recurrence."

## 【错误项分析】

- **A 错误（教材直接依据）｜主体或阶段错配**：为审计团队起草行动计划混淆了审计方与被审计方的角色；内部审计作为独立评估职能不应直接执行整改行动，教材P258描述审计后由反洗钱合规团队实施改进。相比之下，C更直接匹配教材对审计发现处置的根本原因分析要求。
- **B 错误（题干对照）｜题干要素不匹配**：重新测试控制措施以确认审计结果倾向于质疑审计结论，而非着手纠正；教材P251指出合规测试职能负责QA审查并建议纠正措施，而非复验审计发现本身。题干场景更支持基于审计发现制定补救措施，而非返回去验证审计工作。
- **D 错误（题干对照）｜主体或阶段错配**：董事会负责最终问责和战略方向（P260），但行动计划审查这类具体运营职责通常由管理层承担，不应直接分配给董事会。合规官面对审计报告，更直接的任务是分析根本原因并推出补救措施，而非调整董事会职责。

## 【易错提醒】

常见误区：收到审计发现后直接起草行动计划，跳过了根本原因分析。教材强调必须先分析并纠正根本原因（P279），再制定有针对性的补救措施，这样才能防止问题复发，而非仅就发现本身打补丁。
