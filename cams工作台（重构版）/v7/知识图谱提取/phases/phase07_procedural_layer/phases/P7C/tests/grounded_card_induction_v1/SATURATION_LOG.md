# Saturation Log

## 判定口径

本轮把“信息增加”限定为以下任一情况：

```text
出现新的入口一级类型
出现新的处理一级类型
出现新的出口一级类型
出现此前没有的入口—处理—出口关系
出现改变成卡/不成卡边界的反例
```

措辞变化、业务名词变化、同一类型的新例子和节点数量变化不计为一级新增。

停止规则：首批 10 个 section 后继续理论抽样；连续 3 个 section 无一级新增时停止。
