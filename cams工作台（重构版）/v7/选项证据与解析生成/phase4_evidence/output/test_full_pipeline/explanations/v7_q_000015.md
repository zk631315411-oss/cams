# v7_q_000015

题型：single

题干：一个强大的交易监控系统应具备以下能力:

英文题干：A robust transaction monitoring system includes the capability to:

选项：

- A. 监控交易并识别可能表明可疑活动的异常情况
  English: Monitor transactions and identify anomalies that might indicate suspicious activity
- B. 自动翻译文档
  English: Automatically translate documents
- C. 整合社交媒体资料
  English: Integrate social media profiles
- D. 提交可疑活动报告(SAR)、货币交易报告(CTR)及其他监管报告
  English: File Suspicious Activity Reports (SARs), Currency Transaction Reports (CTRs), and other regulatory reports

## 【AI答案】

A

## 【考点】

区分交易监控系统的核心功能与辅助功能或后续流程

## 【核心解析】

交易监控系统是帮助金融机构检测可疑交易模式的技术框架（P325），其核心任务是在开户后持续观察客户交易，以识别可能表明洗钱等金融犯罪的异常或非法活动（P329）。题干问的是「强大的交易监控系统应具备什么能力」，正确选项 A 描述的正是这个系统的本职——监控交易并在海量数据中识别出那些偏离正常、可能指向可疑活动的异常情况。选项A本质上是该系统的功能定义本身，因此最直接的匹配。

教材原句："Transaction monitoring (TM) systems are the technological frameworks that help financial institutions detect suspicious transaction patterns."

## 【错误项分析】

- **B 错误（教材定义应用）｜概念混淆**：教材提到AI工具可在准入环节核实文档真实性（P408），但这是身份验证环节的自动核验功能，并非交易监控系统本身的责任。题干讨论的交易监控能力不覆盖文档翻译。
- **C 错误（教材定义应用）｜主体或阶段错配**：教材将社交媒体资料归入「外部信息」来源，在调查阶段为分析师提供客户背景（P338）。这是分析师在收到警报后进行深入调查时可能参考的辅助数据，而非交易监控系统运行时应具备的核心能力。
- **D 错误（教材定义应用）｜主体或阶段错配**：教材明确将提交可疑活动报告（SAR）和货币交易报告（CTR）分配给「监管报告与联络职能」（P251），这是随后才需履行的独立步骤。交易监控系统产出警报，但提交报告职能归属于反洗钱合规的第二道防线中的另一个职能，不属于监控系统本身的定义范围。

## 【易错提醒】

容易将交易监控、文件审核与监管报告三个不同领域的职能混淆。记住区分主线：监控系统负责发现异常；准入环节的工具负责验证身份文档；第二道防线的职能负责向监管机构提交报告（P251）。
