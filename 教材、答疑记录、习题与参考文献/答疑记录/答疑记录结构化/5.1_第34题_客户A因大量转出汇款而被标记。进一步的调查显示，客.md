# 第五章 5.1 第34题 客户A因大量转出汇款而被标记。进一步的调查显示，客户A在一个与人口贩运有关的网络中可能扮演着关键角色。在提交了可疑活动报告后，调查员接下来应该采取什么措施?

## 题目
客户A因大量转出汇款而被标记。进一步的调查显示，客户A在一个与人口贩运有关的网络中可能扮演着关键角色。在提交了可疑活动报告后，调查员接下来应该采取什么措施?

## 选项
- A 为高级管理层准备一份摘要，建议客户销户
- B 将客户的情况告知当地其他金融机构，以便他们能够停止潜在的服务
- C 与联邦调查局（FBI）联系，传达调查结论
- D 在执法部门逮捕之前，限制或阻止客户的账户

## 答案
答案：A

## 学生提出的问题
为什么选a?

## 教研的回答
核心依据：文档在多个案例和要点中强调了内部报告流程和高级管理层审批在处理高风险客户
（尤其是涉及严重犯罪的客户）时的核心地位。
1. 问题本质的再理解
问题的关键在于“在提交了可疑活动报告后，调查员接下来应该采取什么措施？”
“提交可疑活动报告”是履行了对金融情报机构的法定义务。之后，金融机构需要启动内部
风险管理程序。
2. 文档中的直接证据
文档通过多个案例明确指出，涉及高风险客户的重大决策（如销户）必须由高级管理层批准：
在“要点”部分强调：“高级管理层的支持，是合规专员有效履职的必要条件。”
在多个案例（如德意志银行、巴克莱银行案例）中，问题都出在合规人员的建议未能得到高
级管理层的及时响应和支持。
文档明确指出，在调查后，“组织应考虑以下重要因素：...销户的法律依据；组织关于销户所
规定的政策和程序...”。这表明销户是一个需要依据内部政策和程序进行的正式决策过程。
3. 为何A是正确步骤
合规流程：调查员的职责是调查和报告。提出“销户”这种重大决策的建议，需要形成正式
报告（摘要）上报给拥有决策权的高级管理层。这是内部控制的必然要求。
1.
风险控制：立即单方面限制账户（选项D）可能会惊动犯罪分子，影响执法部门的后续调查。
正确的做法是先将风险评估和建议上报，由高级管理层统筹决策，并可能在必要时与执法部门
协调行动。
2.

权责分明：调查员无权直接决定销户或限制账户。他的职责是完成调查后，提出专业建议供
管理层决策。选项A准确地描述了这个承上启下的关键步骤。

4. 为何D不是首选
选项D“在执法部门逮捕之前，限制或阻止客户的账户”是一个可能的最终行动，但这个行动
通常需要基于高级管理层的决策和可能的法律建议。在流程上，它应该发生在选项A（建议）
被批准之后。调查员直接执行D，越过了必要的审批环节。
正确顺序：标准的流程是：调查 -> 提交可疑活动报告 -> 向高级管理层提交摘要和建议 -> 管
理层决策（可能包括下令限制账户或销户）。
因为在提交SAR后，调查员的下一步应是内部升级处理，包括向高级管理层报告并建议是否终止客户
关系。不得泄露信息、干扰调查或擅自采取外部行动。

能包括下令限制账户或销户）。
【为什么不选D？】
选项D“在执法部门逮捕之前，限制或阻止客户的账户”是一个可能的最终行动，但这个行动通常需要
基于高级管理层的决策和可能的法律建议。在流程上，它应该发生在选项A（建议）被批准之后。调查
员直接执行D，越过了必要的审批环节。
通知销户不会有tipping-off嫌疑吗？
SAR提交后，银行绝对不能通知客户、其他金融机构或执法部门（除非执法主动联系），也不能限
制或冻结客户账户，因为这些行为可能构成SAR泄密或非法干预客户资产。调查员的职责是调
查、记录并提出建议，而不是直接采取账户措施；因此下一步必须将调查发现、风险评估和处理
建议（如是否销户）整理成摘要，上报给拥有决策权的高级管理层，由管理层根据风险、商业和
政策因素决定是否终止关系。银行即使最终选择销户，也必须以“风险或商业原因”作为理由，
而不能暗示与SAR有关，因此不会违反 SAR 保密义务；相反，如果调查员在未获批准的情况下限
制账户，不仅越权，还可能因时机敏感而被客户察觉，从而构成泄密风险。
