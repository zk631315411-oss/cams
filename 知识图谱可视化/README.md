# V6 知识图谱可视化归档

本目录是基于 V6 `cards_v6_sentence.json` 和旧 KG 生成的 Obsidian 可视化，保留用于历史展示，不是 V7 正式知识图谱。

V7 正式 KG 位于 `cams工作台（重构版）/v7/知识图谱提取/phases/phase06_kg_views/outputs/`，当前口径为 59 章、983 个 core point、4,973 个 unit 和 8,632 条边。

打开历史库时使用 `obsidian/` 目录；其中的 `.obsidian/` 是库级配置。顶层 `.obsidian/` 仅按当前本地状态保留，不作为正式配置入口。
