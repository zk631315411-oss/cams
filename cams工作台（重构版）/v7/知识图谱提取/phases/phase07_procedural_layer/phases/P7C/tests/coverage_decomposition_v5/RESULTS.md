# P7C Coverage Decomposition Controlled Iteration Results

## Outcome

The decomposition hypothesis is supported, but no tested variant is ready for production promotion without one deterministic routing change.

The stable architecture is:

1. Initial P7C extraction.
2. Proposition-level Coverage Audit without graph construction.
3. Patch builder restricted to missing and partially covered P7C claims.
4. Deterministic Patch contract and unresolved routing.
5. P7D structure and edge-level semantic review.

## Iterations

| Iteration | Changed variable | Development result |
|---|---|---|
| v1 | Split one-call Coverage into Audit and Patch | Rejected: KG over-classification and 2 contract failures |
| v2 | Hard P7 eligibility gate in Audit | Rejected: Audit found targets, but Patch added 7 rejected edges |
| v3 | Qualifier/source/independent-result Patch prompt | Rejected: 3 accepted, 5 pending, 3 rejected new edges; unknown relation type blocked CH06 |

## What Is Solved

- Audit detects the four known gap classes at proposition level.
- CH03-S02 investigative obstruction and CH05-S04 general control effects remain KG-only.
- CH12 monitoring, predefined-standard reference, and qualified CDD results can become accepted edges.
- CH47 scenario-setting REFERENCES historical experience becomes an accepted minimal open relation.
- The strict contract blocks unknown relation types and edge evidence that does not cover both endpoints.

## Remaining Boundaries

- CH02 investigation/evidence to tentative conclusion does not map cleanly onto the current process-to-exit graph without inventing an assessment source. Its atomic facts remain in KG; the directed proof path should stay unresolved unless the schema policy changes.
- CH06 calculation-to-classification is a valid P7C claim, but the model repeatedly supplements a mixed existing card. A deterministic dedicated-card route is more reliable than another prompt-only iteration.
- Patch contract failures currently fail a section. Production integration should instead preserve the Audit claim in an unresolved queue and leave the original graph unchanged.

## Promotion Decision

Do not promote a prompt file alone. Promote the decomposed workflow only together with deterministic unresolved routing and claim-level provenance. Holdout testing is still required after that integration.
