# v7_q_000152

教材章节：未映射

题型：single

题干：在姓名筛查的背景下, 模糊逻辑或模糊匹配是一种方法,其:

英文题干：In the context of name screening, fuzzy logic or fuzzy matching is a method that:

选项：

- A. 利用机器学习根据历史数据预测名称
  English: Uses machine learning to predict names based on historical data
- B. 将筛查名单上的姓名与拼写、模式或发音相似的姓名进行匹配
  English: Matches names on screening lists to names with similar spellings, patterns, or sounds
- C. 将长度相同且字符相同的名称进行匹配
  English: Matches names with the same length and characters
- D. 仅依赖于精确的字符串匹配
  English: Relies exclusively on exact string matches

答案：B

解析：

考点：识别姓名筛查中模糊逻辑匹配的定义

核心解析：模糊逻辑匹配使用算法匹配相似但不完全相同的名称，处理拼写、打字错误和翻译差异（P416）。题干问姓名筛查背景下模糊逻辑是什么方法，关键属性是「处理名称相似但不完全相同的情况」。选项B「将筛查名单上的姓名与拼写、模式或发音相似的姓名进行匹配」直接覆盖了教材对模糊逻辑的核心定义，故成立。
教材原句："Fuzzy logic matching uses algorithms to match names that are similar but not identical, accounting for variations in spelling, typos, and translations."

A项错误：机器学习利用历史数据预测并持续学习（P417），与模糊逻辑聚焦特定名称集进行相似匹配不同。题干明确问模糊逻辑，选项A描述的是另一种技术，不如B直接吻合模糊逻辑的定义。
C项错误：将长度相同且字符相同的名称进行匹配实质上是要求严格的结构一致，而模糊逻辑设计的目的正是克服名称在拼写、长度、字符排列上的差异（如「John Smith」与「Jon Smith」仍被视为潜在匹配）。选项C接近精确匹配，与模糊逻辑的灵活性方向相反。
D项错误：教材指出仅靠精确名称匹配极具挑战性（P420），模糊逻辑正是为弥补精确匹配的不足而引入，可匹配拼写错误、不完整名称及发音近似的名称。选项D描述的方法更接近确定性匹配，与模糊逻辑的目的相悖。

易错提醒：模糊逻辑与机器学习的核心区分在于：模糊逻辑聚焦特定名称的相似匹配，处理拼写变体和翻译差异；机器学习则通过历史数据学习并持续改进，可处理更广泛的数据模式（P417）。若题干强调「从历史数据中预测」或「持续学习」，则指向机器学习而非模糊逻辑。
