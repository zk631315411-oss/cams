# v7_q_000198

教材章节：未映射

题型：single

题干：一家银行注意到由于缺乏标准化的支付消息格式,区块链交易的标记存在不一致的情况.在交易筛查工具中,应优先考虑哪项功能来解决此问题？

英文题干：A bank notices inconsistent tagging of blockchain transactions due to the lack of standardized payment message formats. Which functionality should be prioritized in the transaction screening tool to address this issue?

选项：

- A. 对传统支付信息加强制裁筛查
  English: Enhanced sanctions screening of traditional payment messages
- B. 定期人工审查与区块链相关的交易
  English: Periodic manual review of blockchain-related transactions
- C. 与区块链分析提供商的集成
  English: Integration with blockchain analytics providers
- D. 基于规则的系统仅关注已知的钱包地址
  English: Rule-based systems that focus only on known wallet addresses

答案：C

解析：

考点：区块链分析工具的聚类功能解决交易标记不一致

核心解析：区块链分析工具通常内置聚类功能，可将多个地址归入同一钱包，揭示不同地址是否属于同一实体（P486-487）。题干中，因缺乏标准化的支付消息格式，区块链交易的标记出现不一致，而这些不一致的地址标记很可能指向同一钱包或同一实体。集成区块链分析提供商后，其聚类功能能自动识别并归并这些地址，统一标记，从而从根本上解决标记不一致的问题。

A项错误：题干涉及的是区块链交易，而非传统支付信息。教材指出数字资产交易筛查需结合链上数据和链下情报（P434），但并未提及加强传统支付信息筛查能解决区块链交易标记不一致。选项A与题干主体错位，匹配度远不如C。
B项错误：数字资产交易的假名性质使得所有权验证具有挑战性，其复杂性需要高级分析和区块链取证来提高透明度（P435）。定期人工审查在效率和准确性上均无法解决标记不一致这一技术问题，不如集成区块链分析提供商直接、有效。
D项错误：基于规则的模型可用于筛查虚拟资产地址与制裁名单（P417），但仅关注已知钱包地址无法处理因标记不一致而出现的新的或未识别的地址。集成区块链分析提供商通过聚类功能统一标记，比规则系统更匹配题干的问题情境。

易错提醒：容易将标记不一致问题当作普通制裁筛查来做，错选A或D。实际上，区块链交易的标记不一致源于地址归属不明，教材指出区块链分析工具通过聚类将多个地址归入同一钱包（P487），从而自动统一标记，这是传统规则系统和仅查看已知地址所做不到的。
