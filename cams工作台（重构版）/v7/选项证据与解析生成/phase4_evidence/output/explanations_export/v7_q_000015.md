# v7_q_000015

教材章节：未映射

题型：single

题干：一个强大的交易监控系统应具备以下能力:

英文题干：A robust transaction monitoring system includes the capability to:

选项：

- A. 监控交易并识别可能表明可疑活动的异常情况
  English: Monitor transactions and identify anomalies that might indicate suspicious activity
- B. 自动翻译文档
  English: Automatically translate documents
- C. 整合社交媒体资料
  English: Integrate social media profiles
- D. 提交可疑活动报告(SAR)、货币交易报告(CTR)及其他监管报告
  English: File Suspicious Activity Reports (SARs), Currency Transaction Reports (CTRs), and other regulatory reports

答案：A

解析：

考点：交易监控系统的核心功能定义

核心解析：交易监控系统是帮助金融机构检测可疑交易模式的技术框架（P325）。题干问一个强大的交易监控系统应具备什么能力，核心落脚在「系统」本身的功能。选项A「监控交易并识别可能表明可疑活动的异常情况」直接对应了这一技术框架的核心目的：接收交易数据、分析模式、标记异常。教材进一步指出，企业银行业务需要强大的交易监控系统以有效分析模式并检测异常（P51），以及调优的目的正是确保交易监控系统有效检测可疑活动（P331）。这些证据共同指向一个结论：交易监控系统最底层的固有功能就是监控与识别异常，这正是选项A所描述的内容。
教材原句："Transaction monitoring (TM) systems are the technological frameworks that help financial institutions detect suspicious transaction patterns."

B项错误：「自动翻译文档」在任何教材段落中均未与交易监控系统的能力相关联。交易监控系统处理的是交易的结构化数据（金额、频率、对手方等），而非非结构化的文档内容翻译。该选项缺乏教材依据。
C项错误：社交媒体资料在教材中被定位为调查阶段可参考的外部信息源，可为客户提供额外背景信息（P338），属于交易监控触发警报后、分析师手动审查时可能调用的辅助数据。它并非交易监控系统自身的固有核心能力，而是一个补充性的外部数据维度，与题干对系统基础功能的提问匹配度不如A直接。
D项错误：提交SAR和CTR在教材中被明确定义为「监管报告与联络职能」的职责，该职能负责提交所需监管报告并与监管机构沟通（P251）。调查职能负责准备SAR（P251），但报告的实际提交由独立的报告职能执行。尽管交易监控系统产生的警报可能触发后续的SAR流程，但提交报告本身是一个独立于系统监控的操作步骤，不属于交易监控系统这一技术框架的内在能力。题干问系统能力，相较之下，A的监控识别功能比D的报告提交功能更贴近系统的技术定义。

易错提醒：注意区分「交易监控系统」与「调查/报告职能」：监控系统负责产生警报（识别异常交易模式），而SAR的撰写属于调查职能、SAR的提交属于监管报告职能。教材在第二道防线金融犯罪职能结构中（P251）将交易监控、调查、监管报告并列描述为不同职能模块，选项D虽然与反洗钱流程紧密相关，但它对应的是独立的报告职能而非监控系统本身。
