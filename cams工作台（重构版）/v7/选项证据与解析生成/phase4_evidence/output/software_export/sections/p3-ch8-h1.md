# p3-ch8-h1 题库软件版解析预览

可导出题目数：1

教材章节：未映射

题型：multiple

题干：根据美国金融犯罪执法网络(FinCEN)的规定,银行账户中的哪些警示信号综合起来可能表明存在现代奴役、人口贩运和剥削行为？（选择两项。）


选项：

- A. 来自第三方支付处理商的资金转入，且附带的汇款人信息有限
- B. 与注册虚拟货币交易所进行的交易活动
- C. 向农业流动工人支付大量现金
- D. 频繁支付在线广告或非本地分类广告费用

答案：A、D

解析：

考点：识别**人口贩运**和**现代奴役**相关的**账户交易红旗**。

核心解析：人口贩运资金通常通过**第三方或不完整的汇款人信息**切断追踪链路，A项中的第三方支付处理商和有限汇款人信息符合这一特征（P34）。D项“**频繁支付在线广告或非本地分类广告费用**”可能反映招募、控制或宣传受害者的运营活动；两项分别覆盖**资金进入和运营支出**。C项中的农业工人现金支付可能有合法工资解释，单独出现时不如D项具有贩运特异性。

B项错误：与受监管虚拟货币交易所交易不是人口贩运特有红旗。
C项错误：现金支付农业流动工人可能是正常工资安排，缺少控制、招募或剥削的附加事实。

易错提醒：不要只看到“现金”或“劳工”就判定人口贩运；应寻找隐藏身份、广告招募和第三方资金控制等组合信号（P34）。
