# v7_q_000031

教材章节：未映射

题型：single

题干：在哪个过程中,一个国家必须向金融行动特别工作组(FATF)证明其拥有有效框架以保护金融体系免受滥用？

英文题干：During which process must a country demonstrate to the Financial Action Task Force (FATF) that it has an effective framework to protect the financial system from abuse?

选项：

- A. 正式评估
  English: Formal assessment
- B. 监管概述
  English: Regulatory overview
- C. 技术分析
  English: Technical analysis
- D. 相互评估
  English: Mutual evaluation

## 【AI答案】

D

## 【考点】

识别 FATF 相互评估作为成员国证明反洗钱框架有效性的专门过程

## 【核心解析】

金融行动特别工作组通过「相互评估」（mutual evaluation）来审查各成员辖区是否有效执行其建议。教材明确指出，相互评估要求严格，每个辖区只有在能够向其他 FATF 成员证明其合规时才会被视为合规（P153），且典型的互评估报告会深入分析该辖区防止金融体系被犯罪滥用的法律和监管框架（P153）。题干所述「国家向 FATF 证明其拥有保护金融体系免受滥用的有效框架」，正好落在相互评估这一过程的定义和作用上，因此互评估直接对应该场景。

教材原句："Mutual evaluations are strict, meaning each jurisdiction is only deemed compliant when it can prove the same to other FATF members."

## 【错误项分析】

- **A 错误（题干对照）｜概念混淆**：教材提到 FATF 进行「formal evaluations」以评估辖区实施情况（P144），但这只是对评估活动的泛称。题干所问的特定过程特指「mutual evaluation」，而非笼统的正式评估。相比之下，D 是 FATF 专有的同行评审机制名称，更直接吻合题干要求的证明义务。
- **B 错误（题干对照）｜题干要素不匹配**：教材中出现的「regulatory overview」是指模块对全球规则的概要介绍（P177），而非 FATF 要求成员国证明框架有效性的流程。题干要素（国家需向 FATF 证明）在该选项中完全没有对应，匹配度远低于 D。
- **C 错误（题干对照）｜范围或程度偏差**：教材在描述相互评估的七阶段流程时，将「Technical review」列为其中一个步骤，由评估团队分析辖区法律法规（P154）。它只构成互评估的一部分，而非整个证明框架有效性的过程。题干指向的是完整的证明过程，故 C 的范围过于狭窄，不如 D 全面匹配。

## 【易错提醒】

FATF 的定期评估活动正式名称即「相互评估」（mutual evaluation），由其他司法管辖区的反洗钱/反恐怖融资当局进行同行评审（P146）。「正式评估」只是对这类活动的非专有表述；「技术审查」（Technical review）仅是互评估流程中的一个步骤（P154），不能替代整个过程。看到「国家向 FATF 证明框架有效」应直接锁定 mutual evaluation。
