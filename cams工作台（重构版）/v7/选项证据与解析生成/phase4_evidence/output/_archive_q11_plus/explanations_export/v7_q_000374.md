# v7_q_000374

教材章节：未映射

题型：multiple

题干：在机器学习/深度学习交易监控的背景下，应考虑哪些关键绩效指标(KPI)？(选择三项。)

英文题干：Which key performance indicators (KPIs) should be considered in the context of ML/TF transaction monitoring? (Select Three.)

选项：

- A. 招聘新员工所需天数
  English: Number of days required to hire new staff
- B. 提出审查或报告的警报数量
  English: Number of alerts raised for review or reporting
- C. 各地区警报数量
  English: Number of alerts by region
- D. 顶级客户的交易数量
  English: Number of transactions by top customers
- E. 平均警报审查时间
  English: Average time to review an alert

答案：B、C、E

解析：

考点：区分金融犯罪防控KPI与一般业务或人力资源指标

核心解析：关键绩效指标（KPI）用于衡量金融犯罪防控（AFC）控制的效率与效果（P387），典型的KPI包括警报审查时效、误报率以及可疑活动报告提交时限等（P296）。在机器学习／深度学习交易监控场景下，评估这类系统不仅要看其发现可疑行为的能力，还必须衡量其产生的运营负荷与处理效率。提出审查或报告的警报数量（对应选项B）是交易监控校准的核心指标（P446），直接反映系统对可疑活动的捕获能力；各地区警报数量（对应选项C）通过地理维度揭示风险分布与监控覆盖，可评估系统在不同区域的执行一致性；平均警报审查时间（对应选项E）本身就是P296明确列举的KPI量度，直接体现合规团队的调查效率。三者共同构成对监控系统有效性和运行效率的整体评估，因此是应选取的KPI。
教材原句："Ongoing reporting includes key risk indicators to identify potential vulnerabilities and key performance indicators to measure efficiency and effectiveness in detecting and preventing financial crime."

A项错误：招聘新员工所需天数属于人力资源流程效率指标，教材在讨论AFC内部报告或KPI时均未将其纳入金融犯罪防控有效性的量度（P296、P387），与题干要求的监控系统KPI属性不匹配。
D项错误：顶级客户的交易数量可反映特定客群的业务规模和风险敞口，但教材将KPI界定为对AFC控制本身的效率与效果的衡量（P387），而非对客户交易行为的统计描述，因此它不如B、C、E那样直接吻合教材对AFC的KPI的定义。
