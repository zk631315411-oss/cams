题型：single

题干：有三种类型的因素可用于验证某人的身份:拥有物、知识和固有因素.以下哪个因素属于内在因素？

英文题干：There are three types of factors that can be used to authenticate someone: ownership, knowledge, and inherent factors. Which of the following factors falls under inherent factors?

选项：

- A. 挑战-响应
  English: Challenge-response
- B. 指纹
  English: Fingerprint
- C. 安全令牌
  English: Security token
- D. 密码短语
  English: Passphrase

## 【AI答案】

B

## 【考点】

区分多因素认证中 inherence 与 ownership/knowledge 的类别归属

## 【核心解析】

认证方法分为三类：Ownership（你拥有的东西，如安全令牌）、knowledge（你知道的东西，如密码）、inherence（你本身固有的东西，如指纹）（P410）。题干要求选出属于 inherence（固有因素）的选项。「指纹」是个人固有的生理特征，属于典型的 inherence 范畴。教材在强 MFA 示例中明确将 fingerprint 归入 inherence 类别（P410），因此B项直接匹配题干对固有因素的分类要求。

教材原句："An example of strong MFA would be the combination of a security token, such as a one-time code received on the phone (ownership), a password or answer to a security question (knowledge), and a fingerprint or facial recognition (inherence)."

## 【错误项分析】

- **A 错误（教材定义应用）｜题干要素不匹配**：「挑战-响应」是一种身份验证过程中的交互机制，在教材对三类认证因素的定义和举例中均未出现「挑战-响应」。相比之下，它更接近一种验证协议而非属于「固有因素」这一类别。
- **C 错误（教材直接依据）｜概念混淆**：「安全令牌」在教材强 MFA 示例中明确被归入 ownership（拥有物）类别——收到手机上的一次性验证码就是你持有所属移动设备的证明（P410）。题干问的是 inherence，ownership 虽然也是认证因素之一，但与题干要求不匹配。
- **D 错误（教材直接依据）｜概念混淆**：「密码短语」属于典型的知识类因素（something you know），即用户脑中记忆的信息。教材在强 MFA 示例中将 password 归入 knowledge 类别（P410），与题干要求的 inherence（固有因素）类别不匹配。

## 【易错提醒】

三类认证因素的核心区分标准：Ownership 是你持有的外部物件（手机、令牌、卡片），Knowledge 是你脑中的信息（密码、安全问题答案），Inherence 是你身体本身的特征（指纹、面部、虹膜）。做这一类题只需把选项带入「something I have / something I know / something I am」来快速判断。
