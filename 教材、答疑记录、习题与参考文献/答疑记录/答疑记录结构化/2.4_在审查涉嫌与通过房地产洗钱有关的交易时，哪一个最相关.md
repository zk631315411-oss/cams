# 第二章 2.4 在审查涉嫌与通过房地产洗钱有关的交易时，哪一个最相关?

## 题目
在审查涉嫌与通过房地产洗钱有关的交易时，哪一个最相关?

## 选项
- A. 参与交易的金融机构
- B. 资产的位置
- C. 资产的实际所有人
- D. 用于支付的货币

## 答案
答案：C

## 学生提出的问题
为什么是C？

## 教研的回答
本质上这四个选项都是和房地产洗钱相关的，但是这题关键是判断出最核心的是哪个。
选项D：使用现金还是电汇是洗钱方法的一个特征，但只是一种手段。调查最终要回答的是"钱是谁的"以及"资产是谁的"，而不是"用什么方式支付"。

【C为什么正确？】
因为调查出资产所有人是洗钱最终目的。首先你要理解清楚为什么会有洗钱？一般是洗钱者利用空壳公司、代名人和信托等复杂结构来隐藏"资产的实际所有人"。注意隐藏这个词哈。
房地产洗钱的核心目的是将非法所得转化为表面上合法的资产，并隐匿资产的真实所有权，从而让犯罪分子能够安全地持有和享用这些犯罪收益。因此，调查的关键在于穿透层层伪装，找到最终控制资产的人。

选项分析

| 选项 | 内容分析 | 相关性评估 | 结论 |
|------|---------|-----------|------|
| A. 参与交易的金融机构 | 相关，但不是最核心的。 金融机构是交易的通道，调查可以从这里找到线索（如资金流向），但金融机构本身不是洗钱活动的终极目标。 | ❌ 次要相关 | |
| B. 资产的位置 | 相关，但不是最核心的。 资产位于高风险地区或金融保密天堂可能是一个危险信号，但位置本身并不能直接揭示洗钱行为或犯罪主体。 | ❌ 次要相关 | |
| C. 资产的实际所有人 | 最相关。 这是房地产洗钱调查的终极目标。洗钱者会利用空壳公司、代名人和信托等复杂结构来隐藏"资产的实际所有人"（即受益所有人）。文档中多次强调，识别并核实受益所有人是客户尽职调查和反洗钱调查的核心。例如，在"利用私人投资公司开展私人银行业务"和"法人和法律安排的透明度和受益所有权"等章节都重点论述了这一点。查明实际所有人是追踪犯罪收益、提起没收诉讼的关键。 | ✅ 最相关 | |
| D. 用于支付的货币 | 相关，但不是最核心的。 使用现金还是电汇是洗钱方法的一个特征，但只是一种手段。调查最终要回答的是"钱是谁的"以及"资产是谁的"，而不是"用什么方式支付"。 | ❌ 次要相关 | |

结论与文档依据
文档在多个部分强调了识别"受益所有人"或"实际所有人"在反洗钱斗争中的根本重要性：
金融行动特别工作组的建议中，明确要求采取措施识别和核实受益所有人身份。
"利用私人投资公司开展私人银行业务" 案例指出，空壳公司被用来"掩盖最终受益所有人"。
"房地产" 章节明确指出，洗钱风险包括"客户利用并控制多家法律机构，为其个人和家庭进行财产规划"以及"利用前台公司、空壳公司、信托及其他公司结构，掩饰受益所有人"。
因此，在房地产洗钱调查中，所有其他线索（如通过哪家银行转账、房产在哪个国家、是否用现金支付）最终都是为了服务于一个最高目标：找出隐藏在层层法律安排背后的资产的实际受益人。

最终答案：C
