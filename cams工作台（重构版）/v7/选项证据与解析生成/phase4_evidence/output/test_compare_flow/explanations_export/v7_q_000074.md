# v7_q_000074

教材章节：未映射

题型：single

题干：一名反洗钱分析师正在审查一项警报，需要进一步收集信息以判断风险。以下哪项是最合理的下一步行动？

英文题干：An AML analyst at a financial institution is examining an alert generated by the automated transaction monitoring system to determine whether the alert should be escalated to the AML unit for further investigation or archived as a false positive. Which action might be reasonable for the AML analyst to take?

选项：

- A. 限制客户访问账户
  English: Restrict the client's access to the account
- B. 向负责引发警报账户的关系经理请求信息
  English: Request information from the relationship manager assigned to the account that caused the alert
- C. 进行线下测试，以确保自动化监控系统运行有效
  English: Perform below-the-line testing to ensure the automated monitoring system is operating effectively
- D. 向引发警报的交易所涉及的交易对手银行发送信息请求
  English: Send a request for information to the counterparty bank involved in the transactions that caused the alert

答案：B

解析：

考点：交易监控警报审查中信息收集的合理渠道与先后顺序

核心解析：在交易监控警报审查阶段，分析师在决定是否升级调查之前，必须先充分理解可疑交易的性质，判断是否存在合理解释（P337）。当内部系统和公开来源无法获取所需信息时（P339），关系经理或一线员工是联系客户、合作机构或代理行获取信息的最佳渠道，他们负责客户外联并将调查结果反馈给分析师（P339）。本题中，分析师正在审查一项警报、需要进一步收集信息以判断风险，尚未到升级或处置阶段。此时向负责该账户的关系经理请求信息，是最符合教材流程的下一步行动——关系经理既掌握客户背景，又是教材明确的警报调查信息收集渠道。

A项错误：限制账户访问是分析师在调查后期可能建议的预防措施（P335），属于处置阶段动作而非信息收集手段。题干尚处于审查警报、需进一步收集信息的早期阶段，直接限制账户不如先通过关系经理了解情况更匹配当前需求。
C项错误：线下测试是交易监控系统调优阶段的验证方法，用于检查阈值设置是否合理、识别潜在漏洞（P446），属于系统运维层面。题干场景是分析师审查具体警报、需收集信息做判断，这与测试系统运行有效性分属不同工作流，匹配度不高。
D项错误：信息请求（RFI）是金融机构向代理行或合作机构收集交易细节的正式流程（P338），但题干仅要求进一步收集信息以判断风险，尚未明确是否需启动正式外部请求。相比之下，先向内部关系经理获取信息更符合信息收集的合理顺序——内部信息源更快、流程更轻，且教材将「信息无法内部获取」作为进行客户外联的前提条件之一（P340），直接向交易对手银行发请求不如先通过关系经理渠道更匹配当前阶段。

易错提醒：选项D有较强的迷惑性。此处关键在于教材为信息收集设定了先后顺序：先内部后外部。分析师应先利用内部数据（KYC、交易记录、账户历史等，P337），不足时再通过关系经理联系客户或合作机构（P339）。RFI是正式的机构间流程，通常用于内部和关系经理渠道均无法满足需求时。题干处于「进一步收集信息」的初始阶段，内部渠道优先。
