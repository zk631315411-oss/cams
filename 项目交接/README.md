# CAMS 项目交接说明

## 1. 交接范围

本次交接总结的是从 V6 到 V7 的教材处理、知识单元构建、检索、题目盲判、解析撰写、质量复核与软件导出研发。旧前端、工作台布局实验和审核原型不属于当前正式发布版，只在需要追溯设计过程时参考。

正式工作台应用不在本仓库内，位于本机同级目录 `D:/守正公司工作区/cams考试工作台（正式版）/`。本仓库负责研发过程与内容母版，正式应用负责后续题目档案、教研工作流和不可变发布包。

## 2. 接手顺序

1. 阅读 [V6 到 V7 研发总结](V6到V7研发总结.md)，理解为什么从句卡体系迁移到双语知识单元体系。
2. 阅读 [正式资产与 SOP 索引](正式资产与SOP索引.md)，确认正式输入、生产母版、交付文件和历史资产的边界。
3. 阅读根目录的 `重构版解析生产链路总结SOP.md`，按任务类型选择“新教材新题库”或“现有题库增加新题”。
4. 运行或修改任何生产脚本前，先确认输入快照、输出目录和 Git 差异，禁止直接覆盖终审后的 395 题母版。
5. 发布前同时检查题目数量、证据 `unit_id`、人工审核结论、软件导出数量和 DOCX 实际展示。
6. 需要复原外部参考仓库时，先阅读 [外部参考仓库快照清单](外部参考仓库快照/MANIFEST.md)，并执行 `git lfs pull`。
