# P5A 人工 review

本目录记录 P5A section 级术语抽取结果的人工审阅意见。

P5A 的职责是从 section 原文中抽取术语候选，不在这一层追求最终字典的完全干净。人工 review 主要用于给 P5B 合并、去噪、补全提供明确判断。

## 审阅结论

每条问题使用以下判断：

```text
keep：可以保留为术语候选。
merge：应与其他词条合并，不建议独立成最终词条。
review：需要 P5B 或人工继续确认。
drop：不建议进入最终术语字典。
```

## 审阅重点

```text
1. 是否是 CAMS/AML/CFT/金融犯罪复习中有检索价值的术语。
2. 缩写与全称是否有证据支持。
3. 中英文是否需要后续合并补全。
4. 是否太短、太泛、只是普通背景词。
5. 是否应归并到更标准的 canonical term。
```

P5A 原始产物不直接改写。人工 review 只追加审阅意见，最终取舍放到 P5B。
