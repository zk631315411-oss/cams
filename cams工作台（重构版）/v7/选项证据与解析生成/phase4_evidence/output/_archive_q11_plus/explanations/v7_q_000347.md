题干：在为组织选择反金融犯罪(AFC)工具时，应优先考虑哪些因素？(选择两项。)

英文题干：Which factors should be prioritized when choosing an anti-financial crime (AFC) tool for an organization? (Select Two.)

选项：

- A. 实时数据分析能力作为更广泛战略的一部分
  English: Real-time data analysis capabilities as part of a broader strategy
- B. 倾向于选择成本最低的方案
  English: Preference for the lowest-cost solution
- C. 完全消除人工流程
  English: Complete elimination of manual processes
- D. 与现有IT基础设施的兼容性
  English: Compatibility with existing IT infrastructure
- E. 处理不断增长的交易量的可扩展性
  English: Scalability to handle increasing transaction volumes

## 【AI答案】

D、E

## 【考点】

区分AFC技术评估中的四项核心考量：可扩展性、集成、灵活架构与协作

## 【核心解析】

教材在P389明确指出评估新金融犯罪防控技术时有四项关键考量：可扩展性（scalability）、灵活架构（flexible architecture）、集成（integration）与协作（collaboration）。其中，可扩展性要求方案能适应有机增长、并购及新产品服务（P389）；集成方面，P378进一步强调需确保与现有系统兼容（Integration with existing systems: Ensure compatibility with legacy technology and core banking systems）。选项D「与现有IT基础设施的兼容性」直接对应集成这一优先考量，选项E「处理不断增长的交易量的可扩展性」直接对应可扩展性这一优先考量，两者均属于教材界定的核心优先因素。

教材原句："There are four key considerations for evaluating new AFC technology: scalability, flexible architecture, integration, and collaboration."

## 【错误项分析】

- **A 错误（教材定义应用）｜证据不足**：实时数据分析能力是AFC工具的有用功能，但教材在界定评估新技术的最优先因素时，并未将其单独列出（P389）。相比之下，题干更直接匹配教材强调的系统级基础特性——可扩展性与集成，而非某一具体分析功能。
- **B 错误（教材直接依据）｜范围或程度偏差**：教材强调在花费与有效性之间取得平衡（P383），而非单纯追求最低成本。成本考量属于总拥有成本评估的一部分（P378），但并非最优先的筛选维度，可扩展性和集成在教材的优先清单中位置更靠前。
- **C 错误（教材直接依据）｜范围或程度偏差**：教材指出当前AI技术不太可能完全消除人工监督（P387）。题干要求的「优先考虑」因素应落在可扩展性、集成等已被教材明确列为关键考量的领域，完全消除人工流程不如这些基础架构特性更具优先级。

## 【易错提醒】

容易将「实时数据分析」误判为优先因素。教材的四项关键考量聚焦于系统级特性（可扩展、集成、灵活架构、协作），而非特定的分析功能。选择AFC工具时，兼容性与可扩展性比单一功能更基础、更优先。
