# v7_q_000031

教材章节：未映射

题型：single

题干：在哪个过程中,一个国家必须向金融行动特别工作组(FATF)证明其拥有有效框架以保护金融体系免受滥用？

英文题干：During which process must a country demonstrate to the Financial Action Task Force (FATF) that it has an effective framework to protect the financial system from abuse?

选项：

- A. 正式评估
  English: Formal assessment
- B. 监管概述
  English: Regulatory overview
- C. 技术分析
  English: Technical analysis
- D. 相互评估
  English: Mutual evaluation

答案：D

解析：

考点：FATF互评估（Mutual Evaluation）的核心定义与证明义务

核心解析：题目问的是FATF体系下，一个国家必须「向FATF证明」其拥有有效框架的程序。教材定义：FATF互评估（Mutual Evaluation）是成员国之间的同行评审，评估报告深入分析一国防止金融系统被滥用的法律与监管框架（P153）。关键点在于「证明」——互评估要求严格，「每个司法管辖区只有在能向其他FATF成员证明其合规时，才被视为合规」（P153）。也就是说，互评估的本质就是一个国家向FATF展示和证明其反洗钱/反恐怖融资框架有效性的正式过程。题干中的「demonstrate to FATF」（向FATF证明）与证据中的「prove the same to other FATF members」直接对应，因此相互评估是唯一匹配的程序。
教材原句："Mutual evaluations are strict, meaning each jurisdiction is only deemed compliant when it can prove the same to other FATF members."

A项错误：教材在描述FATF互评估流程时，未将「正式评估（Formal assessment）」作为一个独立的、与互评估并列的程序名称。题干中要求向FATF证明框架有效性的特定程序，更匹配教材明确命名的「相互评估」。
B项错误：教材提到「监管报告与联络（Regulatory reporting and liaison）」是金融机构内部合规职能之一（P254），而非FATF层面要求国家证明其框架有效性的程序。题干指向国家层面的国际评审机制，而非机构层面的监管行为。
C项错误：「技术合规性（technical compliance）」是互评估的两大组成部分之一，侧重检查法律法规是否到位（P153）。但题干说的是「证明拥有有效框架」这一完整过程，而非仅分析法规文本的环节。技术合规性只是互评估内部的一个子项，不如互评估整体更直接匹配题干的「证明」要求。

易错提醒：互评估（Mutual Evaluation）包含「技术合规性」和「有效性」两个组成部分。只考查法律法规条文的是技术合规性，但要求国家「证明框架有效」的完整程序是互评估本身。看到选项中出现「技术」二字体现在评估过程中的某个环节，容易误选，但题干强调的是整体的证明过程而非单项分析。
