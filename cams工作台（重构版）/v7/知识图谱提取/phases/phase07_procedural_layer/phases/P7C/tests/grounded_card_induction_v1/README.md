# P7C Grounded Card Induction v1

## 研究问题

从教材 section 自下而上归纳：什么样的业务材料应形成一张 `p7_card`，一张 card 应在哪里开始、在哪里结束，以及哪些结构类型需要被正式模型表达。

本实验不沿用既有 `execution / assessment / risk_indicator / control` 分类作为开放编码框架，也不读取旧 P7C card。唯一预设是用户提出的最小结构：

```text
入口节点 -> 处理节点群 -> 出口节点
```

## 方法

采用扎根理论式的开放编码、持续比较和理论抽样：

1. 逐 section 只读 `section_text_with_unit_anchors`。
2. 贴近原文标记触发情境、动作、判断、约束、结果和交接。
3. 将共同完成一次业务状态转换的编码聚成候选 card。
4. 比较正例、反例及边界案例，归纳入口、处理、出口和组合原型。
5. 每读一个 section 记录是否出现新的一级类型或新的结构关系。
6. 连续 3 个理论抽样 section 无一级新增时，判定本轮达到初步饱和。

这里的“饱和”只表示当前 CAMS 教材样本内的结构类型初步饱和，不代表全书、所有 AFC 业务或所有后续任务已达到绝对饱和。

## 当前结论

一张 card 应定义为：

> 由教材 unit 证据支持的、围绕单一局部业务目标、从可识别入口经过处理或判断到达可观察出口的状态转换单元。

因此：

- “风险、影响、好处、定义或红旗列表”本身不自动成卡。
- 判断型内容可以成卡，但必须有被判断对象/情境、判断过程或标准，以及明确结论或路由。
- 一个出口如果成为下一阶段的入口，通常是自然拆卡点。
- “降低风险、提升效率”等抽象目的不能单独充当出口。
- 并列标准是处理依据，不应被串成时间步骤。
