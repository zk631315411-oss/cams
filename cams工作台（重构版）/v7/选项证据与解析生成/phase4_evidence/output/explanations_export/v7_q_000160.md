# v7_q_000160

教材章节：未映射

题型：single

题干：有效的反洗钱/打击资助恐怖主义合规计划的基本要素之一是:

英文题干：One of the basic elements of an effective AML/CFT compliance program is:

选项：

- A. 企业风险管理体系
  English: A system of enterprise risk management
- B. 基于人工智能的交易监控系统
  English: An artificial intelligence-based transaction monitoring system
- C. 独立且专业的审计职能
  English: An independent and skilled audit function
- D. 基于人工智能的强化尽职调查系统
  English: An artificial intelligence-based enhanced due diligence system

答案：未形成答案

解析：

考点：区分反洗钱合规计划的四大基本支柱

核心解析：反洗钱合规计划的四大基本支柱（four pillars）包括：指定合规官、内部政策和程序、持续培训以及独立审计职能（P256）。题干问的是「基本要素之一」，而独立且专业的审计职能直接对应四大支柱中的第四个——独立审计职能，该职能负责验证和确认组织的合规工作（P256）。选项C完全匹配教材对反洗钱计划基本要素的定义框架，其他选项虽然在实际合规工作中也有价值，但均不属于四大支柱的范畴。
教材原句："The independent audit function is the fourth pillar of an AML program."

A项错误：企业风险管理体系的范畴更广，涵盖风险评估流程等（P265），但教材将独立审计列为反洗钱计划的四大基本支柱之一，企业风险管理体系并不在四大支柱的列举中，与题干要求的匹配度不如选项C直接。
B项错误：教材描述了AI驱动的交易监控如何提升效率（P440），但交易监控系统属于操作层面的工具，教材未将其列为反洗钱计划的基本要素，与四大支柱的定义框架不匹配。
D项错误：强化尽职调查是对高风险客户或特定场景采取的额外措施（P357、P103），属于风险缓释手段而非反洗钱计划的基础构成要素，教材未将其纳入四大支柱之列。

易错提醒：反洗钱合规计划的四大基本支柱是：指定合规官、内部政策与程序、持续培训、独立审计职能（P256）。交易监控系统和强化尽职调查属于内部控制措施的一部分，在四大支柱框架下归于「内部政策和程序」这一支柱之内，本身不是独立支柱。
