# v7_q_000015

教材章节：未映射

题型：single

题干：一个强大的交易监控系统应具备以下能力:

英文题干：A robust transaction monitoring system includes the capability to:

选项：

- A. 监控交易并识别可能表明可疑活动的异常情况
  English: Monitor transactions and identify anomalies that might indicate suspicious activity
- B. 自动翻译文档
  English: Automatically translate documents
- C. 整合社交媒体资料
  English: Integrate social media profiles
- D. 提交可疑活动报告(SAR)、货币交易报告(CTR)及其他监管报告
  English: File Suspicious Activity Reports (SARs), Currency Transaction Reports (CTRs), and other regulatory reports

答案：A

解析：

考点：交易监控系统的核心定义与功能边界

核心解析：交易监控系统的定义是「帮助金融机构检测可疑交易模式的技术框架」（P325）。题干中的「强大的交易监控系统应具备的能力」实质上是问这一系统的核心功能。教材进一步定义了交易监控是「开户后持续观察客户交易以识别异常或非法活动」（P329），并指出它「检测可能表明洗钱、逃税或其他金融犯罪的复杂模式」（P329）。因此，监控交易并识别可能表明可疑活动的异常情况，本身就是交易监控系统的定义性功能，而非附加能力。选项A与教材定义逐字对应，是唯一直接吻合题干「应具备的能力」的选项。

B项错误：教材涉及文档验证时提到AI工具可自动核实文档真实性（P408），但讨论的是身份验证环节，而非交易监控系统。教材中没有任何单元将「自动翻译文档」与交易监控系统关联，题干缺少支撑这一能力所需的要素。
C项错误：教材在讨论调查阶段的信息收集时提到，社交媒体资料可作为外部信息提供额外背景（P338），属于分析师人工调查时的工具，而非交易监控系统的技术框架本身具备的功能。监控系统的核心功能是检测交易模式，社交媒体属于调查辅助手段，两者在教材中处于不同章节、不同职能阶段。
D项错误：提交SAR和CTR是调查职能或监管报告与联络职能的职责（P251），发生在交易监控系统检测出可疑活动之后。教材明确指出「若发现并确认可疑活动可能涉及洗钱，必须提交SAR」（P329），这显示监测与报告是两个不同阶段、不同主体的动作。题干问的是系统本身的「能力」，而非系统触发后由人来执行的后续程序，因此选项D不如选项A直接匹配题干对系统自身功能的定义。
