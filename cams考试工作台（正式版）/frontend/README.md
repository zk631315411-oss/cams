# 前端

前端是原生 HTML、CSS 和 JavaScript，没有 npm、打包器或前端框架。它只能通过同源 HTTP API 读取和修改工作台，不直接访问 `data`。

## 文件

- `index.html`：V2 里程碑、选题抽屉、题目/证据/解析标签、PDF 分屏、证据抽屉、人工决定和 DeepSeek 设置。
- `js/app.js`：API 客户端、页面状态、题目选择、五秒轮询、证据分页、人工动作和快捷指令复制。
- `js/pdf-reader.js`：教材 manifest、连续页面、语言、缩放、页码定位、文字匹配与五秒高亮。
- `css/workbench.css`：半屏与桌面布局、抽屉、表单和状态样式。
- `assets/`：当前为空的项目静态资源预留目录。

## 交互边界

- 网页不能创建新题；新题由 Codex MCP 建档。
- 教研在网页确认证据、提交解析批注、标记润色完成和作最终决定。
- 选择题目会更新 `data/control/active-context.json`，不改变题目版本或审计。
- 页面每五秒检查 `archive_revision`。无未保存内容时自动刷新；存在未保存编辑时只提示新版本。
- 后台更新不得自动换题、切换标签或跳转 PDF。
- 点击证据后先跳页并请求文字匹配；匹配成功高亮五秒后淡出，失败只跳页并提示。

## API

前端使用的路由以 [HTTP API 契约](../docs/api.md) 为准。新增按钮或表单前必须先确定对应 API 是否属于网页权限，不能从浏览器直接调用 Codex 专属动作。

## 验收

当前没有浏览器自动化测试。修改后至少手工验证：

1. `960 x 900` 半屏和常规桌面无重叠、截断或横向溢出。
2. 中文、英文、双语 PDF、翻页、缩放和最大化。
3. 精选/原始证据抽屉、筛选和分页。
4. 五秒高亮、连续点击清理旧定时器、匹配失败提示。
5. 后台更新与未保存批注保护。
6. “整理证据”“处理当前题”复制以及 MCP 当前题读取。
