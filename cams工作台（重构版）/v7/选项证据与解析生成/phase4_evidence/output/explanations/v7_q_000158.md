# v7_q_000158

题型：single

题干：对于金融机构的高级管理层而言,哪项关键指标能为其提供有关反洗钱控制措施有效性的最有价值的数据？

英文题干：Which key metric provides senior management with information about the effectiveness of its AML controls?

选项：

- A. 自动监测系统生成的真阳性与假阳性之比
  English: The ratio of true positives to false positives generated by the automated monitoring system
- B. 监测名单筛查系统生成的洗钱警报数量
  English: The number of money laundering alerts generated by the watchlist screening system
- C. 每月新引入的高风险客户数量
  English: The number of high-risk customers onboarded each month
- D. 因商业原因退出的客户数量
  English: The number of clients exited for commercial reasons

## 【AI答案】

A

## 【考点】

区分关键绩效指标（KPI）与关键风险指标（KRI）

## 【核心解析】

教材将关键绩效指标（KPI）定义为衡量金融犯罪防控控制有效性的指标，示例包括可疑活动报告提交时限、筛查误报降低率及警报解决时间（P296）。题干问的是高级管理层用来衡量「反洗钱控制措施有效性」的指标，这直接对应KPI的定义范畴。选项A提到的「真阳性与假阳性之比」本质上是误报率的一种表达方式——真阳性比例越高，说明系统越精准，控制越有效。这与教材KPI示例中的「false positive reduction rates」在概念上完全吻合，因此是衡量控制有效性的最有价值数据。

教材原句："Key performance indicators (KPI) are measures of AFC control effectiveness, such as SAR filing timelines, false positive reduction rates in screening, and alert resolution times."

## 【错误项分析】

- **B 错误（教材定义应用）｜概念混淆**：警报数量是工作量指标，不直接反映控制的有效性。一个系统可能因阈值设置过低而产生大量警报，但这并不说明控制措施有效——大量警报中可能绝大部分是误报。P422提到「系统生成的预警数量超出预期」恰恰是需要调优的标志，而非有效性的证明。题干更关注「有效性」而非「活动量」，A直接量化了有效性。
- **C 错误（教材定义应用）｜概念混淆**：每月新引入的高风险客户数量反映的是业务接受决策的尺度，而非既有控制措施的有效性。P296提到高风险客户报告包含准入决策和尽职调查评估，这属于风险暴露程度的指标（KRI范畴），不能直接说明机构现有的控制系统是否有效运转。题干问的是「控制措施有效性」，而非「承担了多少风险」。
- **D 错误（题干对照）｜题干要素不匹配**：因商业原因退出的客户数量与反洗钱控制有效性无直接关联。题干要求的是金融犯罪防控控制的有效性指标，而「商业原因」退出属于业务决策范畴，即使在候选证据中关于客户退出的讨论（P303、P422）也均围绕金融犯罪风险或风险偏好不匹配展开，而非商业因素。该选项缺失了题干要求的核心维度。

## 【易错提醒】

KPI衡量控制措施「运行得好不好」（有效性），KRI衡量机构「面临多大风险」（风险敞口）。P296将KPI与KRI并列区分：KPI关注SAR提交时限、误报率等控制表现；KRI关注可疑交易量、尽职调查积压等风险状态。选项C的高风险客户数量更接近KRI，选项B的警报数量若用于监测异常波动也偏向KRI，只有A直接衡量控制措施本身的精准度。
