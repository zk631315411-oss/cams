# v7_q_000384

教材章节：未映射

题型：multiple

题干：以下哪些是使用搜索引擎进行负面媒体报道搜索的局限性？(选择三项.)

英文题干：Which of the following are limitations of using search engines to screen adverse media? (Select Three.)

选项：

- A. 搜索引擎在全球语言覆盖方面存在局限性
  English: Search engines have limited global language coverage
- B. 搜索引擎提供的非结构化数据使媒体分析变得复杂
  English: Search engines provide unstructured data that complicates media analysis
- C. 搜索结果在识别相关负面媒体报道方面往往效率低下
  English: Search results are often inefficient in identifying relevant adverse media
- D. 这个过程耗时且需要大量的人工投入.
  English: The process is time-consuming and requires significant manual effort
- E. 由于搜索引擎算法的不同,结果可能会不一致
  English: Outcomes can be inconsistent due to varying search engine algorithms

答案：B、C、D

解析：

考点：搜索引擎在负面媒体筛查中的非结构化数据、效率与人工耗时局限

核心解析：负面媒体筛查常依赖外部数据，外部数据来源多样，可能非结构化或与合规系统不兼容（P467）。非结构化数据是指非固定格式的数据，如自由文本，需要额外处理才能转换为可用格式（P467）。负面媒体筛查系统需调优关键词和短语以过滤无关信息，否则搜索结果往往效率低下，难以有效识别相关负面媒体报道（P422）。此外，人工检查此类数据耗时且劳动密集（P330），自然语言处理算法之所以被引入，正是为了减少人工筛查的工作量（P417）。题干所问的「使用搜索引擎进行负面媒体报道搜索的局限性」，恰好落在这三个教材明确指出的问题上：搜索引擎返回的是非结构化网页内容，使分析复杂化；不加调优的搜索结果包含大量无关信息，识别效率低；逐个查看结果需要大量人工投入，过程耗时。
教材原句："External data originates from many diverse sources, which might make it unstructured or incompatible with compliance systems."

A项错误：教材提到跨司法管辖区和语言边界使数据处理更复杂（P470），以及筛查系统存在无法一致处理不同语言的情况（P429），但这些讨论针对的是数据和系统整体，并非专门将语言覆盖列为搜索引擎进行负面媒体搜索的局限性。相比之下，教材更直接地将搜索引擎的局限归结为非结构化数据、效率与人工投入，题干更支持 B、C、D 而非 A。
E项错误：教材在数据情景中讨论不一致时，提及的是客户关联不同部门导致的数据不一致（P468）或不同区块链浏览器对同一交易显示不同信息（P486），并未将搜索引擎算法差异列为负面媒体筛查的局限性。在教材框架下，缺乏对这一点的直接阐述，因此 E 不如正确项有依据。

易错提醒：教材对使用搜索引擎进行负面媒体筛查的局限性，重点强调的是非结构化数据带来的复杂性、搜索结果效率低下以及人工耗时，而非全球语言覆盖范围或算法一致性。语言处理和算法差异在教材其他部分提及，但并不属于负面媒体搜索的核心局限范畴。
