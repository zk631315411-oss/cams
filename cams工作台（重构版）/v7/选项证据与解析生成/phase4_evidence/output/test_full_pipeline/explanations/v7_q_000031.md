题型：single

题干：在哪个过程中,一个国家必须向金融行动特别工作组(FATF)证明其拥有有效框架以保护金融体系免受滥用？

英文题干：During which process must a country demonstrate to the Financial Action Task Force (FATF) that it has an effective framework to protect the financial system from abuse?

选项：

- A. 正式评估
  English: Formal assessment
- B. 监管概述
  English: Regulatory overview
- C. 技术分析
  English: Technical analysis
- D. 相互评估
  English: Mutual evaluation

## 【AI答案】

D

## 【考点】

识别FATF互评估（Mutual Evaluation）的定义与核心环节

## 【核心解析】

FATF互评估（Mutual Evaluation）是成员国之间的同行评审，用以深入分析一国反洗钱程序及其有效性（P153）。其关键特征在于，互评估过程严格，司法管辖区必须向其他FATF成员证明其合规性，才能被视为合规（P153）。题干中提到「一个国家必须向FATF证明其拥有有效框架以保护金融体系免受滥用」，这直接对应了互评估流程中，被评估国需在技术合规性及有效性两方面提交证据、接受其他成员评审的「证明」义务。因此，D选项「相互评估」（Mutual evaluation）是教材定义的唯一符合此描述的过程。

教材原句："Mutual evaluations are strict, meaning each jurisdiction is only deemed compliant when it can prove the same to other FATF members."

## 【错误项分析】

- **A 错误（教材定义应用）｜概念混淆**：教材在数据管理和客户准入等场景中频繁提及「正式审批流程」，但该术语并非FATF定义的国家级评估程序。题干讨论的是国家向FATF证明其制度有效性，A选项的术语缺乏与FATF官方评估流程的教材定义关联，匹配度远不如D。
- **B 错误（题干对照）｜范围或程度偏差**：教材中「监管概述」通常指对法规框架的一般性介绍，或监管报告与联络职能。题干强调的是国家需「证明」其框架有效性，这是一个严格、正式的国际评审程序，而非概述性介绍。题干要求的「证明」动作，需在D选项的评审机制中实现，而非B选项所描述的活动。
- **C 错误（题干对照）｜范围或程度偏差**：「技术分析」在教材中是互评估流程中的一个具体步骤，即评估团队分析司法管辖区的法律法规（P154）。题干描述的是包含技术分析在内的整个互评估过程，与国家向FATF「证明」其框架有效性的完整周期相比，技术分析作为其中一个环节，其涵盖范围小于题干描述的整体过程。

## 【易错提醒】

「技术分析」和「相互评估」易混淆。记住：「技术分析」是「相互评估」过程中的一个环节（评估团队分析法律），而「相互评估」指代包含技术分析、现场访问、报告撰写及评审投票在内的完整七年制同行评审过程。
