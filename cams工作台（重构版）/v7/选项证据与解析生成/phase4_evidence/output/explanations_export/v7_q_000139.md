# v7_q_000139

教材章节：未映射

题型：single

题干：隐私增强技术(PETS)在反洗钱方面的一个关键优势在于它们能够提供:

英文题干：A key advantage of privacy-enhancing technologies (PETs) in anti-money laundering is that they offer:

选项：

- A. 对底层数据进行同步加密和解密
  English: Simultaneous encryption and decryption of underlying data
- B. 对底层数据的完全访问权限,并能对数据进行完整且不间断的计算.
  English: Full access to underlying data, with full and uninterrupted calculations made on the data
- C. 在数据保持加密状态下对其进行安全处理.
  English: Secure processing of data while it remains encrypted
- D. 数据处理者对数据的传输、解密和存储.
  English: Transfer, decryption, and storage of data by the data processor

答案：C

解析：

考点：识别PETs的核心特性：数据在加密状态下的安全计算能力

核心解析：隐私增强技术（PETs）是能在保护个人隐私的同时实现数据共享与分析的创新工具（P393）。其关键子类——同态加密，允许对加密数据直接执行计算而无需先解密，从而在保持数据效用的同时保护隐私（P393）。题干问的是PETs在反洗钱领域的「关键优势」，这正好对应了同态加密的核心特征：数据全程保持加密状态，却能进行安全处理和分析。选项C准确捕捉了这一点，即「数据保持加密状态下对其进行安全处理」，这既满足了反洗钱协作中对敏感金融数据的分析需求，又避免了暴露个人身份信息（PII）的风险。
教材原句："Homomorphic encryption: Using this technique, computations can be performed on encrypted data without needing to decrypt it first. This enables collaborative analysis of encrypted data, preserving privacy while maintaining utility."

A项错误：PETs旨在避免不必要的解密，以降低数据泄露风险。选项A中的「同步加密和解密」与PETs追求的「无需解密即可计算」的目标不吻合。同时，教材也未将PETs的优势描述为加密和解密的同步操作。
B项错误：PETs的核心设计目标是保护隐私，因此「完全访问权限」（Full access）与教材定义直接矛盾——教材明确指出PETs使机构能在「不暴露个人身份信息（PII）」的前提下协作，P393）。题干更匹配在限制访问的同时进行计算，而非要求对底层数据的完全访问。
D项错误：数据传输、解密和存储是常规数据处理流程，而非PETs独有的关键优势。PETs的优势恰恰在于减少对「解密」环节的依赖。选项D描述的做法反而是PETs力求避免的，因为解密状态下的数据更容易暴露，不符合PETs保护隐私的初衷。

易错提醒：看到「隐私增强」容易联想到数据被严密锁死、无法使用。但教材强调PETs（如同态加密）的核心是在「加密中处理」，实现隐私保护和数据效用的平衡。
