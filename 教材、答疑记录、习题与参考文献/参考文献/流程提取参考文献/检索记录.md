# 流程提取参考文献检索记录

检索日期：2026-07-10

## 1. 研究问题

围绕以下问题检索：如何利用 NLP、机器学习或 LLM，从业务文本、工业操作规程、临床指南、建筑规范和法律/监管文本中抽取活动、条件、分支、时序、规则及其关系，并进一步形成流程模型、动作图、知识图谱或可执行规则。

本轮检索特别关注对 P7E 有用的证据：

- 文本如何转换为节点和边，而不是只做实体识别；
- 条件、例外、触发、AND/XOR 分支和时序如何表示；
- 是否允许模型补出隐含节点，以及如何记录来源；
- 如何在高召回要求下控制幻觉并安排人工复核；
- 全书规模下如何避免对所有 card 进行两两昂贵推理。

## 2. 数据源

- Crossref：题名、作者、年份、DOI 和出版状态核验；
- arXiv API/开放 PDF：流程抽取、PET 数据集、LLM 提示、程序知识图谱；
- PubMed、PMC、Europe PMC：可计算临床指南和 LLM 指南抽取；
- OpenAlex：开放获取状态、作者仓储和 PDF 定位；
- ACL Anthology：ChemActor 和中文法律实体关系抽取；
- 出版商/机构开放仓储：Nature、JMIR、MDPI、ITcon、Cardiff ORCA、ORBilu 等。

## 3. 主要检索式

英文组合词包括：

- `process model extraction from natural language text`
- `process extraction text BPMN gateway condition relation`
- `procedural knowledge graph extraction LLM`
- `industrial procedure action sequence extraction`
- `engineering rules extraction unstructured text`
- `clinical guideline computer interpretable workflow extraction`
- `large language model clinical guideline information extraction`
- `construction regulatory requirements NLP compliance knowledge graph`
- `legal metadata condition exception modality extraction`
- `automated workflow knowledge graph self-driving labs`

## 4. 纳入与排除规则

纳入：

- 直接从自然语言抽取流程、动作、关系、规则或程序知识；
- 虽不直接画流程图，但对条件/例外抽取、形式化、跨模型复核或图验证有明确方法贡献；
- 有可核验题名、作者和 DOI/arXiv/PMID；
- 下载文件来自合法开放来源或作者公开存档。

排除或仅列书目：

- 只做流程日志挖掘而不处理自然语言；
- 只评价 LLM 是否遵从指南，不抽取结构化知识；
- 搜索摘要与主题明显不符；
- 出版社付费墙、自动访问阻断或无法确认合法开放版本；
- 下载结果实际是 HTML、挑战页或未完成文件。

## 7. 局限

- 这不是 PRISMA 式穷尽系统综述，而是面向 P7E 设计决策的定向证据检索；
- 部分经典医学 CIG 论文在 PMC 自动下载端触发挑战页，因此只保留可合法取得并成功核验的论文；
- 不同论文的指标对象不同，不能把实体 F1、完整动作序列匹配率、分类准确率和人工感知质量直接横向排序；
- 论文对“跨 card 桥接”的直接研究很少，相关 P7E 结论属于跨领域方法迁移，已在综述中标注为 `【LLM推理】`。
