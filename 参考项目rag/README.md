# 外部 RAG 参考项目

`DeepRefine-Skill/`、`LightRAG/` 和 `weknora/` 按当前本地状态原样交接，包括其嵌套 Git 信息和已有本地修改。它们用于来源研究、RAG 方案比较和代码参考，不是 CAMS 正式运行依赖，也不得作为教材或题目证据来源。

由于父仓库不能可靠提交嵌套 `.git` 和未提交修改，完整状态另存于 `项目交接/外部参考仓库快照/` 的 Git LFS 压缩包；目录、上游、HEAD、差异数和 SHA-256 见其中的 `MANIFEST.md`。本地原目录不作子模块转换。

各项目的上游说明、许可证和运行方式以其自身 README 与 Git 元数据为准。本仓库不对第三方项目正文进行 CAMS 化改写。

安全例外：上传前删除真实 `.env` 并脱敏凭据字面量，不保留或恢复任何 API key。
