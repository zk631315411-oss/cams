# v7_q_000062

教材章节：未映射

题型：single

题干：一家银行使用网络分析工具来识别客户与犯罪实体之间的联系。该系统能够识别潜在的间接关系，但无法对这些关系进行优先级排序。合规官应采取什么措施来提高该工具的有效性？

英文题干：A bank is using a network analysis tool to identify links between its customers and criminal entities. The system identifies potential indirect relationships but is unable to prioritize them. What should the compliance officer do to enhance the tool's effectiveness?

选项：

- A. 手动审查所有被标记的关系以确保准确无误
  English: Manually review all flagged relationships for accuracy
- B. 对间接关联实施风险评分算法
  English: Implement risk-scoring algorithms for indirect connections
- C. 整合外部数据库和社交媒体资料，以交叉核对被标记的实体
  English: Integrate external databases and social media profiles to cross-check flagged entities
- D. 关注客户与犯罪实体之间的直接联系
  English: Focus on direct connections between customers and criminal entities

## 【AI答案】

B

## 【考点】

识别链接后通过风险评分模型实现间接关系的优先级排序

## 【核心解析】

实体解析流程中，实体链接后基于风险的评分模型评估潜在匹配（P484）。风险评级模型通过基于交易行为、客户属性和高风险司法管辖区敞口分配风险评分来增强场景有效性（P444）。题干中网络分析工具能识别客户与犯罪实体之间的潜在间接关系，但无法进行优先级排序——这意味着系统完成了「链接」步骤，却缺少「评分」环节。因此，合规官应对间接关联实施风险评分算法，使系统不仅能识别关系，还能根据风险高低排序，从而提升工具的有效性。

教材原句："Once entities are linked, risk-based scoring models assess potential matches."

## 【错误项分析】

- **A 错误（题干对照）｜范围或程度偏差**：教材描述实体解析流程时指出，高风险匹配升级至数据专家人工审核，低风险匹配自动清除或休眠（P484）。选项A要求「手动审查所有被标记的关系」，与教材只对高风险匹配升级人工审核的做法相比，过度扩大了人工审查范围，且单纯增加人工审查并不能解决系统无法排序的根因。
- **C 错误（题干对照）｜题干要素不匹配**：实体解析工具确实整合内部和外部数据源，包括客户数据库、交易记录和制裁名单等（P484），社交媒体资料也可提供客户或相关方的额外背景信息（P338）。但这些措施解决的是数据丰富和交叉验证问题，题干核心挑战是系统已识别出间接关系但缺少优先级排序机制，整合外部数据不能直接解决排序缺失的问题。
- **D 错误（题干对照）｜概念混淆**：题干明确系统已能识别潜在的间接关系，只是无法排序。选项D建议「关注直接联系」，本质上放弃了间接关系的分析价值。教材指出金融犯罪防控技术可通过自动化数据收集和持续监控来减少直接联系（P382），说明技术发展方向恰恰是深化间接关系分析而非退回只关注直接联系。

## 【易错提醒】

实体解析流程分为两步：先用匹配算法链接实体（识别关系），再用基于风险的评分模型评估潜在匹配（优先级排序）。题干问题出在只有第一步没有第二步，选项C整合外部数据属于第一步的数据丰富，不能替代第二步的评分排序。
