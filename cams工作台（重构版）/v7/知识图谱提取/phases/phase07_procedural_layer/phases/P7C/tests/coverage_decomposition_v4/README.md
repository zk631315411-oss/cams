# P7C Coverage Decomposition v4

This iteration keeps the v2 Audit ledger fixed and upgrades the Patch evidence contract.

Changes are limited to Patch construction and deterministic validation:

- explicitly named institutional processes can be nodes without inventing a named actor;
- every new edge evidence set must cover both endpoint nodes;
- relation types are validated against the P7 schema;
- minimal open relations and qualifier-preserving targets remain mandatory.
