# v7_q_000152

教材章节：未映射

题型：single

题干：在姓名筛查的背景下, 模糊逻辑或模糊匹配是一种方法,其:

英文题干：In the context of name screening, fuzzy logic or fuzzy matching is a method that:

选项：

- A. 利用机器学习根据历史数据预测名称
  English: Uses machine learning to predict names based on historical data
- B. 将筛查名单上的姓名与拼写、模式或发音相似的姓名进行匹配
  English: Matches names on screening lists to names with similar spellings, patterns, or sounds
- C. 将长度相同且字符相同的名称进行匹配
  English: Matches names with the same length and characters
- D. 仅依赖于精确的字符串匹配
  English: Relies exclusively on exact string matches

答案：B

解析：

考点：识别姓名筛查中模糊逻辑匹配的定义

核心解析：模糊逻辑匹配使用算法匹配相似但不完全相同的名称，处理拼写、打字错误和翻译差异（P416）。题干问姓名筛查语境下模糊逻辑是一种什么方法，选项B“将筛查名单上的姓名与拼写、模式或发音相似的姓名进行匹配”直接概括了教材定义的核心要素，因此是正确项。
教材原句："Fuzzy logic matching uses algorithms to match names that are similar but not identical, accounting for variations in spelling, typos, and translations."

A项错误：机器学习模型利用历史数据学习并提高筛查系统准确性（P417），属于与模糊逻辑不同的技术。题干描述的是模糊逻辑本身，选项A涉及机器学习，不如B直接贴合模糊逻辑对相似名称匹配的定义。
C项错误：要求名称长度和字符完全相同更接近确定性匹配（P484），而模糊逻辑专门处理拼写变体和发音相似但不完全相同的名称，C的限制比模糊逻辑更严，不如B贴合模糊逻辑的灵活匹配特征。
D项错误：仅依赖精确字符串匹配与模糊逻辑的理念相反，模糊逻辑正是为解决精确匹配难以覆盖的拼写差异和不一致数据而设计的（P420），D的描述直接排斥了模糊逻辑的核心功能，不如B吻合。

易错提醒：模糊逻辑匹配通过算法识别拼写、发音相似但不完全相同的名称（P416），机器学习模型则利用历史数据学习和自适应，提高筛查准确性（P417），两者是不同的技术路径。
