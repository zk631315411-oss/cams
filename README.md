# CAMS 考试教研工作区

本仓库是 CAMS 反洗钱考试教研工作台的本地工作区。

核心目标不是做一个普通网页，而是建立一套可追溯的教研辅助系统：

```text
教材原文
→ 教材句卡 / 证据池
→ 题目、选项、学生答疑与教材证据绑定
→ 候选考点、旁注、新题解析、学生答疑草稿
→ 教研在工作台中复核和使用
```

所有重要结论都应尽量回到教材原文。题目解析、学生答疑、考点旁注都不能只靠模型记忆或历史解析。

## 快速启动

在本目录运行：

```powershell
python start_cams_workbench.py
```

该脚本会尝试启动：

- 新题解析 API：`http://127.0.0.1:8765/api/new-question/health`

第一次运行新题解析或学生答疑时，会加载教材证据池和 BGE 检索模型，可能会比较慢。

## 主线数据流

### 已有题库和考点旁注

```text

→ 教材句级证据池
→ 四角色法 / agentic search 绑定题目选项与教材证据
→ option_evidence_map.json
→ exam_points_teaching_mvp.json
→ sentence_exam_point_map.json
→ 工作台教材阅读页和题目详情页展示
```

当前前端主要读取：

`D:\守正公司工作区\cams考试\cams工作台\data\teaching_assets`

### 新题解析

```text
老师粘贴新题
→ 题目拆解
→ 盲判式 agentic 检索
→ 教材证据召回
→ 答案与解析生成
→ 二次审查
→ 保存 draft JSON
→ 前端展示历史草稿
```

模块位置：

`D:\守正公司工作区\cams考试\cams工作台\新题解析模块`

### 学生答疑

```text
老师粘贴学生疑问
→ 解析输入并判断类型
→ 自由回答 / 识别学生卡点
→ claim planner 拆出待查证主张
→ 多路召回教材原文
→ evidence judge 判断证据是否可用
→ 生成答疑草稿
→ reply reviewer 二次审查
→ 默认依据选择器
→ 保存历史答疑
```

模块位置：

`D:\守正公司工作区\cams考试\cams工作台\学生答疑模块_agentic`

## 关键原则

1. 教材原文是最终依据。
2. 教材句卡不是天然考点，只有经过题目、答疑、证据绑定和教研判断后，才可作为候选考点使用。
3. KG、LightRAG、历史解析、学生答疑都可以辅助召回或理解，但不能替代教材原文依据。
4. 新题解析和学生答疑不应读取教研历史解析作为生成依据。
5. 旧目录不要直接删除，先归档并写 README。
6. 涉及 API key、Codex 配置、CC Switch 配置的脚本不要随便运行。
7. 需要重建下游资产时，先确认数据源和产物链路，再跑批量脚本。
