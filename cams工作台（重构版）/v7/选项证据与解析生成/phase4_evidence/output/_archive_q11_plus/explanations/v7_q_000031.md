# v7_q_000031

题型：single

题干：在哪个过程中,一个国家必须向金融行动特别工作组(FATF)证明其拥有有效框架以保护金融体系免受滥用？

英文题干：During which process must a country demonstrate to the Financial Action Task Force (FATF) that it has an effective framework to protect the financial system from abuse?

选项：

- A. 正式评估
  English: Formal assessment
- B. 监管概述
  English: Regulatory overview
- C. 技术分析
  English: Technical analysis
- D. 相互评估
  English: Mutual evaluation

## 【AI答案】

D

## 【考点】

识别FATF通过相互评估过程审查成员国反洗钱框架的有效性

## 【核心解析】

FATF相互评估（Mutual Evaluation）是成员国之间的同行评审，目的是深入分析一个司法管辖区为防止金融系统被犯罪滥用而建立的法律和监管框架（P153）。该过程要求严格，「每个司法管辖区只有向其他FATF成员证明其合规才能被视为合规」（P153）。题干问的是「一个国家必须向FATF证明其拥有有效框架以保护金融体系免受滥用」的过程，这正好对应了相互评估的核心机制：由被评估国主动向同行评审团队展示其反洗钱/反恐怖融资体系的有效性，评估团队据此出具详细报告。选项D「相互评估」与教材定义直接吻合。

教材原句："Mutual evaluations are strict, meaning each jurisdiction is only deemed compliant when it can prove the same to other FATF members."

## 【错误项分析】

- **A 错误（题干对照）｜范围或程度偏差**：「正式评估」在教材中是FATF对成员国标准实施情况进行监督的泛称（P144），并非一个被精确定义、可与其互评估流程平级的独立过程。题干要求的是一个具体的、以「证明」为内核的评审场景，教材直接用「相互评估」定义了这个场景，匹配度比泛称「正式评估」更高。
- **B 错误（题干对照）｜概念混淆**：「监管概述」在教材中仅作为章节导语出现，指对全球反洗钱规则的高层面介绍（P177），并非FATF的任何正式程序。题干所问的是一个要求国家「证明」自身框架的过程，监管概述不具备此功能。
- **C 错误（题干对照）｜范围或程度偏差**：技术合规是相互评估中的第二个组成部分，主要审查国家的法律法规是否与FATF标准对齐（P153）。技术合规性审查发生在相互评估大框架内，作为其中一步，并非与相互评估并列的完整「过程」。题干问的是一个「国家证明自身」的宏观过程，相互评估是比其子组成部分更直接的答案。

## 【易错提醒】

最容易混淆的是「技术合规」和「相互评估」。相互评估是一个完整的同行评审过程，包含有效性和技术合规两个组成部分。技术合规仅关注法律法规层面的静态审查，而相互评估整体才是国家需要向FATF证明其体系有效的场合。如果题目问的是「FATF互评估中审查法律法规的部分叫什么」，那时才会选与技术分析相关的项。
