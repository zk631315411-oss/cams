# 来源资产说明

本目录保存教材、题源和参考文献。名称中的“答疑记录”模块已经取消，当前不存在正式答疑记录输入目录。

| 目录 | 定位 |
|---|---|
| `教材原文/` | V6/V7 PDF、MinerU Markdown 及 OCR 过程材料；PDF 与当前确认的中英文 MD 是教材来源 |
| `习题/` | 原始题源、OCR/清洗过程及多格式快照 |
| `参考文献/` | 外部参考资料，不自动成为教材证据 |

V7 正式结构化题库不是本目录中的派生副本，而是 `cams工作台（重构版）/v7/选项证据与解析生成/phase3.5_questions/output/v7_questions.json`。本目录下的 `v7结构化文本/` 只作为题源与导出快照保留。
