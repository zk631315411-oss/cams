# CAMS 教研工作台项目记录

## 背景

**项目**：为 CAMS 反洗钱资格认证考试教研老师开发知识工作台。

**教研老师**：小公司，一个人兼三个角色——HR、教研、售后客服。学生通过小程序刷题，遇到问题找她答疑。目前的179题解析是她和 OpenAI Codex 协作写的，但解析质量参差不齐，部分逻辑不够通顺、教材依据不够扎实。解析不够好 → 学生看不懂 → 提问增多 → 教研疲于答疑 → 没时间做学情复盘和专题优化。

**我**：实习生，负责技术实现。之前一周都在写数据管线和前端界面。

**已有数据资产**：
- V6 教材第2章（MinerU提取，7915行Markdown）
- 1950张考点卡片（citation / knowledge / type）
- 179道完整题目（题干+选项+答案+解析）
- 37条答疑记录（学生提问+教研回答）
- 3927条知识三元组、4771个实体（知识图谱）
- 题目→卡片AI匹配结果（question_card_map.json）
- 答疑→题目→卡片绑定结果（qa_bindings.json）

### 教研上线后反馈（5/30）
| # | 反馈 | 我的理解 |
|---|---|---|
| 1 | 颜色花花绿绿，不如原型HTML清晰 | 我加了五种类型彩条+黄色高亮+橙蓝标签，视觉过载 |
| 2 | 跳转功能最好是自动跳转 | 我做了"浏览/定位分离"，教研觉得多一步操作 |
| 3 | 右侧题目关联感觉只是关键词匹配，没有真正定位到考点 | 核心问题——匹配逻辑不对 |
| 4 | 左侧标黄太密，原版是定位精炼考点概念再附样式 | 标黄应该是精选考点，不是大片划词 |
| 5 | 教材重新定位时切换晃眼睛 | 滚动动画视觉刺激过度 |
