# v7_q_000184

教材章节：未映射

题型：single

题干：一家金融机构正在探索采用自动化手段来协助调查人员审查被标记的交易.目前,调查人员花费大量时间能有效提高调查人员的工作效率？

英文题干：A financial institution is exploring automation to assist investigators in reviewing flagged transactions. Currently, investigators spend a significant amount of time gathering data from multiple sources. Which of the following automation features would be most effective in improving investigator efficiency?

选项：

- A. 预填充的搜救报告模板
  English: Pre-populated templates for SAR filing
- B. 集成开源工具以收集实时情报
  English: Integration of open-source tools to gather real-time intelligence
- C. 基于风险评分的自动化案件优先级排序
  English: Automated case prioritization based on risk scoring
- D. 由人工智能驱动的汇总了被标记交易的仪表板
  English: AI-powered dashboards summarizing flagged transactions

答案：D

解析：

考点：区分自动化汇总数据与后续工作流工具对调查效率的不同影响

核心解析：案件管理工具通过减少调查员手动整理数据的需求来提升效率，缩短整理与汇编数据的时间（P455）。反洗钱系统整合多源信息，让调查员能更快访问数据（P455）。题干中调查员花费大量时间从多个来源收集数据，痛点在于手动汇集分散的信息。选项D「AI驱动的汇总仪表板」正是一种自动化汇总工具，将被标记交易的数据集中呈现，消除了跨来源逐个查找和拼凑的过程，直接缩短数据整合时间。教材也在警报管理情境下提到，仪表盘可展示特定类别与数量的警报以保证可审计性，体现了其汇总展示功能（P397）。因此，D项最直接匹配题干描述的效率瓶颈。
教材原句："These tools make the management of cases more efficient by reducing the need for investigators to manually sort through data, reducing the time required to collate and assemble such data."

A项错误：预填充的SAR模板主要解决报告撰写阶段的格式与完整性（P353-P354），而题干痛点是调查初期从多个源头收集数据耗时长。模板不能减少数据收集的工作量，相比D的直接汇总，匹配度明显偏低。
B项错误：集成开源工具（OSINT）能收集公开情报（P399），但仍需调查员自行筛选、验证和整合信息，并未免除手动整理的过程。选项D则自动汇总交易，直接取消跨源拼接的步骤，效率提升更直接。
C项错误：基于风险评分的优先级排序帮助决定哪个案件先审，但不同案件的数据仍需调查员分别从多源收集（P484）。它优化的是审查顺序而非数据获取方式，对消除题干所述的收集时间瓶颈作用有限。

易错提醒：注意区分「减少手动收集整理数据」与「优化审查工作流」两类工具。仪表板、自动化系统整合多源信息属于前者（P455），风险评分排序、警报路由属于后者。题干只强调数据收集时间过长，前者直接命中。
