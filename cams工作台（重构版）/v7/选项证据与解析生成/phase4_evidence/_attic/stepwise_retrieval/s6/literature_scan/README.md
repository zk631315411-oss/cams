# s6 文献扫描：面向学员的考试解析

本目录记录 s6 解析设计的轻量级文献扫描。

研究问题：

> 在练习题回顾过程中，哪种类型的反馈和解析特征最能支持考试导向的学员，特别是在正确性、错误诊断和迁移到相似题目的能力方面？

范围：

- 形成性反馈与纠正性反馈
- 测试情境或多选题情境中的反馈
- 提取练习与迁移
- 已解例题与自我解释
- 认知负荷与解析复杂度
- 自我调节学习与反馈的诊断性使用

文件：

- `search_strategy.md`：可复现的搜索策略、使用的 API 和检索限制。
- `candidate_sources.json`：筛选后的来源元数据，含 DOI 验证状态。
- `annotated_bibliography.md`：针对 s6 设计相关性的简要注释。
- `literature_matrix.md`：来源-主题矩阵。
- `notes_for_s6_design.md`：s6 解析格式的初步设计假设。
- `retrieval_log.md`：API 结果、速率限制说明和排除/不匹配项。

状态：

这是一次范围扫描，而非系统综述。DOI/标题存在性主要通过 Crossref 检查。本轮未下载或穷尽阅读全文，因此来源特定声明应视为设计输入，在正式引用前需验证。
