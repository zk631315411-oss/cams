# v7_q_000104

教材章节：未映射

题型：single

题干：在将新技术应用于反洗钱(AML)时,应用程序编程接口(API)能够实现:

英文题干：When applying new technologies to AML, application programming interfaces (APIs) allow for:

选项：

- A. 移动设备上的数字身份识别
  English: Digital identification on mobile devices
- B. 不同的应用程序用于连接和通信
  English: Different applications to connect and communicate
- C. 通过人工智能(AI)和生物识别技术进行身份验证
  English: Authentication via artificial intelligence (AI) and biometrics
- D. 在客户入职期间快速进行客户细分和客户特征分析
  English: Quick CDD and client traits analysis during onboarding

答案：B

解析：

考点：API 的核心功能：让不同应用程序连接与通信

核心解析：在AML技术语境下，API（应用程序编程接口）的核心作用是实现系统间的连接与数据交互。教材提到，筛查系统应与其他系统兼容，这其中就包括 API 集成（P424）。同时，数据收集的方法也包含 API 调用（P476），并且 API 能够支持从数据库、云服务或第三方应用自动检索数据，无需人工干预（P480）。综合这些教材表述，API 最本质的功能就是充当不同软件之间的桥梁。题干问 API 能够「实现」什么，选项 B「不同的应用程序用于连接和通信」正好精准对应了这个最基础的互连互通功能。其他选项描述的都是在此连接能力基础上，由特定上层应用（如数字身份系统、AI引擎、客户分析工具）才能完成的特定业务场景，并非API本身的定义。
教材原句："Screening systems should be compatible with other systems. This includes data flows, workflow management tools, and application programming interface (API) integrations."

A项错误：教材在讨论数字身份时，确实提到了移动设备（P404），但阐述的核心是政府电子身份系统与金融机构流程的整合，并未明确将「移动设备上的数字身份识别」归结为API的直接功能。API更基础的角色是打通数据通路，而非直接执行身份识别这一具体任务，因此B比A更直接地匹配API的本质定义。
C项错误：教材提到金融机构会使用AI和生物识别技术来验证客户（P408，P374），但这些技术是独立的身份验证手段。API的作用是连接和调用这些技术模块，而不是直接等同于「通过AI和生物识别技术进行身份验证」这个身份验证功能本身。题干问的是API本身的功能，因此B的「连接与通信」比C更接近API的底层定义。
D项错误：客户细分和客户特征分析（CDD）是客户准入流程中的特定业务环节（P374）。教材表明这些流程会用到数据，而API负责从源头系统和第三方自动检索和传输这些数据（P480）。API是实现数据流通的通道，而非直接执行「快速客户细分和特征分析」的分析工具，因此B的功能描述更为通用和基础。

易错提醒：避免将API（连接工具）和它支撑的上层应用（如AI身份验证、数字身份识别）混为一谈。就像水管的作用是送水，而非直接灭火。本题问的是「送水」的功能，而非「灭火」的场景。
