## 这个目录是什么

这是早期围绕“考点确认”做的一组方案文档和小批量 LLM 试验产物。

当时的核心问题是：

> 如何从教材句卡、题库、学生答疑和图谱中，反推出教研可用的考试考点？

该目录里的内容用于探索这个流程，不是当前工作台运行时直接读取的主数据。

## 主要文件

- `考点确认落地计划.md`
  - 早期考点确认工作流设计文档。
  - 其中明确区分了“教材句卡”和“考试考点”：教材句卡只是原文证据，不能直接等同于考点。

- `llm_work_items_qa37.json`
  - 基于 37 条学生答疑整理出的 LLM 待处理工作项。

- `_batch_01_input.txt` 到 `_batch_08_input.txt`
  - 分批发送给 LLM 的输入。

- `_batch_01_output.json` 到 `_batch_08_output.json`
  - LLM 分批返回的考点反推结果。

- `_accuracy_spot_check.txt`
  - 对 LLM 输出结果做的准确性抽查记录。
