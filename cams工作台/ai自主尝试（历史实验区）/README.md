## 这个目录当初在探索什么

### 1. 四角色法雏形

相关文件：

- `run_four_roles.py`
- `test_four_role.py`
- `test_four_role_v2.py`

当时探索的流程是：

```text
AI #1 联想者
→ AI #2 核查员
→ LightRAG / BGE 搜教材
→ AI #3 裁判官
```

关键思想是：

- 允许 AI #1 自由联想，提供搜索方向。
- AI #3 不能看到 AI #1 的回答，只能基于教材证据写最终解析。
- 最终判断必须回到教材原文和 card_id。

这个思想后来发展为正式的“四角色法 / agentic search”流水线。

### 2. 教材知识图谱 / 概念树探索

相关文件：

- `plans/plan_concept_tree.md`
- `step1_annotate_edges.py`
- `step2_card_mount.py`
- `step3_validate.py`
- `kg_snapshot.json`
- `kg_explore.txt`

当时探索的问题是：

```text
能否把教材小节做成节点，
把小节之间的关系做成边，
再让题目选项落到图谱节点上，
帮助教研理解一道题到底考什么。
```

这部分实验为后来的教材句卡、KG 辅助召回和题目证据绑定提供了思路。

### 3. BGE / LightRAG 检索实验

相关文件：

- `build_query_layer.py`
- `run_one.py`
- `batch_179.py`
- `tests/`

这些文件用于尝试：

- 题干和选项如何匹配教材节点。
- BGE 是否能找到正确教材卡片。
- LightRAG 是否适合作为教材证据搜索层。
- 多题批量跑时质量和速度如何。
