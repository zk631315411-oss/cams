# 第六章 6.人口贩卖 习题集

共 1 题

## 第1题 (多选题)根据美国金融犯罪执法网络（FinCEN）的指导，银行账户中的哪些可疑迹象，如果同时出现，可能表明涉及现代奴役、人口贩运和刹削?（请选择两个）

### 选项
- A.与注册的虚拟货币交易所有交易往来
- B.频繁支付在线广告费用或非本地分类广告费用
- C.收到来自第三方支付处理机构的资金转账，但缺乏完整的付款人信息
- D.向外籍农业工人支付大量现金

### 答案
答案:B C

### 解析
解析:【2025真题】
具体知识点:
人口贩卖 (Human Trafficking)
也称为"人口贩运"。 人口贩卖的目的通常是开展性奴役、强制劳动或商业性剥削活动。人口贩卖几乎存在于全球各国，常被称为世界第二大犯罪形式。
选项分析:
选项 B正确，人口贩运者常利用在线广告或非本地分类广告来招募受害者、宣传非法服务（如性交易 ）等。频繁支付这类广告费用，可能是在为人口贩运等非法活动做准备或运作，是可疑迹象之一。
选项 C 正确，缺乏完整付款人信息的第三方支付处理机构资金转账，可能是为了掩盖资金来源，隐瞒非法活动（如人口贩运、剥削活动产生的收入 ）的资金流向，符合可疑特征。
选项 A 错误，与注册的虚拟货币交易所有交易往来本身不一定就与现代奴役、人口贩运和剥削直接相关 。虽然虚拟货币可能被用于洗钱等非法活动，但仅这一点关联性不强。
选项 D错误，向外籍农业工人支付大量现金，可能有多种原因，不一定就意味着涉及现代奴役、人口贩运和剥削 。比如可能是当地支付习惯等因素，不能直接判定为可疑迹象。
