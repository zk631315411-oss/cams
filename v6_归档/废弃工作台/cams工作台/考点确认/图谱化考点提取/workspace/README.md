# Workspace 说明

本目录用于图谱化考点提取流程的工程试验。

目录说明：

- `inputs/`：记录输入资产清单、版本、校验摘要，不直接存放大体积教材文件。
- `intermediate/`：保存中间图谱、候选考点、候选合并对、LLM 原始返回。
- `outputs/`：保存 preview 资产，不直接覆盖工作台正式数据。
- `reports/`：保存构建报告、质量报告、人工复核清单。
- `scripts/`：保存本流程专用脚本。
- `prompts/`：保存候选生成、合并裁判、标题生成等提示词。
- `tests/`：保存五题试跑、回归样例和质量检查脚本。

第一阶段原则：先产出可审计 preview，不写回正式前端资产。
