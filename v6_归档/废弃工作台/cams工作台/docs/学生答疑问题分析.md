# 学生答疑问题分析（初版观察）

> 基于 37 条答疑中前 10 条的详细阅读 + 其余记录的模式扫描。各项结论均属初步观察，需逐条标注后才能做精确统计。

## 一、学生问题类型（初步观察）

从已读记录中观察到五类提问模式，注意类型之间可重叠（一条提问可能同时属于多类）：

| 类型 | 典型问法 | 学生真实困惑 |
|---|---|---|
| **正确答案为什么对** | "为什么是A？""为什么选A正确？" | 看了解析还是没懂，需要更细的推理链 |
| **某个选项为什么不选** | "为什么不选D？""B怎么理解？" | 学生对某个概念有具体误解，需要针对性地拆 |
| **概念/机制不理解** | "巢状交易是？""为什么PEP授权签字人就直接归高风险？" | 教材或解析有概念跳跃，学生没跟上 |
| **教材依据在哪** | 隐含在"为什么"问题中，少数单独问 | 解析说了结论但没说为什么，学生想看原文 |
| **题干/解析本身有疑问** | "题干问的是X，为什么答案不是Y" | 学生可能理解偏了，也可能是解析确实写得不清楚 |

"为什么"类问题占绝对多数，"为什么不选"也反复出现。精确分布需等 37 条逐条标注后补上。

**关键发现**：学生不只是"想要答案"——他们往往已经有了一个自己的理解（可能是错的），然后在那个理解上卡住了。学生不是白纸一张，而是带着推理框架来的。

## 二、教研回答模式

常见结构是"核心考点定位 → 教材依据引用 → 正确选项推理 → 干扰项逐一排除 → 结论"，但并非每条答疑都完整具备所有要素。观察到的几种变体：

| 模式 | 使用场景 | 例子 |
|---|---|---|
| **法律条文驱动** | 题目考法规具体条款 | 答疑3（爱国者法案）：考点→法律依据→条文内容→选项匹配 |
| **概念边界辨析** | 题目考两个易混概念 | 答疑6（隐私政策风险）：区分法律风险 vs 经营/声誉风险 |
| **场景+定义联动** | 题目考场景识别 | 答疑8（处置vs离析）：阶段定义→场景套用→选项排除 |
| **多源证据链** | 教材没有直接写答案，需要多处材料串起来 | 答疑5（为什么不选D）：税收损失+贸易洗钱+空壳公司税务欺诈+黑市比索→证据链 |
| **比喻+解释** | 概念抽象，需要类比 | 答疑9（巢状交易）：套娃比喻→上下游客关系→风险解释 |
| **简短推理** | 概念边界清晰，不需长篇引用 | 有些回答只用几句话区分概念层级，教材依据较弱但逻辑自洽 |

教研的回答质量取决于她能否找到教材里的"根证据"。答疑5信息密度最高，因为她串了四个不同教材小节的证据；答疑6信息密度低，因为这个概念在教材里支撑更弱。

## 三、教材证据需求分析

以下仅基于前 10 条逐条阅读的结果（答疑1-10），不推广到全部 37 条：

| 强度 | 条数 | 例子 | 特征 |
|---|---|---|---|
| **教材充分支撑** | 4 | 答疑8（处置阶段）、答疑3（爱国者法案）、答疑7（PEP风险） | 教材有明确定义或条款，直接引用即可 |
| **教材多处串联可得** | 3 | 答疑5（税问题）、答疑10（代理行尽职调查） | 教材没写在同一段，需要跨节找，组合成证据链 |
| **以推理为主，教材为辅** | 2 | 答疑6（隐私政策风险）、答疑2（资本市场洗钱迹象） | 核心逻辑靠"题干问法+概念定义+排除法"，教材只给了概念框架 |
| **教材术语不直给但相关内容存在** | 1 | 答疑9（巢状交易） | 教材未必叫"巢状交易"，但有代理银行/通汇账户/子账户/嵌套关系等内容，可从相关内容推导 |

**说明**：37 条中各类占比暂无法给出，需要等逐条标注完成。上面 10 条的分布仅作为方向性参考，不做外推。

**对系统设计的意义**：如果只做"教材原文直给"类问题，覆盖不到全部需求。系统必须能处理"跨节推理"和"概念边界辨析"两类问题。同时需要区分"教材术语不直给但可推导"和"教材确实无支撑"——前者系统应尝试推导并标注推导逻辑，后者应标记"教材证据不足"并转教研。

## 四、典型误解点

以下从答疑中提取的误解模式，暂未做频次统计，"高频"的结论待逐条确认后补：

1. **混同不同概念层级**：处置vs离析vs融合（多次被问）、PEP相关概念（多次被问）
2. **把犯罪分子的行为理解成机构行为**："虚假交易要交税"（把洗钱者的行为套到金融机构头上）
3. **不理解术语在特定语境的含义**："公司税的增加"被误解为"洗钱过程中交了税"，但教材说的是"洗钱导致政府税收减少"
4. **选项措辞误导**："代理银行设施的增加"——学生看到"代理银行"关键词就想选，但实际洗钱导致的是代理关系的减少/终止
5. **场景套不进定义**：知道三阶段定义，但给一个具体场景就不会套了
