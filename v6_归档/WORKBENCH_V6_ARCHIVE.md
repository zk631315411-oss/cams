# V6 工作台归档索引

## 定位

v6 是历史教材与教研资产档案，仅用于追溯已有结论、核对历史题目和必要时重现旧研究。v6 不再是正式工作台运行依赖，也不得作为 v7 题目、解析或考点的正式教材依据。

## 保留内容

- `重构版数据/`：历史工作台数据样本和构建记录。
- `习题/v6/`：v6 结构化练习题与原始材料。
- 根工作区中的 v6 原文、历史知识图谱和一次性工具：按其现有位置保留，不复制、不补建。

## 已废弃的运行责任

以下 v6 派生资产不再恢复为产品能力：句卡运行池、题目-句卡映射、正式考点映射和句卡-考点映射。它们的缺失不能由工作台静默降级掩盖，也不应阻塞 v7 发布。

## 边界

- v7 前端和发布包中不得出现 `v6s_N*` 或其他 v6 句卡标识。
- v7 证据必须链接到冻结的 `v7u_N*` 双语知识单元。
- 对 v6 内容的引用必须标记为历史背景，不能与 v7 教材依据混合展示。
