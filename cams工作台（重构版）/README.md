# 重构工作区资产地图

本目录混合保存 V7 正式内容生产链、V6 历史数据、早期前端和审核原型。正式工作台应用已经迁至同级目录 `D:/守正公司工作区/cams考试工作台（正式版）/`，本目录不再提供正式产品入口。

| 目录 | 定位 |
|---|---|
| `v7/` | V7 教材单元、检索索引、KG、395 题证据与解析生产链 |
| `content/` | `workbench-v2` 的历史导入快照，不是解析母版 |
| `data/` | V6 和旧工作台数据池，不得作为 V7 正式依据 |
| `frontend/` | 旧 V7 教材阅读与审核原型 |
| `workbench-v2/` | FastAPI + React 审核 MVP 历史原型 |
| `services/` | 依赖 V6 句卡池的实验 API，当前不可作为正式服务 |
| `tools/` | V7 历史发布工具、V6 研究工具及辅助脚本 |
| `重要资产以及构建方式/` | V6 资产样本副本与历史构建说明 |

正式内容边界和数量见仓库根目录 `项目交接/正式资产与SOP索引.md`。
