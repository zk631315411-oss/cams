## Theme convergence for s6

| Theme | Evidence pattern in this scan | s6 implication |
|---|---|---|
| Correct-answer-only feedback is insufficient for transfer | Directly supported by explanation-feedback and transfer/testing literature; needs full-text confirmation for exact conditions. | s6 should write reasoning, not just answer. |
| Distractors matter in MCQ learning | Direct MCQ feedback literature indicates wrong options can have learning effects. | s6 needs option-level positive/negative evidence and why distractors fail. |
| Explanation must be task-focused | Feedback frameworks warn that feedback can fail when it shifts attention away from the task. | s6 should focus on题干信号, 教材规则, and option comparison. |
| Transfer requires an explicit rule or process | Retrieval-practice and worked-example sources point toward process/rule extraction. | s6 should include “类似题怎么判断”. |
| More information is not always better | Cognitive-load sources and formative-feedback sources suggest complexity management. | s6 should separate core explanation from expanded evidence/micro-textbook. |
| Learners need self-diagnosis | Self-regulated feedback and metacognitive-error literature support feedback that helps learners locate the error. | s6 should include “你为什么容易错/错在什么判断环节”. |
