# Notes for s6 explanation design

这些是从本轮文献扫描得到的设计假设，后续需要用 CAMS 题目、v6 解析、参考解析和真实/模拟考生反馈验证。

## 1. s6 的目标应从“写解析”改成“帮助考生完成错题复盘”

为了通过考试而刷题的考生，最关心的不是教材全貌，而是：

- 这题到底考什么？
- 题干里哪个词决定了判断方向？
- 正确项强在哪里？
- 干扰项为什么不够好，错在事实、范围、顺序、程度，还是题干限定？
- 下次遇到类似题，应该先看什么、排除什么？

因此 s6 解析的最小闭环应是：`考点 -> 题干信号 -> 判断链 -> 选项比较 -> 易错点 -> 迁移规则 -> 依据`。

## 2. 裁判结果和学习解析要分开，但解析必须继承裁判证据

s4 裁判回答的是“根据证据哪个选项成立”。s6 回答的是“考生如何理解这道题并迁移到下一题”。两者不是同一个输出，但 s6 不能脱离 s4/s3 的证据重新发挥。

建议 s6 输入至少包括：

- s4 的盲判答案和选项判定。
- s3 的召回文本，包括教材片段、KG 路径、边关系微缩教材。
- s5 的冲突标记：AI-参考答案是否冲突，中英参考是否冲突。
- 可选：参考答案、参考解析、v6 风格样例。

## 3. 解析应先短后长，避免把 KG 证据直接堆给考生

认知负荷相关文献提醒我们，更多信息不等于更好反馈。对 markdown 输出，可以采用两层结构：

第一层：考试作答层。

- 答案。
- 本题考点。
- 一句话判断。
- 关键题干信号。
- 各选项为什么对/错。
- 下次判断规则。

第二层：依据层。

- 教材依据。
- KG 路径依据。
- 正反证据表。
- 与参考解析冲突时的冲突说明。

## 4. 选项解析要写“强弱比较”，而不是孤立写对错

选择题学习的关键是干扰项。尤其 CAMS 题目常见“相关但不是最佳”“后续措施但不是初步措施”“控制存在但不一定有效”“概念相近但边界不同”。

建议选项表增加字段：

| 字段 | 作用 |
|---|---|
| 判定 | 正确/错误/存疑 |
| 依据 | 教材 unit、KG 路径或参考解析 |
| 为什么成立/不成立 | 直接对准题干限定 |
| 干扰类型 | 范围错、方向错、程度过强、时序错、概念偷换、相关但非最佳 |
| 与正确项比较 | 说明正确项更强在哪里 |

## 5. “类似题怎么判断”应成为稳定模块

检索练习和迁移相关文献提示，考生需要把本题经验变成下一题可用的判断规则。s6 解析末尾建议固定输出：

- 看到哪些题干词时触发该规则。
- 先排除哪类说法。
- 正确项通常满足什么条件。
- 高风险干扰项通常长什么样。

这部分不宜太长，最好控制在 2-4 条可操作规则。

## 6. s6 后续可测试的解析模板

```md
## 第 N 题

### 答案
答案：X

### 本题考点
一句话说明考点。

### 解题思路
1. 题干信号：...
2. 教材规则：...
3. 判断结论：...

### 选项依据与解析
| 选项 | 判定 | 依据 | 为什么 |
|---|---|---|---|
| A | 错误 | ... | ... |
| B | 正确 | ... | ... |

### 易错点
说明最容易误选的选项及其干扰原因。

### 下次遇到类似题
- 规则 1
- 规则 2

### 依据摘录
- 教材依据：...
- KG 路径：A --关系--> B --关系--> C
- 参考解析冲突：无/有，说明...
```

## 7. 待验证问题

- 解析越详细是否真的更好，还是会拖慢刷题效率？
- CAMS 考生更需要“教材依据”还是“考试判断规则”？比例是多少？
- 多选题是否需要不同模板？
- 与参考答案冲突时，是否应先显示冲突，还是放到依据层？
- KG 路径应展示多少条才既可信又不干扰阅读？
- v6 教研解析里哪些“教师经验判断”是教材/KG无法直接召回但考生很需要的？
