# s5：判定评估

s5 是判定评估层。

它在盲审判定完成后，将 s4 的盲审输出与参考材料进行对比。

## 定位

- s4 在不参考参考材料的情况下生成盲审结构化判定。
- s5 将这些判定与参考答案进行对比，必要时还与参考解析对比。
- s6 单独研究面向学员的解析生成。

## 目标

衡量盲审判定结果是否与可用参考材料一致。

s5 可追踪：

- AI 预测答案
- 参考答案
- 答案一致或冲突
- 参考答案冲突（如存在多个参考来源）
- 选项级判定一致性
- 对比过程中发现的证据缺口

## 边界

- 不涉及 BGE/BM25 搜索。
- 不涉及知识图谱扩展。
- 不做新的盲审判定。
- 不编写面向学员的解析。
- 不将参考答案反馈回 s4 输出。

## 状态

目前仅定义了阶段契约。具体的评估 schema、参考来源优先级和报告格式将后续设计。
