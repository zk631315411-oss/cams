# p3-ch11-h3 题库软件版解析预览

可导出题目数：3

教材章节：未映射

题型：single

题干：大量汇入的电汇交易触发对某客户的警报.资金随即通过现金提取和汇出交易被迅速转走.要调查此警报/案例,应首先审查哪些信息？


选项：

- A. 开源信息
- B. 客户概况
- C. 不良媒体搜索
- D. 账户活动

答案：B

解析：

考点：**警报初查时优先利用客户画像判断活动是否符合预期**

核心解析：警报审查的第一阶段，分析师会综合评估警报性质、交易类型、客户资料、账户历史等数据点，以判断**警报是否有效**（P334）。客户概况提供客户业务性质、风险因素和**预期交易行为**等基线信息（P307、P337），有助于判断题干所述大量汇入后迅速转出的活动是否符合客户背景。因此，在给定选项中，B项最适合作为初步判断的基线。教材将客户概况与账户历史等并列为审查信息，并未明确规定两者在所有调查中必须遵循固定先后顺序；实际调查通常还需要结合账户活动共同判断。

教材原句："An analyst examines the alert’s validity by evaluating various data points, including the alert's nature, transaction type, customer profile, account history, and previous alert history."

A项错误：开源信息可补充客户背景并帮助识别风险信号（P337），但与题干所问的初步审查相比，客户概况更直接提供预期活动和业务性质等判断基线。
C项错误：不良媒体搜索可以补充风险信息，在教材中也常见于强化尽职调查（EDD）等场景（P310、P322）。但题干首先需要判断交易模式是否符合客户背景，B项与这一目的更直接相关。
D项错误：账户活动是区分典型与异常行为的重要数据点（P337），实际调查中通常需要审查。题干已概述触发警报的账户活动，而B项可补充判断这些活动是否符合客户背景的基线，因此在本题的选项比较中更合适。

易错提醒：“账户历史与活动”和“客户概况”都是警报审查的重要信息：前者反映实际交易，后者提供业务性质和预期活动等判断基线。本题选择B，是因为题干已经概述了异常交易模式，而客户概况更能补充比较基准；不要据此理解为所有调查都必须机械地先查客户概况、后查账户活动。

教材章节：未映射

题型：single

题干：一家金融机构的交易监控系统发现，一个小型企业账户发起的国际电汇数量异常增多，这些电汇被汇往多个监管宽松的司法管辖区。此外，一名员工在客户到访时报告称，该账户持有人有可疑行为，其要求提取大额现金，却未给出合理的商业理由。作为调查的一部分，合规团队必须评估这些活动是否可疑，并确定下一步的适当行动。在调查过程中，为了妥善收集信息并评估交易是否可疑，首先应采取以下哪一步骤？


选项：

- A. 查看该账户的交易记录，以识别相关模式，包括电汇的频率、目的地和用途
- B. 通知高级管理层，并建议关闭账户以规避潜在风险
- C. 立即根据员工报告的可疑行为提交可疑活动报告（SAR）
- D. 直接联系客户，询问其大额现金支取的原因

答案：A

解析：

考点：**调查阶段的首要步骤是分析交易模式与历史数据**

核心解析：在一个交易监控警报被触发并升级后，会进入**二级审查即调查阶段**。在这个阶段，分析师的核心任务是对警报和数据进行详细分析，以判断异常行为是否可能指向金融犯罪（P334）。教材列举了该阶段包含的具体动作，首项便是**分析交易模式和频率**（P334）。此外，在升级调查以确认和报告可疑之前，分析师还应审查同一账户或客户的过往交易模式（P337）。题干给出的场景正是一个已经触发了预警、正在被调查的企业账户：系统发现其国际电汇数量异常增多并汇往多个监管宽松的司法管辖区，同时员工也报告了客户的可疑行为。这明确进入了需要深入分析的调查阶段。据此，第一步应当调取并审查该账户的交易历史，去识别电汇的频率、目的地、用途等模式，以判断这些活动是否符合客户的预期行为模式。选项A完整对应了调查阶段首步的规范要求。

教材原句："During the Level 2 review, or investigation stage, analysts perform a detailed analysis of the alert and data from the initial review to establish whether the unusual behavior could indicate a financial crime."

B项错误：“通知高级管理层并建议关闭账户”涉及的是风险决策和账户处置。题干目前尚处于判断交易是否可疑的调查初期，直接跳到关闭账户的处置阶段，与调查流程的先后顺序不匹配（P334、P357）。
C项错误：“立即提交可疑活动报告”跳过了关键的审查环节。教材规定，发现异常活动后，必须先审查案件事实，然后才能决定是否提交SAR（P357）。员工现场报告的可疑行为是重要线索，但它本身代替不了对交易数据的系统性调查。立即提交SAR不符合“先调查、再决策”的程序逻辑，调查阶段的分析（如审查交易模式）才是决定是否提交SAR的前提（P334）。
D项错误：“直接联系客户询问原因”可以是后续获取信息的手段，但在调查初期，合规团队应先利用交易记录和客户历史等内部数据完成初步分析。在尚未掌握完整交易背景时联系客户，可能使潜在调查对象提前察觉调查。因此，先审查交易历史更符合调查顺序。

教材章节：未映射

题型：multiple

题干：金融行业在交易监控方面高度依赖基于规则的方法来发现可疑活动.基于场景的系统利用技术和算法来识别:（选择三项。）


选项：

- A. 涉及被盗或伪造身份证明的欺诈性身份。
- B. 涉及在一天中不寻常时间发生的交易的可疑行为。
- C. 隐藏的实际受益人。
- D. 涉及超过一定金额的交易的交易模式。
- E. 涉及在远离客户通常消费地点发生的交易的异常情况。

答案：B、D、E

解析：

考点：理解交易监控场景的典型识别对象与行为维度

核心解析：交易监控场景（scenarios）是对交易进行分析以生成警报的规则框架，其分析因素包括行业规模、司法管辖区和客户活动，且场景可从简单到复杂（P333、P442）。典型的监控场景既要覆盖“超过特定金额的交易”这类基于金额阈值的简单规则，也关注**偏离客户正常行为参数的交易活动**——当客户活动超出其正常参数时系统便生成警报（P333、P328）。题干中B项“一天中不寻常时间发生的交易”、D项“超过一定金额的交易”和E项“远离客户通常消费地点发生的交易”，恰好分别对应教材所述场景可识别的三个维度：交易金额的阈值监控、交易时间的异常偏离、以及交易地点的地理异常。这些均是基于场景的系统通过技术和算法可直接捕捉的交易行为特征。

教材原句："For example, one rule identified all transactions above a specific monetary amount."（P333）

A项错误：欺诈性身份更多属于客户尽职调查中的身份验证风险，例如远程开户可能被假身份利用（P63）。交易监控场景主要识别资金流和交易行为异常，而不是直接验证账户持有人身份的真实性。
C项错误：隐藏的实际受益人确实构成洗钱风险，但识别隐藏所有权结构更依赖受益所有权信息和实体尽职调查中的穿透分析（P298）。交易监控场景主要关注金额、频率、时间和地点等可量化的交易行为参数。

易错提醒：交易监控场景识别的是“交易行为本身的异常模式”（金额异常、时间异常、地点异常）（P333、P442），而非“账户持有人的身份问题”（盗用身份、隐藏受益人）。身份欺诈和隐藏受益人是洗钱风险要素，但它们分别由CDD和受益所有人报告制度来应对（P63、P298），不是transaction monitoring scenario的直接输出对象。
