英文题干：According to FinCEN, when a financial institution (FI) identifies suspicious activity that necessitates a suspicious activity report (SAR) filing, the SAR supporting documentation should: (Select Two.)

选项：

- A. 包括所有协助FI作出该活动需要提交申报这一决定的文件或记录.
  English: Include all documents or records that assisted the FI in making the determination that the activity required a filing
- B. 始终仅限于账户名称、账户详情和交易记录.
  English: Always be limited to account name, account details, and transaction records
- C. 制定了维护支持性文件的政策和程序.
  English: Have written policies and procedures to maintain supporting documentation
- D. 保存在一个单独的文件中,并将纸质副本存放在防火柜里.
  English: Be saved in a single separate file with hard copies stored in a fireproof cabinet

## 【AI答案】

A、C

## 【考点】

**SAR 支持性文件的合规范围与政策要求**

## 【核心解析】

教材要求，SAR 应包含客户信息、机构服务、交易活动、怀疑理由及任何支持性证据（P353）。同时，在作出是否提交 SAR 的风险决策时，必须彻底记录调查发现及决策理由（P358）。据此，题干问 SAR 支持性文件「应」如何，核心指向两个层面：一是范围上，**所有协助作出提交决定的文件或记录都应纳入**——对应选项 A；二是制度上，机构必须有**维护这些文件的书面政策和程序**——对应选项 C。二者共同反映了 FinCEN 对 SAR 文件完整性及流程规范性的双重要求。

教材原句："You should include information about the customer, services offered by the institution, transaction activity, rationale for suspicions, and any supporting evidence."

## 【错误项分析】

- **B 错误（题干对照）｜范围或程度偏差**：教材列举的 SAR 内容远不止账户名称、账户详情和交易记录，还包括怀疑理由及任何支持证据（P353）。选项 B 用「Always be limited to」将文件范围锁定为三项，与教材「any supporting evidence」的开放表述矛盾。题干问的是支持性文件的合规范围，教材更直接支持 A 的全口径要求而非 B 的限定清单。
- **D 错误（题干对照）｜证据不足**：教材要求文档按照机构的记录保留政策保存（如 PDF、打印件等形式）（P345），并要求妥善安全存储以遵守隐私法和数据安全要求（P345），但未指定「单独文件」或「防火柜」等具体物理形式。选项 D 将合规性落脚于特定存储安排，而题干更直接匹配 A 的内容范围和 C 的制度程序要求。
