# v7_q_000001

教材章节：未映射

题型：single

题干：一名反洗钱合规官收到了一份独立审计报告，其中包含若干发现。对这份报告的恰当回应应包括:

英文题干：An AML compliance officer receives an independent audit report with a number of findings. An appropriate response to the report would include:

选项：

- A. 为审计团队起草详细的行动计划，以落实整改意见
  English: Drafting detailed action plans for the audit team to execute to close the findings
- B. 重新对审计发现中提及的控制措施进行测试，以确认审计结果
  English: Reperforming the testing for the controls mentioned in the findings to confirm the results of the audit
- C. 根据调查结果的根本原因分析来确定补救措施
  English: Defining remedial actions based on the findings' root cause analysis
- D. 将审查行动计划的责任分配给董事会
  English: Assigning responsibility for reviewing the action plan to the board of directors

答案：C

解析：

考点：收到审计发现后应优先分析根本原因再定补救措施

核心解析：教材规定，当控制出现缺失或错误时，「组织必须分析并纠正错误的根本原因以避免再次发生」（P279）。题干中反洗钱合规官收到独立审计报告，报告内包含若干发现——这正是控制可能失效或存在缺口的情形。此时恰当的回应不是立即为审计团队起草计划，也不是自行重新测试审计结论，更不是直接把审查责任推给董事会，而是先根据发现进行「根本原因分析」（root cause analysis），再据此确定补救措施。选项C直接对应这条规则，从分析到补救的路径与教材一致。
教材原句："The organization must analyze and correct the root cause of the error to avoid recurrence."

A项错误：教材提到审计后可与内部审计持续沟通以制定行动计划（P258），但行动计划的制定和实施主体是反洗钱合规团队自身，而非为审计团队起草。选项A将行动计划的起草对象指向审计团队，与教材强调的「反洗钱合规团队可及时实施改进」的职责定位不吻合，因此比起C项的直接根本原因分析回应，A的匹配度更弱。
B项错误：重新对审计发现中的控制进行测试属于确认审计结果的程序，通常由内部审计或合规测试职能负责（P251提及合规测试职能进行QA审查）。题干中的反洗钱合规官处于收到审计报告后的回应角色，更合理的做法是基于审计发现去分析根源和设计补救，而非重复验证审计结论的准确性。
D项错误：董事会负有监督反洗钱计划有效性和确保缺陷被及时解决的最终责任（P259‑260），但这并不意味着日常将「审查行动计划」的责任全部分配给董事会。行动计划更常由业务负责人、运营负责人具体执行和审查，董事会关注战略方向和重大缺陷。教材中董事会角色侧重于批准风险偏好和确保项目获得资源，其监督性质与选项D所述的直接审查责任分配相比，C项在程序阶段上更贴合合规官收到报告后的直接行动。

易错提醒：容易将「制定行动计划」视作收到审计报告的常规回应，但教材框架下，行动计划来源于对发现的分析，尤其是根本原因分析（P279）。没有分析直接制定计划可能治标不治本，而先分析根本原因再确定补救措施，才是教材所强调的正确顺序。
