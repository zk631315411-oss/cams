## 初步观察

- 竞品解析普遍偏短，常见结构是“知识点/规则 + 正确项理由 + 错误项一句排除”。
- 多选题通常把多个正确项合并说明，再集中排除错误项；阅读速度快，但错因分类不够细。
- “易错提醒”和“口诀”会出现，但不是稳定模块，更多像结尾补一句。
- 很少单独拆出“题干信号”“判断链条”“下次怎么判断”。这正是 s6 可以做得更清晰的方向。
