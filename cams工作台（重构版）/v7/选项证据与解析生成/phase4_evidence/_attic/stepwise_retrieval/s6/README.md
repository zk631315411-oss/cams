# s6：面向学员的解析生成研究

s6 是解析编写研究层。

它在检索、知识图谱扩展、召回文本渲染、盲审判定和评估分离之后，研究如何为学员编写解析。

## 定位

- s4 通过盲审判定做决策。
- s5 将判定结果与参考材料对比。
- s6 研究如何为学员编写有用的解析。

## 目标

生成或研究最终考试风格的解析，作为独立任务。

s6 后续可考虑：

- s4 判定结果
- s5 评估结果
- s3 渲染的召回文本
- 参考答案和参考解析
- 额外的教学上下文
- 双语术语或来源引用

## 边界

- 不涉及 BGE/BM25 搜索。
- 不涉及知识图谱扩展。
- 不替代盲审判定。
- 不隐藏 AI 判定与参考材料之间的冲突。
- 不将解析风格研究混入 s4 判定。

## 状态

已初步确定面向学员的解析结构。后续提示词、评估表和样例库应围绕本结构迭代。

## 默认解析结构

s6 解析采用“双层结构”：先给学员一个能快速理解的短结论，再给可展开的推理、选项错因和原文依据。目标不是把解析写长，而是把“为什么这样判断”写清楚。

默认模块如下：

```text
【答案】A

【一句话结论】
用 1-2 句话说明本题考什么、为什么该答案成立。

【题干信号】
- 场景：题目发生在什么业务/监管/调查场景
- 关键条件：题干中真正影响答案的限制词、程度词、主体、时序
- 问法：题目问的是最佳措施、首要步骤、风险来源、定义识别，还是例外边界

【推理过程】
把题干信号连成判断链，说明从题干到答案的推理路径。

【选项分析】
A 正确/错误：说明击中或偏离了哪个判断点。
B 正确/错误：说明错因，不只说“不符合题意”。
C 正确/错误：说明错因。
D 正确/错误：说明错因。

【原文依据】
引用或概括最相关的教材、考纲、法规、标准或证据片段，并说明它如何支持本题判断。

【下次怎么判断】
给出可迁移规则，帮助学员遇到同类题时知道先看什么、排除什么。
```

## 模块写法

### 答案

- 第一行直接给答案，不绕弯。
- 多选题写成 `【答案】A、C、D`，不要只写字母串。
- 如果答案存在冲突或来源不一致，在答案后标注“需复核”或“存在答案冲突”，不要用解析掩盖冲突。

### 一句话结论

- 面向快速刷题场景，控制在 1-2 句话。
- 必须同时回答两件事：本题考点是什么，为什么答案成立。
- 不写空泛句，例如“本题考查相关知识点”“其他选项不符合要求”。

### 题干信号

这是 s6 区别于普通题库解析的关键模块。很多学员错题不是因为完全不会知识点，而是没有识别题干中真正起决定作用的信号。

优先提取：

- 主体：金融机构、合规官、监管机构、FIU、执法机关、客户、第三方服务商。
- 场景：开户、CDD/EDD、交易监控、调查响应、制裁筛查、EWRA、PPP、SAR/STR、跨境信息共享。
- 问法：最有效、首要、最符合、可疑迹象、可靠来源、例外情形、允许/要求。
- 程度词：high、moderate、robust、sophisticated、solely、all、completely、directly。
- 时序：发现问题后、收到报告后、开户前、交易后、上报前。

### 推理过程

- 写“判断链”，不要堆概念。
- 对相近选项题，必须解释为什么一个更优而另一个只是有吸引力。
- 对场景题，必须说明题干事实如何触发规则。

推荐写法：

```text
题干给出 A 条件；根据 B 规则，A 会导致 C 判断；因此正确选项应当满足 D，而不是 E。
```

### 选项分析

选项分析要写出错因类型。常见错因包括：

- 主体错：把监管机构职责写成金融机构职责，或反过来。
- 时序错：把后续措施当作首要步骤。
- 程度过度：把“降低风险”写成“完全消除风险”。
- 范围过窄：只覆盖题干一部分，没有覆盖全部条件。
- 范围过宽：把有限授权扩展成无限披露或无限共享。
- 忽略题干限制：没有处理题干中的 jurisdiction、customer type、risk level、existing controls 等限制。
- 概念混淆：混淆固有风险与剩余风险、CDD 与 EDD、OSINT 与单一公开来源、制裁筛查与客户风险评级。
- 风险关联弱：选项本身可能正确，但与本题问法或风险链条关系不够直接。

### 原文依据

- 依据要短而准，不做长篇资料摘录。
- 优先引用教材/考纲/法规/标准中的判断规则，而不是只引用定义。
- 引用后必须加一句“与本题的连接”，说明为什么这条依据能支持答案。
- 如果原文依据不足、冲突或无法覆盖答案，应明确写出“证据不足/需复核”。

### 下次怎么判断

- 用一句可迁移规则收尾。
- 重点写“以后遇到同类题先看什么”。
- 不写鸡汤式鼓励，不重复答案。

## 长短控制

s6 解析不追求所有题同样长。按风险分层：

| 题型/风险 | 建议长度 | 写法 |
|---|---:|---|
| 低争议定义题 | 120-200 字 | 答案 + 一句话结论 + 简短选项分析 |
| 普通单选场景题 | 250-450 字 | 补齐题干信号和推理过程 |
| 多选题 | 400-700 字 | 每个正确项说明入选条件，每个错误项说明排除原因 |
| 相近选项题 | 450-800 字 | 重点解释选项间程度、范围、时序差异 |
| 答案冲突/证据不足题 | 不限硬字数 | 明确冲突点、依据强弱和复核建议 |

默认前台可以采用“学生版 + 展开依据版”：

- 学生版：答案、一句话结论、题干信号、选项分析、下次怎么判断。
- 展开依据版：完整推理过程、原文依据、证据来源、冲突说明。

## 可压缩版本

并不是每道题都必须完整展开七个模块。低争议、低复杂度题可以压缩，但不能丢掉“判断为什么成立”。

### 最小可用版

适用于低争议定义题、直接考规则的单选题：

```text
【答案】A

【一句话结论】
说明本题考点和答案成立原因。

【选项分析】
正确项为什么对；主要干扰项为什么错。

【下次怎么判断】
一句可迁移规则。
```

### 标准版

适用于普通场景题、相近选项题、多选题、错题复盘题：使用默认七模块。

### 复核版

适用于答案冲突、证据不足、题目翻译不一致、原文支持弱的题：在标准版基础上必须增加“冲突说明/复核建议”，并明确说明当前答案的可信度边界。

## 成稿检查清单

每条解析交付前至少检查以下事项：

- 是否第一行直接给出答案。
- 是否用一句话说清楚本题真正考什么。
- 是否提取了影响答案的题干信号，而不是复述整道题。
- 是否写出了从题干到答案的判断链。
- 是否逐项说明正确项和错误项，错误项是否有明确错因。
- 是否给出教材、考纲、法规、标准或召回证据中的关键依据。
- 是否说明依据与本题判断之间的关系。
- 是否在答案冲突、证据不足时诚实标注，不用漂亮话掩盖问题。
- 是否用“下次怎么判断”沉淀一条可迁移规则。

## 012 示例骨架

题目：`CAMS-V7-0012`。企业范围风险评估中，私人银行部门固有风险较高，但已实施严格 CDD、EDD 和先进交易监控，问这些控制措施如何影响剩余风险。

```text
【答案】A（需结合答案冲突标记复核）

【一句话结论】
本题考查 EWRA 中“固有风险、控制措施、剩余风险”的关系。题干已给出严格 CDD/EDD 和先进交易监控，因此这些控制会有效缓释私人银行的高固有风险，使剩余风险显著降低，但不会完全消除。

【题干信号】
- 场景：全企业范围风险评估（EWRA）
- 固有风险：私人银行客户高净值、财务结构复杂
- 控制措施：严格 CDD、EDD、先进交易监控
- 问法：控制措施如何影响剩余风险

【推理过程】
剩余风险不是业务本身的固有风险，而是在考虑控制措施有效性之后仍然存在的风险。题干已经明确给出多项强控制措施，因此不能只按“私人银行天然高风险”判断，也不能认为风险被完全消除。合理判断是：控制措施有效缓释风险，使剩余风险明显下降。

【选项分析】
A 正确。它体现了控制措施有效时，剩余风险会显著下降。
B 不优。它说“适度降低且仍需进一步控制”，语气偏保守；如果题干没有强调控制有效性，B 会更有吸引力，但本题已明确给出 robust CDD/EDD 和 sophisticated monitoring。
C 错误。它只看到私人银行固有风险高，忽略了题干中的控制措施。
D 错误。控制措施只能降低风险，不能完全消除所有潜在风险。

【原文依据】
风险基础方法下，剩余风险是在固有风险基础上考虑控制措施有效性之后的风险水平。CDD、EDD、交易监控属于缓释客户和交易风险的重要控制措施，但不能将风险降为零。

【下次怎么判断】
看到 “inherent risk + controls + residual risk” 类题，先区分三层：业务本身风险、控制是否有效、控制后还剩多少风险。不要把固有风险直接等同于剩余风险。
```

## 与竞品写法的取舍

竞品解析的优点是短、快、答案导向强；缺点是常停留在“解释答案”，没有充分展示题干信号、判断链条和错因分类。

s6 的取舍：

- 保留竞品的直接性：先给答案和短结论。
- 补足教学性：必须写题干信号、推理过程、错因类型。
- 补足可信度：关键题必须给原文依据或证据来源。
- 补足复盘价值：用“下次怎么判断”形成迁移规则。
