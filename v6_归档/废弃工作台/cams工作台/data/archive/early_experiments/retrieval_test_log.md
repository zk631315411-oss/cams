## 检索成功的关键因素

1. **多锚点拆分**：10个锚点分别检索，比合成一个大 query 更精确
2. **Embedding 补漏**：BM25 靠字面，Embedding 靠语义，两路互补
3. **字符 n-gram**：不依赖 jieba 分词，专业词（"黑市比索"）不会拆散
4. **全章语料**：不限制章节范围，跨节证据（黑市比索在 2.5）顺利召回
5. **人工锚点质量**：锚点覆盖了教研推理链的全部关键词

## 发现的问题

### 问题1：短 citation 卡片污染 top 结果
- v6_b02_N29 (#2): citation = "税收损失" (4 字)
- v6_b02_N30 (#7): citation = "私有化的风险" (6 字)
- v6_b02_N24 (#9): citation = "损害合法的私营机构" (9 字)

**原因**：这些卡片的 knowledge 字段有完整描述，citation 只是章节标题。
knowledge 参与了 BM25 和 Embedding 匹配，但 citation 无法作为独立证据。
**影响**：占用了 3/15 的位置，且如果 LLM 直接用 citation 生成回答会出错。
**改进**：检索前排除 citation < 20 字的卡片，单独保留为概念索引。

### 问题2：E3 虚假发票/税务欺诈命中偏弱
只通过"空壳公司"命中，缺少"虚假发票""税务欺诈""增值税链条"的独立命中。
**原因**：v6_b33_N23 (VAT链条) 和 v6_b33_N25 (税务欺诈) 两卡在排序中不够高，
被 v6_b32_N19 (空壳公司降低透明度) 挤掉。原因是 "空壳公司" 作为高频锚点匹配了更多卡片。
**改进**：锚点需要进一步区分——"虚假发票"和"空壳公司"应拆为独立锚点，各自跑检索。

### 问题3：噪声全是 2.1 同区域宏观影响内容
v6_b02_N30 (私有化风险)、v6_b02_N24 (损害私菅机构)、v6_b03_N16 (低质量投资)
都是 2.1 "洗钱未被查出的宏观影响"系列卡片，被"税收""洗钱"等通用锚点带进来。
**原因**：BM25 对高频出现在同区域的概念区分度不足。
**改进**：BM25 对章节锚点加权，或用卡片 type 字段做后置过滤。

### 问题4：v6_b29_N05 (操纵贸易价格=洗钱避税) 未进 top-15
这是教研原话"操纵贸易价格的做法表明存在洗钱、避税活动"的精确来源，
但排序低于 v6_b32 系列（其 citation 更长、匹配锚点更多）。
**原因**：RRF 对匹配多锚点的卡片天然有利。v6_b29_N05 只匹配了锚点7，
而 v6_b32 系列同时匹配了锚点7和锚点9。
**改进**：在评估时不应只看 top-15 是否包含证据，还应检查"最精确匹配"
的排名是否因策略而被压低。

### 问题5（隐患）：人工锚点 vs LLM 锚点差距未知
本次用了高质量人工锚点。LLM 生成的锚点质量可能更低（漏扩展、扩展错误）。
这需要在下一步用 LLM 实际拆题来验证。

## 下一步建议

1. **卡片预过滤**：排除 citation < 20 字的索引卡片，减少噪声
2. **E3 锚点拆分**：把"虚假发票""税务欺诈""增值税"各自独立为锚点
3. **换 LLM 生成锚点**：用 DeepSeek v4-pro 实际拆题，对比人工锚点的召回差距
4. **增加"最精确匹配"追踪**：记录每个证据区域的最佳匹配排名，不止看整体覆盖
5. **考虑对 type=分类 的卡片降权**：减少章节标题/列表项类卡片的噪声

## 结论

混合检索（BM25 + Embedding + RRF）在人工锚点条件下，能完整召回 2.1_19 D 选项所需的四段跨节证据。
下一风险点不是"搜不搜得到"，而是"LLM 能不能生成足够覆盖的锚点"。

# 第二次测试：修复 + LLM 锚点对比

## 修复内容
- 排除 citation < 20 字的索引卡片（1950→1714 张）
- E3 锚点拆分为 3 个独立锚点（空壳公司/虚假发票/税务欺诈各自独立）
- 添加每证据区最佳匹配排名追踪（含 E3 子关键词独立追踪）

## 人工锚点结果（修复后）

| 指标 | 结果 | 阈值 | 通过 |
|---|---|---|---|
| 教研证据召回 | 3/4 | >= 3/4 | ✓ |
| 噪声 | 4/15 (27%) | <= 7/15 | ✓ |

### E3 拆分效果

| E3 子证据 | 修复前 | 修复后 |
|---|---|---|
| 空壳公司 | #13 (top-15) | #8 (top-15) |
| 虚假发票 | 未命中 | **#3 (top-15)** |
| 税务欺诈/VAT | 未命中 | #24 (top-50) |

拆分锚点后"虚假发票"从完全漏召变为排名 #3，效果显著。
"税务欺诈/VAT"仍在 #24，需要进一步优化或增加锚点。

### E4 轻微退化
黑市比索从 #11 降到 #18，差 3 位未进 top-15。
原因：锚点拆分增加了 RRF 列表数量（12→24），对只匹配少量锚点的证据不友好。
**但这在可接受范围内**——卡片仍在 top-50 中，只是排序被多锚点命中的卡片挤掉。

## LLM 锚点结果

| 指标 | 结果 | 阈值 | 通过 |
|---|---|---|---|
| 教研证据召回 | 2/4 | >= 3/4 | **✗** |
| 噪声 | 13/15 (87%) | <= 7/15 | **✗** |

### LLM 生成的锚点（D选项）
```
"洗钱 逃税 隐瞒 应税收入 减少"
"公司税 税基侵蚀 利润转移 非法资金"
"税务负担 增加 无关 洗钱 直接后果"   ← 这是元评论，不是检索词！
```

### LLM 锚点失效根因

**不是 LLM 分析能力差**——LLM 正确理解了题目、选项和所需证据类型。
**是 LLM 不知道教材里有什么**：

| 教材实际术语 | LLM 生成的近似词 |
|---|---|
| 税收损失、政府税收缩水 | 洗钱、逃税、应税收入 |
| 贸易洗钱、黑市比索 | (未生成) |
| 空壳公司、虚假发票 | (未生成) |
| 税务欺诈、增值税链条 | 税基侵蚀、利润转移 |

LLM 用"反洗钱领域一般会有什么"来生成锚点，而不是用"CAMS 教材具体写了什么"。
第三个锚点"税务负担 增加 无关 洗钱 直接后果"甚至是推理结论而非检索词。

## 核心发现

**检索不是瓶颈。LLM 题目拆解是瓶颈。**

人工锚点 → 检索达标（3/4, 噪声 27%）
LLM 锚点 → 检索失败（2/4, 噪声 87%）

问题不在检索算法，而在 LLM 生成的锚点与教材实际术语之间存在**表述鸿沟**。
LLM 缺少教材知识，无法生成教材中实际使用的概念名称。

## 下一步方向

三个选项：

### A. 给 LLM 教材上下文（推荐优先尝试）
在 LLM 拆题前，先跑一轮粗检索（用题干关键词），把 top-20 卡片的 knowledge 列表
作为上下文喂给 LLM，让 LLM 基于"教材实际有什么"来扩展锚点。

```
题干关键词粗检索 → top-20 card knowledge 列表 → LLM 审阅后生成精准锚点 → 精细检索
```

### B. LLM 不生成锚点，而是直接判断相关性
LLM 拿到粗检索的 top-50 结果后，直接判断每条属于哪个证据区。
跳过"锚点生成"环节，改用"检索→排序→LLM 分类"。

### C. 混合：人工维护锚点模板 + LLM 填充
教研为每类题型维护锚点模板（如"FI后果题→必查税收损失+贸易洗钱+空壳公司..."），
LLM 只负责根据具体题目填充变量部分。

建议先试方案 A，因为改动最小且不牺牲自动化程度。
