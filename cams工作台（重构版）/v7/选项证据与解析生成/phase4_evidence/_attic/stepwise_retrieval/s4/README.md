# s4：盲审判定

s4 是盲审判定层。

它读取 s3 的 LLM 可读召回文本，让 LLM 仅基于提供的召回内容做出结构化判定。

## 定位

- s3 准备可读的召回上下文。
- s4 执行选项盲审判定。
- 面向学员的解析编写是后续独立的研究层。

## 目标

为每道题和每个选项生成结构化判定。

s4 应输出：

- 预测答案
- 置信度级别
- 选项级判定
- 引用的单元 ID
- 每个选项的简要依据
- 证据缺口（如有）

## 边界

- 不涉及 BGE/BM25 搜索。
- 不涉及知识图谱扩展。
- 不重组召回文本（仅提示组装）。
- 不输入参考答案或参考解析。
- 不编写面向学员的解析。
- 不生成最终考试风格的解析。

## 理由

判定和编写解析是不同的任务。

判定应受限、结构化、易于评估。面向学员的解析可能需要额外的教学上下文、风格控制或与参考材料的对比，因此应单独研究。

## 状态

目前仅定义了阶段契约。提示格式、输出 schema、模型选择和验证检查将后续设计。
