# 教研需求理解

## 最终目标

建设一个 CAMS 教材知识图谱。教研拿到一道新题，把题干和每个选项往图里查：

- 每个选项落到图上的知识节点
- 节点之间有边连着——这些边就是概念之间的客观关系
- 教研看图上的分布和连线，直接理解这道题考了什么、选项之间是什么关系、学生可能在哪条边上走岔了

验收标准不是准确率，是三个"能"：
1. 选项能落到节点上（教材没讲的可以落空，落空也是信息）
2. 节点之间的边能说清关系
3. 教研看一眼图谱就懂这道题——不需要先读解析、不需要翻教材

---

## 铁律（不可打破）

1. **旧解析、教研答疑、人工证据包绝不能作为输入**。只能用于事后验证。破了整个实验无效。
2. **教材原文可以全量用**。教材全文、目录、卡片——这些都是教材自身的材料，不是教研的智力产出。
3. **每一步的 LLM 输出驱动下一步**。不人手写分析结论塞进 prompt。
4. **节点和边不人工编造**。人可以审核、删、改，但不能替 LLM 写。
5. **每条推理必须有 card_id**。最终输出不能只有"教材说……"，必须指向具体卡片。可追溯是底线。
6. **教研数据只验证，不参与构建**。建图过程完全封闭（教材+卡片+LLM）。建好后用教研数据验收。验收不通过回去改图，不反向喂数据。
7. **过程可审计**。每次 LLM 调用的 prompt 和输出都保存。任何节点、任何边都要能追溯到"怎么来的"。

## 最终效果示意（以 2.1_19 为例）

```
选项 A "盈利业务的减少或损失"──→ [FI后果列表] ──挂载──→ v6_b04_N09
选项 B "代理银行设施的增加"  ──→ [FI后果列表] ──边──→ "方向相反：代理银行业务被终止"
选项 C "雇员人数减少"        ──→ [?]                     ← 图上挂不上，说明教材没讲
选项 D "公司税的增加"        ──→ [税收损失]   ──边──→ [FI后果列表]
                                   │                        │
                                   v6_b03_N18              v6_b04_N09
                                   "政府税收缩水"          "FI负面影响列表"
                                   │                        │
                                   └── 关系：主体不同 ──────┘
                                      政府≠金融机构
                                      缩水≠增加
选项 E "调查费用和罚金的增加"──→ [FI后果列表] ──挂载──→ v6_b04_N09
```

教研看这张图：
- A/E 落在 FI 后果列表节点 → 正确项，有卡片支撑
- B 也落在 FI 后果列表，但边指向"方向相反" → 干扰项，考的是方向和原文相反
- C 落空 → 教材没讲这个，纯干扰
- D 落在税收损失，和 FI 后果之间有一条"主体不同"的边 → 学生把政府税收缩水误认为 FI 公司税增加

## 教研要什么

- 哪个选项落到哪个知识点
- 这些知识点之间怎么连的
- 从图的结构就能看出这道题考了什么、选项之间是什么关系

## 图的节点和边怎么来

**节点**：教材的小节/概念 + 每张卡片挂载到对应节点。这是确定性关系，从教材目录和卡片 citation 可以直接得到。

**边**：跨节概念之间的关系。由 LLM 读教材全文后一次性标注。边描述的是两个知识点之间客观存在的联系——比如"税收损失的主体是政府""FI 后果的主体是金融机构"，这个主体差异本身就是一条边。

## 易混淆是怎么来的

"易混淆"不是预先打好的标签。一道题的选项落到图上不同节点后，这些节点之间如果本来就有一条边（比如主体不同、方向相反），那就自然解释了学生为什么会选错——他在两个相关但不同的概念之间走了岔路。

## 和教研当前工作的关系

教研目前是人工做这件事：看题 → 想学生错在哪 → 翻教材找对应段落 → 串联证据。知识图谱是把这一步自动化——选项落到图上，节点之间的边直接给出推理路径，不需要每次人工串联。

## 和关键词匹配的区别

关键词匹配：选项文本 → 搜到相关卡片 → 返回

知识图谱：选项文本 → 定位到图上的节点 → 沿边走到关联节点 → 拿到关联节点的卡片 → 返回推理链

区别在于那一步"沿边走到关联节点"。关键词匹配只有一跳，知识图谱可以多跳。
