# s3：检索上下文重排序与渲染

s3 是召回文本渲染层。

其目的是将前序步骤产生的召回内容转换为更易于 LLM 阅读的文本。

## 定位

- s1 提供直接 BGE/BM25 召回单元。
- s2 添加知识图谱扩展的候选上下文并保留路径。
- s3 对召回内容进行重排序、组织和格式化。

## 目标

构建可读的召回文本，用于后续提示组装。

s3 应清晰区分：

- 哪些文本来自直接检索
- 哪些文本来自同核心点知识图谱扩展
- 哪些文本来自知识图谱边扩展
- 每个渲染块支持哪些单元 ID 和路径

## 边界

- 不涉及 BGE/BM25 搜索。
- 不涉及知识图谱扩展。
- 不调用 LLM。
- 不做答案判定。
- 不编写最终解析。

## 状态

目前仅定义了阶段契约。具体的渲染策略和预算将后续设计。
