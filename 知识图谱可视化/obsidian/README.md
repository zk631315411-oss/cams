# CAMS 教材知识图谱

这个 Obsidian 库由 `重要资产以及构建方式/kg_data.json` 导出，用于现场查看教材知识点、关系边和句卡证据。

## 怎么看

- 打开 Obsidian 后，选择“打开本地仓库”，指向本文件夹。
- 进入 `知识节点/` 查看每个知识节点页面。
- 打开 Obsidian 右上角关系图谱，能看到知识节点之间的双链关系。
- 每个节点页里的“证据句卡”来自挂载到该节点的教材句卡。
