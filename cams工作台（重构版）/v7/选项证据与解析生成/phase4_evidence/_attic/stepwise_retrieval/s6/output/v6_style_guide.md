# v6 教研解析风格指南

> 本指南基于对 v6 习题结构化目录中 9 个文件、约 40 道代表性题目的深度精读归纳而成。精读样本覆盖 2.1/2.2（基础概念）、3.1/3.3（FATF/监管）、4.1/4.3（CDD/审计）、5.1/5.3（合规计划）、6.x（专题）各章节，含单选、多选、案例题、法条引用题等不同题型。
>
> 指南目的：不是抄格式，而是总结教研"怎么想、怎么写"的思维路径与表达习惯，供 s6 阶段生成 v7 解析时设计 LLM prompt 使用。

---

## 一、写作模式归纳

### 1. 错误选项辨析的切入角度

v6 教研辨析错误选项时，使用频率从高到低大致为以下五类。每种切入角度都有其适用题型，s6 生成时应根据题干特征匹配切入角度。

**(1) 概念范围（"这只是 X 的一部分"/"以偏概全"）— 最高频**

适用于：选项把局部措施说成核心目标、把手段说成目的、把单一要素说成全貌的题。

例 1（2_1 第1题 B 选项）：
> "支付控制（如现金限额）**仅是 AMLD 的部分措施**（如第6号指令规定≥€10,000现金交易禁令），**非核心目标**。"

例 2（3.1 第2题 A 选项）：
> "成员国数据标准不一，难以横向比较……**输出是数据而非风险分析**，无法直接用于理解趋势或方法。"

例 3（5.1 第22题 A 选项）：
> "虽然重要，但题目问的是追踪资金的具体步骤，而非合规程序。**STR 是结果，而非调查方法**。"

**关键句式**：仅是/属于……的一部分、非核心目标、是手段而非目的、输出是 X 而非 Y。

**(2) 权限边界（"超出了 X 的权限"/"越权"）— 高频**

适用于：涉及 FATF、FIU、监管机构、银行、执法机构等多主体职责划分的题。

例 1（3.1 第1题 D 选项）：
> "**超出了 FATF 权限**，需联合国或国家层面决定。"

例 2（4.3 第14题 A 选项）：
> "通知其他银行冻结客户资产**属于越权行为**，银行无权指令第三方，需由执法机构统一协调。"

例 3（5.1 第7题 D 选项）：
> "**建议引渡超出了金融机构职权范围**。"

**关键句式**：超出了……权限、属于越权、不在……职责范围内、需由 X 而非 Y 决定。

**(3) 条件前置（"需先确认 Y"/"前提未满足"）— 高频**

适用于：操作流程题、先后顺序题、"下一步应做什么"题。

例 1（2_2 第4题 A/D 选项）：
> "A 和 D 其实讲的是同一件事情……都不选是因为**这两个做法只能保证后续的客户尽调是合规的，但是现存客户却没有被覆盖到**。"

例 2（4.1 第10题 B 选项）：
> "培训是重要手段，但**必须先知道问题在哪**……如果没有风险评估，修改培训可能是无效的。"

例 3（4.3 第25题 B 选项）：
> "核实存款来源虽然重要，但**应在完成客户身份验证后进行**。"

**关键句式**：需先……再……、前提未满足、属于后续步骤而非第一步、应先 X 后 Y。

**(4) 概念混淆（"混淆了 X 和 Y"/"张冠李戴"）— 中频**

适用于：指令编号、法条编号、标准来源、机构职能等"识记型"题，以及把 A 概念错认为 B 概念的题。

例 1（3.3 第1题 A 选项）：
> "将范围扩大到与毒品有关的犯罪之外**是第 2 个欧盟指令**。"（题干问第 1 号指令）

例 2（3.1 第5题 A 选项）：
> "'技术标准评估'并非 FATF 术语，**混淆了'技术合规性'概念**。"

例 3（4.1 第1题 C 选项）：
> "风险偏好是**战略层面**的设定，而风险评估是**执行层面**的具体措施，两者相关但**不等同**。"

**关键句式**：混淆了 X 和 Y、是第 N 号指令而非本题、是 A 概念不是 B 概念、属于 X 范畴而非 Y。

**(5) 因果链（"是手段而非目标"/"颠倒了因果关系"）— 中频**

适用于：目标—措施类、原因—结果类的辨析。

例 1（2_1 第1题 C 选项）：
> "**合作是手段**（如 FIU.net 平台），**非 AMLD 的立法目标**。"

例 2（4.1 第7题 A 选项）：
> "易规模大≠高风险，**需结合交易背景**（如是否涉及制裁国家）判断，不能仅因金额终止。"

**关键句式**：是手段而非目标、颠倒了……关系、需结合 X 判断、不能仅凭 Y。

**(6) 其他辅助切入：违反原则 / 程序违规**

例 1（5.1 第28题 D 选项）：
> "联系客户可能**打草惊蛇**，如涉及恐怖融资，或导致资金转移（《爱国者法案》第316条禁止）。"

例 2（5.1 第10题 B 选项）：
> "绝大多数司法管辖区**禁止'通风报信'**，可能构成妨碍司法。"

**关键句式**：违反……原则、构成……违规、可能打草惊蛇、属于禁止行为。

### 2. 正确选项的论证方式

教研论证正确选项时，**主流模式是"正向引用教材原文/法规 + 反向排除其他选项"的正反结合**，单纯反向排除或单纯正向引用的较少。

**(1) 正反结合（主流，约 70% 题目）**

例 1（4.1 第1题 D 选项）：
> "D 选项正确，风险评估的核心目标（**根据 FATF 建议1 和巴塞尔委员会指引**）：识别高风险领域（如特定客户、产品、服务、地理位置）。确保采取风险为本（Risk-Based Approach, RBA）的控制措施，例如：对高风险客户加强尽职调查（EDD）、限制高风险地区的业务或交易、对复杂产品（如虚拟资产）实施额外监控。"
> 之后逐项排除 ABC。

例 2（4.3 第6题 B 选项）：
> "B 选项正确，高风险客户（如政治公众人物 PEPs、空壳公司、高净值客户）必须提供**实际受益人（UBO, Ultimate Beneficial Owner）的详细信息**，包括：身份证明（护照、身份证）、职业背景（是否涉及敏感行业）、资金来源（财富积累过程）、与客户的关联性（是否直接/间接控制账户），**这是 EDD 的核心要求（FATF 建议10、12）**。"

**论证要素**：① 引用法规/标准来源（FATF 第 X 条、巴塞尔原则、AMLD 等）；② 概括正确选项的核心含义；③ 与选项关键词对应；④ 在选项分析中再排除其他项。

**(2) 单纯反向排除（约 20% 题目，多见于"定义型/识记型"题）**

例（3.3 第1题 B 选项正确）：
> "B 选项正确，将毒品贩运确立为洗钱的前提罪行**是第 1 个欧盟指令**。"
> 其他选项分别指出"是第 2/3 个指令"。

**(3) 单纯正向引用（约 10% 题目，多见于简单识记题）**

例（3.3 第5题 C 选项正确）：直接抄录教材原文"将从事商品交易且支付或收取现金超过 10,000 欧元（此前为 15,000 欧元）或以上的自然人和法人纳入监管"即结束。

**对 s6 的启示**：默认采用正反结合；只在识记型题（指令编号、定义原文）使用单纯反向排除；单纯正向引用应避免，因为对考生理解无帮助。

### 3. 教材依据引用

教材依据引用方式存在较大差异，规律如下：

**(1) 直接抄原文 — 适用于定义题、阶段题、列表题**

例（2_1 第4题"洗钱的三个阶段"）：完整抄录处置/离析/融合三个阶段的教材原文，含示例列表。
例（3.1 第27题"11 条直接目标"）：完整列出 11 条 Immediate Outcomes。

**问题**：3.1 第27题抄录全部 11 条后，选项分析只简短对应 A/B/E，**教材原文与选项分析脱节**，篇幅浪费。

**(2) 浓缩概括 — 适用于原则题、机制题**

例（3.1 第1题）：
> "金融行动特别工作组（FATF）公开声明公布的国家或司法管辖区：或存在重大战略缺陷，须实施应对措施。"

把整段教材浓缩为一句话，便于考生抓住核心。

**(3) 改写转化 + 法规标注 — 适用于应用题、案例题**

例（4.1 第1题）：
> "风险评估的核心目标（**根据 FATF 建议1 和巴塞尔委员会指引**）：识别高风险领域……"

将教材表述改写为"核心目标"句式，并标注法规来源。

**(4) 不引用，仅给具体知识点标签 — 适用于实操题、流程题**

例（4.1 第18题、4.3 第31题）：仅给出"反洗钱 / 反恐融资风险识别"或"可疑和异常交易监控与报告"等标签，直接进入选项分析。

**对 s6 的启示**：
- 定义题、阶段题：可适度抄录教材原文，但**必须在选项分析中将原文要点与各选项对应**，避免脱节。
- 原则题、机制题：浓缩为一两句话，标注法规来源（FATF 第 X 条 / 巴塞尔原则 X / AMLD X 等）。
- 应用题、案例题：改写为"核心目标 / 关键要求"句式 + 法规标注。
- 实操题、流程题：可仅给知识点标签，但选项分析必须自给自足。

### 4. 详略节奏

**(1) 主流节奏：正确选项详细论证，错误选项简略排除**

约 80% 题目遵循此节奏。正确选项展开 2-5 句，错误选项各 1-2 句。

例（4.1 第1题）：
- D 正确：4 句话展开（核心目标 + FATF 引用 + 三类控制措施举例）
- A/B/C 错误：各 1 句话排除

**(2) 高迷惑性选项展开多，明显错误选项简略**

例（3.1 第9题）：B/C/D 选项都展开两层（"完整性不足"+"宏观制度覆盖不全"），因为它们迷惑性高；A 选项展开较多是因为它是正确选项。

**(3) 含案例 / 场景的题，题干要素必须被解析呼应**

例（5.1 第4题"游泳池公司 19 个账户"）：解析逐选项讨论"客户信用局报告""执法调查报告""面试技术员和供应商""因特网搜索"四个资源对案例的具体适用性，并加入教研注释"面试并非我们普通理解的'面试'，英文中的 interview 还有调查、审问等意思"，帮助考生理解题意。

例（5.1 第38题"退休老人每周三次存 3000 美元"）：解析指出"历史模式：25 年来每月仅存入 1,500 美元退休金……近期异常：过去 4 个月，每周多次存入 3,000 美元现金（频率和金额激增）"，**把题干要素重新组织为对比模式**。

**问题**：部分题目详略严重失衡。
- 例（2_1 第4题）：解析仅"BCD 均是离析阶段"一句话，没有任何展开。
- 例（2_1 第7题）：仅"A 是处置阶段。BC 为离析阶段。D 是……融合阶段。"，过简。

**(4) 何时收束：明显常识错误、明显越权行为、明显概念错位时**

例（3.3 第1题 C 选项错误）："将犯罪活动的定义扩大到所有严重犯罪**是第 2 个欧盟指令**。"一句话点破，无需展开。

**(5) 何时展开：迷惑性强、需要因果链、需要法规支撑、需要案例对应时**

例（3.1 第9题 B 选项）：先指出"主要关注法人这一特定主体"，再展开"完整性不足：它只是反洗钱制度中的一个局部环节，缺乏对资金流动全过程……的综合考量"，两层论证。

**对 s6 的启示**：
- 默认：正确选项 3-5 句展开（含法规标注 + 核心含义 + 选项对应），错误选项 1-3 句排除（含切入角度 + 一句解释）。
- 高迷惑性选项：展开到 2-3 层（角度 + 理由 + 反例/对照）。
- 含案例题干：解析必须重新组织题干要素，与选项逐项对应。
- 明显错误：一句话点破即可，避免注水。

### 5. 语气和逻辑层次

**(1) 语气特征：以客观陈述为主，教研口吻为辅**

- **客观陈述（主流）**：使用"属于……""是……的一部分""违反……原则""应……"等句式。
- **教研口吻（次要）**：偶尔出现"我们应当注意……""解题关键……""举例：……"等教研提示性语言。
- **考官口吻（极少）**：如 2_2 第9题"解题关键：1）上游……2）下游……"，5.1 第34题"标准的流程是：调查 → 提交可疑活动报告 → 向高级管理层提交摘要和建议 → 管理层决策"。
- **考生口吻（无）**：未发现。

**对 s6 的启示**：保持客观陈述为主；可在迷惑性高的选项后加"解题关键""举例"等教研提示；避免考生口吻。

**(2) 逻辑层次：先知识点再选项（主流）**

约 75% 题目遵循"具体知识点 → 教材原文/概括 → 选项分析"的三段式。

约 20% 题目采用"直接进选项"（多为实操题、流程题），如 4.1 第18题、4.3 第31题。

约 5% 题目"知识点和选项交织"，多见于案例题，如 5.1 第4题、4.3 第24题，将教材原则融入选项分析。

**(3) 教研注释（值得保留的特色）**

部分解析加入"教研注释"帮助考生理解，是 v6 的一个亮点：

例 1（5.1 第4题）：
> "面试并非我们普通理解的'面试'，英文中的 interview 还有调查、审问等意思。这里的面试指的是要去查一查技术员和供应商，对于银行而言，可能就是通过 RFI（客户征询函）……"

例 2（2_2 第9题）：
> "解题关键：1）上游：代理银行（大银行）为代理银行客户（小银行）提供的直接通汇服务……2）下游：代理银行客户（小银行）再把它在代理银行的账户，提供给其他更小的金融机构使用……"

例 3（5.1 第34题）：
> "标准的流程是：调查 → 提交可疑活动报告 → 向高级管理层提交摘要和建议 → 管理层决策（可能包括下令限制账户或销户）"

**对 s6 的启示**：保留教研注释特色；对容易误解的术语（如 interview、tipping-off、去风险化等）可加 1-2 句注释；对操作流程类题目可给出"标准流程"链条。

## 二、写得好的地方

### 亮点 1：多维度辨析迷惑项，揭示选项的"局限性"

例（3.1 第9题 B 选项）：
> "B 选项错误，主要关注法人这一特定主体被滥用于非法活动的情况。虽然法人在经济活动中具有重要地位，且确实存在被利用进行洗钱和恐怖融资的风险，但这只是反洗钱工作中的一个方面，不能涵盖所有可能的洗钱渠道和主体，如自然人、非法人组织等同样可能参与洗钱活动。因此，仅强调防止法人滥用，不能全面反映一国反洗钱制度在防范各类主体和各种形式洗钱行为方面的有效性。
> **完整性不足**：它只是反洗钱制度中的一个局部环节，缺乏对资金流动全过程以及其他相关方面的综合考量，不能体现反洗钱制度在宏观层面上对整个金融体系和社会经济环境中非法资金的防控能力。"

**好在哪里**：先用一句话概括选项的局限（"主要关注法人这一特定主体"），再用"完整性不足"作为小标题点出切入角度，最后展开具体理由。**两层论证层层递进**，让考生明白"为什么错"和"错在哪里"。

### 亮点 2：概念混淆精准定位，用对比直接揭穿错位

例（3.3 第1题）：
> "A 选项错误，将范围扩大到与毒品有关的犯罪之外**是第 2 个欧盟指令**。
> B 选项正确，将毒品贩运确立为洗钱的前提罪行**是第 1 个欧盟指令**。
> D 选项错误，将洗钱定义为一种单独的犯罪**是第 3 个欧盟指令**。"

**好在哪里**：每句话都用"是第 N 个指令"做对比，**三句话形成对照矩阵**，考生一眼即可识破"张冠李戴"。这是识记型题的最佳辨析模式。

### 亮点 3：因果链分析透彻，一句话点破本质

例（5.1 第22题 A 选项）：
> "A 选项错误，虽然重要，但题目问的是追踪资金的具体步骤，而非合规程序。**STR 是结果，而非调查方法**。"

**好在哪里**：用"是结果，而非调查方法"一句话点破"合规程序"与"调查方法"的因果颠倒，**精炼有力**。这种"是 X 而非 Y"的句式适合用于因果链辨析。

### 亮点 4：案例与法规结合，给出可操作的操作链条

例（5.1 第34题"人口贩运客户")：
> "选项 A 正确：因为在提交 SAR 后，调查员的下一步应是内部升级处理，包括向高级管理层报告并建议是否终止客户关系。不得泄露信息、干扰调查或擅自采取外部行动。
> 选项 D 错误：'在执法部门逮捕之前，限制或阻止客户的账户'是一个可能的最终行动，但这个行动通常需要基于高级管理层的决策和可能的法律建议。在流程上，它应该发生在选项 A（建议）被批准之后。调查员直接执行 D，**越过了必要的审批环节**。
> **标准的流程是**：调查 → 提交可疑活动报告 → 向高级管理层提交摘要和建议 → 管理层决策（可能包括下令限制账户或销户）"

**好在哪里**：先给出正确选项的操作定位，再用"越过了必要的审批环节"点出 D 选项的流程错误，最后用"标准的流程是"画出完整操作链条。**考生读完不仅知道选什么，还知道在实务中怎么做**。

### 亮点 5：教研注释化解术语误解

例（5.1 第4题）：
> "面试并非我们普通理解的'面试'，英文中的 interview 还有调查、审问等意思。这里的面试指的是要去查一查技术员和供应商，对于银行而言，可能就是通过 RFI（客户征询函）、请客户亲临分行，甚至可能派出高级调查员中的卧底 team（可以把它简单理解为客户经理上门回访）去获取更多的信息。"

**好在哪里**：敏锐察觉中文翻译可能引起的误解，主动加注释把"面试"还原为"调查/审问"，并给出银行实务中的具体形式（RFI、上门回访）。**这种"教研补丁"是 v6 区别于普通题库的价值所在**。

## 三、有待改善的地方

### 问题 1：详略失衡，部分解析过简，未真正辨析

例（2_1 第4题）：
> "选项 A 是处置阶段，将犯罪资金存入金融机构。BCD 均是离析阶段。"

**问题**：B/C/D 三个选项只用"均是离析阶段"一句话带过，**没有解释为什么**。考生无法理解为什么"在不同银行账户间进行大量转账交易"是离析而不是处置或融合。

**改进方向**：每个错误选项至少要给出"为什么属于该阶段"的一句解释，例如"B 是离析，因为通过账户间转账隐匿资金来源"。

### 问题 2：教材原文冗长且与选项分析脱节

例（3.1 第27题"11 条直接目标"）：完整抄录 11 条 Immediate Outcomes，约 500 字，但选项分析仅简短对应 A/B/E：
> "A 选项正确，'各国通过国际合作及时提供可操作金融情报、证据和追赃协助。'评估要点：司法互助条约（MLATs）的执行效率、FIU 间埃格蒙特集团框架下的情报交换。"

**问题**：教材原文与选项分析**没有逐项对应**，考生看完原文仍不知道哪条对应哪个选项，篇幅浪费严重。

**改进方向**：教材原文应**裁剪到与选项相关的 3-5 条**，并在选项分析中明确标注"对应教材第 X 条"。

### 问题 3：逻辑跳跃，引用法条但不解释适用理由

例（2_1 第13题）：
> "A 选项错误，扣押特权文件**违反《联邦证据规则》第 502 条**，（律师-客户/审计师特权），必须通过法律部，申请特权审查。
> C 选项错误，无传票索要文件**违反《第四修正案》**，禁止无理搜查，要求出示：行政传票（FinCEN）、大陪审团传票。"

**问题**：直接抛出《联邦证据规则》第 502 条、《第四修正案》等具体法条，但**没有解释为什么这些法条适用**、它们的保护对象是什么。考生若不熟悉美国法，根本无法理解。

**改进方向**：引用法条时先一句话概括法条精神（"《第四修正案》禁止无理搜查，要求执法行为有合法授权"），再说明"因此 C 选项违反……"。

### 问题 4：避重就轻，争议题或难解析处直接空白

例（3.1 第13题，标注【争议题】）：
> "### 解析
> 解析:具体知识点:
> 【争议题】金融行动特别工作组 40 项建议
> 选项分析:
> （空白）"

**问题**：争议题更应详细解析，说明争议点在哪里、各选项的强弱理由。直接空白**等于放弃解析**，对考生无帮助。

**改进方向**：争议题应：(1) 明确争议焦点；(2) 给出参考答案的最优理由；(3) 说明其他选项的"也有一定道理"之处；(4) 给出考场上的取舍建议。

### 问题 5：个别辨析牵强或武断

例（2_1 第9题 D 选项错误）：
> "D 选项错误，洗钱主要通过金融系统和经济领域扩散影响，对国家基础设施（如电力、交通、通信等）的**直接破坏缺乏实证依据**。"

**问题**：洗钱确实可能通过"私有化风险"和"经济扭曲"间接影响基础设施，"缺乏实证依据"过于武断。**应改为更准确的切入角度**，如"E 选项属于衍生性/间接影响，非洗钱的直接社会/经济后果"。

### 问题 6：格式混乱，解析内容写在选项列表中

例（2_1 第17、18、19题，2_2 第9、20题，3.3 第1、4、6、14题，4.1 第4、13题等）：
```
- B. 选项正确，有组织犯罪集团通过设立多个空壳公司，可以在某个经济部门中进行渗透和布局。例如，他们可以通过这些空壳公司控制供应链、操纵市场价格、垄断某些资源等，从而实现对整个经济部门的非法控制……
```

**问题**：把选项分析直接写在选项列表里，与"### 解析"段分离，格式上**严重不一致**，影响后续解析的结构化处理（如 s6 检索）。

**改进方向**：选项列表只保留"A. xxx"原文本，所有分析内容统一放在"### 解析 → 选项分析"段下。

### 问题 7：知识点标签与考点不匹配

例（2_1 第13题）：
> "具体知识点: 有组织犯罪和腐败的风险增大"

**问题**：题目问的是"执法机构向 FI 提交请求，哪个合法需要银行回应"，考点应为"执法请求/作证传票/法律授权"，而非"有组织犯罪和腐败的风险增大"。**标签错位会导致检索失败**。

**改进方向**：知识点标签必须精确对应题目考查的核心概念，避免机械抄录章节标题。

## 四、对 s6 生成 v7 解析的启示

基于以上归纳，s6 阶段生成 v7 解析时，LLM 应遵循以下 8 条具体建议：

### 建议 1：辨析错误选项时，先识别题型再选切入角度

- **目标—措施类题** → 优先用"概念范围"（"这只是 X 的一部分"）和"因果链"（"是手段而非目标"）。
- **多主体职责类题**（FATF / FIU / 监管 / 银行 / 执法）→ 优先用"权限边界"（"超出了 X 的权限"）。
- **操作流程题**（"下一步应做什么"）→ 优先用"条件前置"（"需先确认 Y"）。
- **指令编号/定义识记题** → 优先用"概念混淆"（"是第 N 号指令而非本题"）。
- **涉及保密/泄密/客户通知的题** → 优先用"违反原则"（"构成 tipping-off"）。

**每道题至少识别一个主切入角度，避免"角度混乱"**。如果某选项同时涉及多个角度，按主次顺序展开。

### 建议 2：正确选项默认采用"正反结合"论证

- 默认结构：① 标注法规来源（FATF 第 X 条 / 巴塞尔原则 X / AMLD X 等）；② 概括正确选项的核心含义；③ 与选项关键词对应；④ 在选项分析中再排除其他项。
- 仅在识记型题（指令编号、定义原文）使用单纯反向排除。
- **避免单纯正向引用**教材原文而不做选项对应。

### 建议 3：教材引用按题型分级处理

- **定义题/阶段题**：可适度抄录教材原文（如洗钱三阶段），但**必须在选项分析中将原文要点与各选项逐一对应**，避免"原文归原文、分析归分析"的脱节。
- **原则题/机制题**：浓缩为一两句话，标注法规来源。
- **应用题/案例题**：改写为"核心目标 / 关键要求"句式 + 法规标注。
- **实操题/流程题**：可仅给知识点标签，但选项分析必须自给自足。
- **教材原文裁剪原则**：只引用与选项相关的部分，**禁止抄录大段教材原文后只对应少数选项**。

### 建议 4：详略节奏遵循"3-5 / 1-3"原则

- 正确选项：3-5 句展开（含法规标注 + 核心含义 + 选项对应）。
- 错误选项：1-3 句排除（含切入角度 + 一句解释）。
- **高迷惑性选项**：展开到 2-3 层（角度 + 理由 + 反例/对照）。
- **明显常识错误**：一句话点破即可，避免注水。
- **含案例题干**：解析必须重新组织题干要素（如"历史模式 vs 近期异常"），与选项逐项对应。

### 建议 5：引用法条时先解释法条精神，再说明适用

- 错误示例（v6）：直接抛出"违反《联邦证据规则》第 502 条"而不解释。
- 正确示例：先一句话概括法条精神（"《第四修正案》禁止无理搜查，要求执法行为有合法授权"），再说明"因此 C 选项违反……"。
- 法条引用应**与题干情境绑定**，避免"法条归法条、选项归选项"。

### 建议 6：保留教研注释和"标准流程"链条

- 对容易误解的术语（如 interview、tipping-off、去风险化、巢状交易等），可加 1-2 句教研注释。
- 对操作流程类题目（如 SAR 提交后的步骤、收到传票后的应对），可给出"标准流程是：A → B → C → D"的链条。
- 教研注释应放在选项分析中，**不要单独成段**，避免破坏结构。

### 建议 7：争议题不能空白，必须给出取舍逻辑

- 明确争议焦点（"本题争议在于……"）。
- 给出参考答案的最优理由。
- 说明其他选项的"也有一定道理"之处。
- 给出考场上的取舍建议（"如遇此类题，优先选 X，因为……"）。

### 建议 8：格式必须严格统一

- 选项列表（`### 选项`段）只保留选项原文（`- A. xxx`），**禁止把分析内容写在选项列表里**。
- 所有分析统一放在`### 解析 → 选项分析`段下，按"选项 A：…… 选项 B：……"顺序展开。
- `具体知识点`标签必须精确对应题目考查的核心概念，**避免机械抄录章节标题**。
- 多选题在选项分析前可加一句总结（如"选择 CD。ABE 均是对于洗钱行为的规避，CD 是危险信号"），但**不能代替逐项分析**。
