# 日报 — 2026-07-23

昨天把V7 解析导出流程从三步压到两步，今天自然延续，把剩下的问题收掉。解析格式统一到导入标准，和 DOCX 转换打通了——之前解析出来的东西格式不一致，往 docx 倒的时候各种格式问题，今天集中搞定。

之前盲判只读当前段落，跑了几轮测试发现有些题目被前后文截断，信息量不够，判断不准。看了几个具体 case 以后确认是这个问题，于是把上下文扩展到前后各 4 段。±4 这个数字没有精确推敲，是基于对教材段落长度的估计拍脑袋定的，后续如果效果不理想再调。

跑解析的时候发现大约 5% 的证据引用存在问题——要么引用错了位置，要么引用的表述不严谨。虽然比例不高，但考试场景下这 5% 就是实打实的错误，不能放过去。所以在 prompt 层面加了强制检查逻辑，如果引用不到原文证据就直接拒答，不再输出"可能对"但没依据的答案。

第一二章的 V7 英文版今天上线了。其实昨天就已经可以上了，内容本身没问题，只是结构上需要自动化处理一下（之前手动调格式也能上线，但效率低）。今天把结构问题自动化搞定后直接推上线。中文版延后——中文教材是从英文翻译过来的，翻译质量不稳定，今天 CAMS 售后刚好出了翻译相关的反馈，所以中文版压着，先核对翻译问题。
