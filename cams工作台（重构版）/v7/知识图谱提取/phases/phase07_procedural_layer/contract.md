# P7 Contract

## Input Sources

P7 reads the P6 base graph and P5 alias index:

```text
phases/phase06_kg_views/outputs/kg_retrieval_graph.json
phases/phase05_terms/outputs/p5c_alias_index.json
```

P7 may read earlier phase outputs only when a script explicitly documents why the P6 base graph is insufficient.

## Chapter Reading Task

Each chapter reading task preserves full chapter/section context. It is not a keyword-only candidate packet.

```json
{
  "task_id": "p7read_CH47_reader_a",
  "reader_role": "reader_a_explicit",
  "chapter_id": "CH47",
  "chapter_title": "Transaction monitoring",

    {
      "section_id": "CH47-S01",

```

## Process Card

Process cards are the required output of a reader. A card records the original evidence, natural-language note, structured nodes, structured short edges, and uncertainty warnings.

```json

  "reader_id": "reader_a",
  "scope": {
    "chapter_id": "CH47",
    "section_id": "CH47-S01",

  "plain_note_zh": "交易监控以客户资料中的正常参数判断异常，异常会触发警报。",
```

## Derivation Levels

```text
explicit          # supported by the cited unit text directly
strong_inference  # strongly implied by nearby units or a clearly connected local section
weak_inference    # plausible but not sufficiently grounded; not accepted into formal overlay
derived_from_edges # generated by programmatic chain assembly from accepted short edges
```

Formal P7 edges may include only:

```text
explicit
strong_inference after review
derived_from_edges with source_edge_ids
```

## Validation Rules

1. Every process card must include `scope.unit_ids`.
2. Every edge must include at least one `evidence_unit_ids` entry unless `derivation=derived_from_edges`.
3. Every `evidence_unit_ids` value must exist in the P6 base graph.
4. `weak_inference` edges must not enter `p7_procedural_edges.jsonl`.
5. Feedback-loop relations must use `edge_family=feedback_loop`; they must not be treated as ordinary `PRECEDES` edges.
6. Bridge edges must include `bridge_basis` and `source_edge_ids` or explicit unit evidence.
7. P5 alias matches may normalize node names but cannot be used as edge evidence.

## Reader Roles

```text
reader_a_explicit:
  Conservative reader. Extract explicit edges only. Mark possible missing bridge context, but do not create inferred bridge edges.

reader_b_process:
  Process reader. Extract explicit edges and strong_inference candidates. Must attach evidence and uncertainty flags.
```
